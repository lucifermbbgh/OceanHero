# 碧海英豪 (SeaHeroes)

> 当前版本 **1.4.20** · 特性版本「舰船模块化」已完结

2D 单机航海 RPG。驾驶风帆战舰航行于 31 张海图，进行观战式部件损伤炮战、跨港贸易、
船员招募与舰船模块养成，在七大势力的夹缝中经营自己的母港。

- 类型：2D 航海角色扮演 · 贸易 · 舰船养成 · 基地建设
- 引擎：Godot 4.7.2 / GDScript / GL Compatibility
- 平台：桌面（Windows / macOS），键鼠操作
- 语言：简体中文
- 网络：完全离线
- 参考：SeaFight（原《海战英豪》）、大航海时代系列、海商王

## 当前已实现

| 系统 | 内容 |
|---|---|
| 世界 | 31 张海图（母港 + 10 级 × 3），邻接图航行 |
| 势力 | 云澜 / 赤鳞 / 霜屿 / 玄礁 / 白鲸 / 苍梧 / 幽溟，声望 -100~100 八档 |
| 海战 | 四池损伤（船体/帆/舵/船员）、弹种、接舷、Boss |
| 舰船 | 12 类模块、船级分层、模块强化、装备与船员按模块归属 |
| 船员 | 4 岗位（大副/炮手/船医/水手）、招募、职级 |
| 经济 | 28 种商品五大类、关税、投资、银行、拍卖行、黑市、声望兑换所 |
| 城镇 | 7 座建筑、建造升级、城镇等级门槛、商店按月刷新 |
| 内容 | 任务板、赏金猎人、势力事件（宣战/停战/结盟/禁运）、存档 |

## 操作

| 操作 | 说明 |
|---|---|
| W / S | 加减帆 |
| A / D | 转舵 |
| 空格 | 开火（需锁定目标） |
| 左键 | 锁定 / 点击航行 |
| E | 靠近时互动（停靠、打捞、航门） |
| 1 / 2 / 3 | 时间速度 1× / 2× / 4× |
| Esc | 关闭最上层弹窗 / 面板 |

## 运行与构建

开发运行：使用 Godot 4.7.2 打开本目录并运行主场景。

导出 Windows 可玩版本：

    godot --headless --path . --export-release "Windows" export/SeaHeroes-1.4.20-Windows.exe

要求：已安装 Godot 4.7.2 导出模板；data/manifest.txt 需包含全部资源路径；
导出过滤需包含 *.txt,*.json,*.csv。
