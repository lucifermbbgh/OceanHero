## 2. 排期总表

> 工作量以"轮"计（1 轮 ≈ 一次完整开发+测试+文档）。音乐无限延后，其余全部排入。

### 第一优先（核心体验）

| 序 | 任务 | 工作量 | 依赖 | 验收 |
|---|---|---|---|---|
| A1 | **Boss 招牌技能**（4 模板：召唤护卫 / 侧舷齐射 / 火船冲撞 / 浓雾） | 2 轮 | 无 | 每个 Boss 有 1 个独有机制，玩家必须改变打法 |
| A2 | **战斗节奏修正**（6 级后 1~5 秒 → 所有等级 30~60 秒） | 1 轮 | A1 | 模拟器全等级战斗时长落在区间内 |
| A3 | **接舷战扩展**（甲板结算：船员对拼 2~3 回合，可选突击/撤退） | 1 轮 | 无 | 接舷不再是"判定即胜" |

### 第二优先（世界与节奏）

| 序 | 任务 | 工作量 | 依赖 | 验收 |
|---|---|---|---|---|
| B1 | **各图港口上岛**（8 张图各一个港口节点，含维修/市场/任务） | 2 轮 | 岛屿系统 | 每张图都能补给，形成航线网 |
| B2 | **越级刷图收益衰减**（低 2 级以上的图战利品 ×0.4） | 0.5 轮 | 无 | 模拟器不再"刷低级图最优" |
| B3 | **岛屿资源深化**（采集点分级、稀有资源、可建造采矿场提升产出） | 1.5 轮 | 建筑系统 | 玩家有稳定的资源来源，不只依赖市场 |
| B4 | **阵营玩法**（同势力不敌对、可协战、声望兑换支援舰队） | 2 轮 | 声望系统 | 声望 ≥3000 后该阵营不再攻击你，并可召唤 1 艘支援 |

### 第三优先（打磨）

## 3. 建议顺序

```
A1 → A2 → A3 → B1 → B2 → B3 → B4 → C1 → C2 → C3/C4 → D1 → D2 → D3
```

**理由**：

1. A 组解决"战斗不好玩"——这是留存的根本
2. B 组解决"世界太空"——9 张图只有 1 个港口，跑图没有意义
3. C 组是打磨，放在内容量足够之后
4. D 组是长线系统，可以边运营边加
