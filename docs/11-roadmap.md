## 2. 排期总表

> 工作量以"轮"计（1 轮 ≈ 一次完整开发+测试+文档）。音乐无限延后，其余全部排入。

### 决策记录（v0.7）

> **战斗系统本版不做升级**：Boss 与海怪不加技能，
> 差异完全由**装备与属性**体现（独有装备、更高数值、更快装填）。

### 第一优先（世界结构）

| 序 | 任务 | 工作量 | 依赖 | 验收 |
|---|---|---|---|---|
| A1 | **岛屿三级 + 港口分级落地**（村/镇/城 的服务差异：船厂、酒馆、交易所、声望按级开放） | 1.5 轮 | 已完成基础 | 三级港口能做的事明显不同 |
| A2 | **母港成长线**（渔港村落 → 乡镇 → 港口城市，按资源解锁功能） | 1 轮 | A1 | 母港升级后解锁交易所/声望面板 |
| A3 | **各图港口联网**（9 张图共 30+ 岛屿，形成补给网，远洋订单跨岛） | 1.5 轮 | A1 | 每张图都能补给，不再只有 1 个哨站 |
| A4 | **岛屿特产贸易路线的经济验证**（模拟器验证跑岛倒货是否比刷怪更划算） | 0.5 轮 | A3 | 两条收益曲线接近，不存在唯一最优解 |

## 3. 建议顺序

```
A1 → A2 → A3 → B1 → B2 → B3 → B4 → C1 → C2 → C3/C4 → D1 → D2 → D3
```

**理由**：

1. A 组解决"战斗不好玩"——这是留存的根本
2. B 组解决"世界太空"——9 张图只有 1 个港口，跑图没有意义
3. C 组是打磨，放在内容量足够之后
4. D 组是长线系统，可以边运营边加
