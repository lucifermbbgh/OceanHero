## 三、文档编写规则

1. **先文档后代码**：每个次版本先写 `13-version-plan.md` 的升级章节，确认后再开发
2. **编号固定**：`01 总体 → 02 系统 → 03 阶段 → 04 测试方案 → 05 测试报告`，新增文档排在其后
3. **每次版本结束必须更新**：版本历史、测试报告、变更记录
