## 启动方式

```
godot --path "$HOME/app/Godot/projects/SeaHeroes"
```

或由 agent 用 `godot_run_project` 启动。

## 一局游戏是什么样

```
母港（建造 / 市场 / 船厂 / 酒馆 / 交易所 / 任务板 / 声望）
   ↓ 出航
图 1 浅湾水道 ──击破 Boss──▶ 图 2 ──▶ … ──▶ 图 9 王冠之海
   ↓ 途中：自动炮战 / 接舷俘获 / 打捞 / 护航 / 赏金猎人
   ↓ 返港：维修 / 交易 / 换船 / 升级 / 交任务 / 存档
```

## 核心操作

| 场景 | 操作 |
|---|---|
| 主菜单 | 点「新游戏」；下方 6 个存档位可直接读取 |
| 母港 | 左侧 12 个按钮，右侧面板逐项操作 |
| 航行 | `W`/`S` 调速，`A`/`D` 转舵，左键点海图自动航行 |
| 战斗 | 左键点敌船**锁定**（不会自动开火）→ 装填就绪后点「**开火**」齐射；底部换弹药 |
| 脱战 | 拉开到 1600px 以外并保持 5 秒，敌人会放弃追击 |
| 任务追踪 | 出海后左上角「任务追踪」显示 3 条进行中任务与进度，点「导航」自动规划航线 |
| 接舷 | 目标船体 ≤10% 时按钮亮起 |
| 航门 | `E`：靠近母港航门返回；靠近前进航门进入下一图 |
| 时间 | 空格暂停，`1`/`2`/`3` 切换 1×/2×/4× |

## 已实现的内容

| 系统 | 内容 |
|---|---|
| 世界 | 9 张海域 + 母港，岛屿确定性生成，双航门关卡推进 |
| 战斗 | 四池损伤（船体/帆/舵/船员）、3 种弹药、接舷俘获、撤离 |
| 敌人 | 海盗、海怪、18 个 Boss（三阶段）、海军赏金猎人 |
| 舰船 | I~X 共 10 级 × 3 变体（通用/海军/海盗） |
| 装备 | 5 部位 20 件（含 9 件 Boss 独有）、火炮 10 级 |
| 船员 | 10 岗位、5 稀有度、酒馆随机招募、上阵加成 |
| 经济 | 金币 + 战功双货币、港口行情、交易所四标签 |
| 母港 | 8 座建筑 5 级、四类资源周产出、建造队列 |
| 任务 | 5 类（讨伐/贸易/运输/护航/采集） |
| 声望 | 三轴（任务/捐赠/击杀获取）、通缉度与保释 |
| 其他 | 流动时间与周结算、5+1 存档位、通关结算、帮助面板 |

## 已知限制（本版不做）

| 项 | 说明 |
|---|---|
| Boss 招牌技能 | Boss 之间靠装备与属性区分，无独有技能/召唤 |
| 其余 8 张图的港口 | 只有图 1 有浅湾哨站，且只提供维修/交易/任务 |
| 音效与音乐 | 完全无声音 |
| 美术 | 全部为程序化几何图形，无贴图 |
| 导出打包 | 导出模板未安装 |
| 越级刷低级图 | 收益未做衰减，高等级回低级图刷钱偏快 |
| 高等级战斗节奏 | 6 级以后同图普通敌人战斗时长偏短（1~5 秒） |

## 建议怎么玩第一局

1. 新游戏 → 母港先看「帮助」了解操作
2. 出航图 1，打 2~3 只海盗斥候，拾取战利品
3. 回港维修、卖货、去船厂换 4 磅炮
4. 攒够 2000 金换平底沙船
5. 挑战图 1 Boss（建议二级船 + 好炮）
6. 逐步推进到图 3~5，体验任务、交易所、声望

预计 60~90 分钟能摸到图 3 左右。
