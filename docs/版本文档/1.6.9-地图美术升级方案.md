# 1.6.9 地图美术升级方案（从色块到海图）

| 项 | 内容 |
|---|---|
| 日期 | 2026-11-26 |
| 背景 | 现有世界地图是「分区色块」，不具备海图素质 |
| 目标 | 达到参考图级别的世界总图 + 30 张海域分图 |

## 1. 参考图拆解

| 参考 | 类型 | 关键要素 |
|---|---|---|
| ERDONIA | 世界总图 | 密集海岸线、山脉/森林/沙漠纹理、海面刻线、地名、图例、边框 |
| NYMERIA | 海域分图 | 岛屿轮廓、浅滩、城镇图标、航线、罗盘、比例尺 |

两者的共同点：**底图信息密度高、文字与图标齐全、颜色克制**。
当前实现的问题：只有 30 个色块 + 稀疏标注，信息密度几乎为零。

## 2. 两个地图产品

| 产品 | 用途 | 内容 |
|---|---|---|
| 世界总图 | 世界地图界面 | 全海域、10 级分区、7 势力、航线、迷雾 |
| 海域分图 | 海上小地图 / 读图 | 单海域岛屿、港口、浅滩、航线 |

## 3. 生产管线（程序为主，AI 为辅）

| 层 | 内容 | 方式 |
|---|---|---|
| L1 海岸线 | 分形海岸（中点位移）+ 海湾/半岛 | 程序 |
| L2 地形 | 山脉、森林、沙漠、河流符号 | 程序撒点 + AI 笔刷贴图 |
| L3 海面 | 刻线波纹、罗经线、浅滩环 | 程序 |
| L4 区域 | 30 海域：虚线边界 + 极淡势力色（仅悬停/选中高亮） | 程序 |
| L5 文字 | 海域名、港口名、图例、比例尺 | 程序（中文字体） |
| L6 装饰 | 罗盘、饰框、标题饰框 | AI 素材 + 程序摆放 |

**关键改变**：区域不再用大面积色块，改为「细虚线边界 + 微弱势力色」，
信息由地形与文字承担，交互高亮时才上色。

## 4. AI 的定位

| 能做 | 不能做 |
|---|---|
| 羊皮纸/海面/山脉/森林笔刷质感 | 精确 30 区域拓扑 |
| 罗盘、饰框、纹章、图标 | 可读的中文地名 |
| 风格参考图 | 俯视世界地图构图（易画成场景） |

## 5. 执行阶段

| 阶段 | 内容 | 轮数 |
|---|---|---|
| **S1** | 海岸线与地形生成器（分形海岸 + 山脉/森林符号） | 2 |
| **S2** | 世界总图合成（区域虚线 + 文字 + 图例） | 1 |
| **S3** | 海域分图生成器（按岛屿数据出图） | 2 |
| **S4** | 游戏接入：世界地图底图 + 小地图分图 | 1.5 |
| **S5** | 验收与调色 | 0.5 |
| | **合计** | **约 7 轮** |

## 6. 验收标准

| # | 标准 |
|---|---|
| 1 | 世界总图缩到 50% 仍能看出海岸与地形 |
| 2 | 海域分图能认出岛屿与港口位置 |
| 3 | 区域边界存在但不抢视觉 |
| 4 | 中文地名清晰无伪字 |
| 5 | 与游戏内交互状态一致（迷雾/选中/航线） |

## 7. 与现有代码的关系

| 现有 | 处理 |
|---|---|
| `world_regions.tmj/json` | 保留，作为区域边界数据 |
| `land_masses.json` | 升级为分形海岸多边形 |
| `bg_sea.png` / `land_overlay.png` | 被新底图替换 |
| `world_map.gd` | 保留交互层，底图换成新总图 |
| `mini_map.gd` | 改为显示海域分图 |
