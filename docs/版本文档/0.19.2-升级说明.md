# 0.19.2 升级说明（试玩问题修复）

| 项 | 内容 |
|---|---|
| 基线版本 | 0.19.1 |
| 目标版本 | 0.19.2 |
| 状态 | 已发布（2026-11-18） |
| 主题 | 修复 0.19 试玩反馈的 8 类问题 |

## 1. 问题与修复

| # | 问题 | 原因 | 修复 |
|---|---|---|---|
| 1 | ESC 关的是外层市场面板 | 只判断 market_root | ESC 优先关商品弹窗 |
| 2 | 市场表格无边框、错位、有走势列 | 用裸 HBox + Label | 改为带边框单元格 PanelContainer；删除走势列与「操作」表头 |
| 3 | 港口规模图看不懂 | 无坐标轴说明 | 改名「规模经济」，加数值标签与结论行 |
| 4 | 指标信息挤成一团 | 单行拼接 Label | 改为三列表格：指标 / 结果 / 计算过程，逐项一行 |
| 5 | 边际分析图全是横线 | MC 用硬编码基数、MR = 基数×1.6 | MC 用本港实际买价曲线、MR 用实际卖出价，并标注绿色可买区/红色亏损区 |
| 6 | 弹性图粗糙、区域分不清、无计算过程 | 曲线采样少、无着色 | 改名「弹性价格」；上下区域着色、加大字号；计算过程进指标表 |
| 7 | 均衡价格图无价值 | 供需两条线无实际含义 | 改为「价格与库存」：横轴库存量、纵轴买价，标出当前库存点与结论 |
| 8 | 财政与经济总览仍是两个面板 | 0.19.0 的按钮未真正移除 | 已删除「财政」按钮，仅保留经济总览 |
| 9 | 均衡价算出负数 | 库存比例未 clamp（200/40=5） | clamp 到 [0,1]，当前价用均衡价 × 漂移 |
| 10 | 关税只是文案 | 未接入扣费 | 非母港卖出扣 5% 并记入财务支出 |
