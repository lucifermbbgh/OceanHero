## 1. 现状问题

| 问题 | 说明 |
|---|---|
| 岛屿与母港两套界面 | 岛屿是堆叠式侧栏，母港是全屏面板 |

## 2. 1.2.2 方案：港口上下文

### 2.1 动态港口标识

| 项 | 说明 |
|---|---|
| 新增 | GameState.visit_port_id（当前访问的港口，默认母港 jadehaven） |
| 替换 | base_scene 的常量 PORT_ID 全部改为读取 visit_port_id |
| 默认 | 从主菜单/存档进入时为母港 |

### 2.2 停泊 → 城镇场景

    海面按 E 停泊
        → GameState.visit_port_id = 该岛 key
        → SceneRouter.goto(base)（城镇界面）
        → 城镇界面左上角显示「望潮港镇（港镇）」
        → 点「离港」→ SceneRouter.goto(sea)

### 2.3 母港行为不变

| 项 | 保证 |
|---|---|
| 母港入口 | 仍从主菜单/返港进入，visit_port_id = jadehaven |
| 建造 | 母港保留 |
| 经济总览 | 母港可见 |

## 3. 1.2.3 预告
