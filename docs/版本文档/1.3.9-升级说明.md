# 1.3.9 升级说明（私掠证重做）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.3.8 |
| 目标版本 | **1.3.9** |
| 状态 | 已发布（2026-11-20） |
| 功能组 | 私掠证按国家发证、四档结算、黑市买卖 |

## 1. 发证规则

| 项 | 规则 |
|---|---|
| 正规途径 | 该国声望 ≥ 51 + 金币 6000 |
| 黑市途径 | 任意国家，价格 ×2.5，通缉度 +5 |
| 数量 | 全游戏仅一张 |
| 幽溟 | **不发私掠证** |

## 2. 结算规则（持 A 证）

| 目标 | 目标势力 | 持证国 A |
|---|---|---|
| A 的敌国 | −L | **+L** |
| A 的中立国 | −L | **不扣** |
| A 的盟国 | −L | **−L/2** |
| A 本国 | −2L | — |

## 3. 交易

| 渠道 | 操作 |
|---|---|
| 正规 | 势力声望面板「购买」（按页签国家） |
| 黑市 | 「黑市购买」弹出国家选择 |
| 出售 | 黑市「出售（返还 30%）」，持证国声望 −5 |

## 4. 顺带修复

| 问题 | 说明 |
|---|---|
| 势力关系 id 失配 | `yunlan` 与旧表 `lan` 不同，导致持证国加成恒为 0；新增 `FACTION_TO_NATION` 映射 |
