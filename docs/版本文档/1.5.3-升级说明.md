# 1.5.3 升级说明（世界地图面板）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.5.2 |
| 目标版本 | **1.5.3** |
| 状态 | 已发布（2026-11-21） |
| 单一功能 | 只读世界地图面板（迷雾 + M/Esc 开关） |

## 1. 面板

| 项 | 内容 |
|---|---|
| 尺寸 | 1568×812，居中 |
| 入口 | 海面按 M 打开/关闭；Esc 关闭 |
| 画布 | 30 节点 + 已探索之间的连线 |
| 已探索 | 势力色圆点 + 「级-列」编号 |
| 未探索 | 灰点 +「?」，不显示任何信息 |
| 当前 | 金色圆环 |
| 底部 | 已探索 X/30、当前海域编号、图例 |

## 2. 技术要点

| 项 | 说明 |
|---|---|
| 挂载 | 独立 CanvasLayer（layer 12），不受相机变换影响 |
| 绘制 | Control._draw 纯代码绘制 |
| 只读 | 无传送、无导航、无点击交互 |

## 3. 验收

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 面板 1568×812 | ✅ |
| 2 | 默认隐藏，M 可开关 | ✅ |
| 3 | 已探索显示势力色与编号 | ✅ |
| 4 | 未探索仅显示灰点「?」 | ✅ |
| 5 | 当前海域金色圆环 | ✅ |

## 4. 遗留

| 项 | 说明 |
|---|---|
| 连线较密 | 跨级连线全画，后续可改「同级三角 + 走廊」 |
| 无点击详情 | 按只读要求暂不实现 |
