# 1.6.13 升级说明（海图母版接入游戏）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.6.12 |
| 目标版本 | **1.6.13** |
| 状态 | 已发布（2026-11-26） |
| 单一功能 | 世界地图与小地图改用 AI 海图母版 |

## 1. 世界地图

| 项 | 之前 | 现在 |
|---|---|---|
| 底图 | 程序噪声海 + 矢量陆地 | AI 海图母版 chart_base_game.png |
| 未探索 | 深色块 + ? | 迷雾遮罩（半透明黑覆盖艺术底图） |
| 已探索 | 势力色块 | 艺术底图 + 细边界 + 琥珀节点 |
| 命中 | 多边形 | 陆地掩膜像素判定 land_mask_game.png |
| 对齐 | — | 底图与区域同一变换，铺满画布 |

## 2. 小地图

| 项 | 之前 | 现在 |
|---|---|---|
| 底 | 纯色 | 世界海图开阔海面裁剪（艺术纹理） |
| 岛屿 | 灰圆 | 沙色圆 + 深边 + 琥珀港口点 |
| 玩家 | 黄三角 | 不变 |

## 3. 数据与资源

| 文件 | 用途 |
|---|---|
| art/world_map/chart_base_game.png | 游戏内底图（1024×576） |
| art/world_map/land_mask_game.png | 陆地命中掩膜 |
| art/world_map/master_chart_v3.png | 设计母版（2048×1152） |
| data/generated/region_islands.json | 每海域岛屿（预留海面场景一致化） |

## 4. 性能

| 项 | 处理 |
|---|---|
| 纹理缓存 | world_map / mini_map 静态缓存，避免重复解码 |
| 分辨率 | 游戏内用 1024 版本，母版保留 2048 |
