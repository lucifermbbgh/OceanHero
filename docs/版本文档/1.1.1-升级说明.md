# 1.1.1 升级说明（界面入口补齐）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.1.0 |
| 目标版本 | **1.1.1** |
| 状态 | 已发布（2026-11-18） |
| 主题 | 把 1.1.0 已实现但无入口的功能接到界面上 |

## 1. 背景

1.1.0 完成了船员职级、装备强化/合成、船只改装、生产产出等**逻辑层**，
但玩家在界面上找不到入口。本版补齐界面。

## 2. 新增面板（均全屏）

### 2.1 船员名单

    姓名      角色     稀有度   职级    经验   属性
    张三      炮手     2       舵手    120    7

| 列 | 说明 |
|---|---|
| 职级 | 水手 / 舵手 / 炮长 / 大副（经验 100 / 300 / 600 升级） |
| 经验 | 参战累计 |

### 2.2 装备强化与合成

    装备        部位    稀有度   强化   操作
    精铁护甲     armor   2        +1     [强化] [合成]

| 操作 | 规则 |
|---|---|
| 强化 | 三级，消耗金币与铁矿（2/4/8） |
| 合成 | 同部位同稀有度 3 件 → 1 件高一级 |

### 2.3 船只改装

    改装项    等级   当前加成      下一级花费   操作
    帆具      1      +6% 航速      15000       [改装]
    火炮位    0      +0 可装炮     8000        [改装]
