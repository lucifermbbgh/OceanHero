# 1.6.21 升级说明（舰船立绘 17 + 变体图标 51）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.6.20 |
| 目标版本 | **1.6.21** |
| 状态 | 已发布（2026-11-28） |
| 单一功能 | 17 艘基准船立绘 + 51 张变体图标，接入船厂与舰船面板 |

## 1. 生产

| 项 | 内容 |
|---|---|
| 模型 | DreamShaper 8（工作流 `39fcfc2b`），768×512，26 步，串行逐张 |
| 提示词骨架 | `painterly game ship portrait, <船型描述>, sailing on calm green-blue sea, dramatic cloudy sky, side view, centered, oil painting` |
| 负面 | text / watermark / picture frame / ornate frame / border / banner / grid / collage / multiple views / logo |
| 产物 | `art/icons/ship/` 68 张（384×256）：17 基准 + 51 变体 |
| 源图 | `art/source/ship_<id>.png`（768×512） |
| 变体派生 | 海军型冷蓝调 + 蓝框；海盗型暖红调 + 红框；标准型为基准立绘复制 |
| 工具 | `tools/map_pipeline/process_ship_icons.py` |
| 联系表 | `art/icons/ship/_contact.png` |

船型：单桅渔船、平底沙船、维京长船、双桅纵帆船、双桅横帆船、六级舰、五级护卫舰、
四级战列舰、三级战列舰、一级战列舰，以及 7 艘专属船（白鲸鲸骨船、苍梧猎帆船、赤鳞商船、
霜屿破冰舰、玄礁夜帆、幽溟鬼船、云澜快帆）。

## 2. 接入

| 页面 | 表现 |
|---|---|
| 船厂头部 | 96×64 当前船立绘，与属性同行 |
| 船厂「本港船队」 | 60×40 变体立绘 |
| 船厂「可购买船只」 | 60×40 变体立绘（海军偏蓝、海盗偏红） |
| 舰船面板 | 144×96 立绘置于属性栏顶部 |

新增 `_ship_icon_rect(sid, h)`：按 3:2 横幅加载 `art/icons/ship/<sid>.png`，
sid 直接使用基准或变体 id（与 DataRegistry.ships 键一致）。

## 3. 顺带修复

| 问题 | 修复 |
|---|---|
| 1.6.17 起 `_icon_rect_path` 未设 `expand_mode`，128px 图标按原始尺寸撑满行（市场/装备库/火炮列表行高 128px、图标溢出） | 设 `EXPAND_IGNORE_SIZE`，所有图标按 26~28px 显示，行高恢复紧凑 |

## 5. 备注

- 单桅渔船、维京长船、白鲸鲸骨船的出图仍偏"通用帆船"，后续可单独重出。
- 变体之间的差异靠色调与边框表达，船体细节相同；若要船体差异化，需要每变体单独出图（生成量 ×3）。
