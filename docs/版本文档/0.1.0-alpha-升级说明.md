| 项 | 内容 |

| 测试 | 65 单元 + 240 集成 |

## 1. 背景

从零搭建可玩的垂直切片。目标是让「航行 → 战斗 → 掠夺 → 贸易 → 建设 → 推进」这条闭环能从头跑到尾。

## 2. 需求与实现

- 世界：9 张递进海域 + 母港，双航门关卡推进
- 战斗：四池损伤（船体/帆/舵/船员）、3 种弹药、接舷俘获
- 敌人：海盗、海怪、18 个三阶段 Boss、海军赏金猎人
- 舰船：I~X 共 10 级 × 3 变体（通用/海军/海盗）
- 装备：5 部位 20 件（含 9 件 Boss 独有）、火炮 10 级
- 船员：10 岗位、5 稀有度、酒馆招募、上阵加成
- 经济：金币 + 战功双货币、港口行情、交易所四标签
- 母港：8 座建筑 5 级、周产出、建造队列
- 任务：5 类（讨伐/贸易/运输/护航/采集）
- 其他：流动时间与周结算、5+1 存档位、通关结算、帮助面板

## 3. 验收结果

- 自动化测试全部通过
- 数值两轮调整：修复「修理费远超收益」与「后期需 13,158 次出海才能升一级」两个结构性问题
- 产出 macOS / Windows 可运行包

## 4. 影响范围

`scripts/（36 个脚本）、data/（88 张 .tres）`
