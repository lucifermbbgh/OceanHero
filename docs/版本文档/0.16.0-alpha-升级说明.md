## 1. 需求

同一件货，对不同玩家卖不同价——这是三级差别定价（市场分割）。
本作用**声望**做分割依据：声望越高，买价越低。

| 声望档（最高阵营） | 买价折扣 | 玩家说法 |
|---|---|---|
| 0 ~ 999 | 0% | 陌生人 |
| 1,000 ~ 2,999 | 2% | 熟客 |
| 3,000 ~ 5,999 | 4% | 老主顾 |
| 6,000 ~ 10,000 | 6% | 自家人 |

**只作用于买入**，卖出不受影响（避免与已有的卖出加成叠加）。

## 2. 界面

- 市场底部指标行：`声望折扣：4%（老主顾）`
- 价格明细里加一行 `声望折扣 -6`
