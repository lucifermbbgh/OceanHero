# 1.4.7 升级说明（舰船面板修正）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.4.6 |
| 目标版本 | **1.4.7** |
| 状态 | 已发布（2026-11-20） |
| 功能组 | 模块按船级开放、船影绘制、旗杆白名单、锚点对齐 |

## 1. 问题与修复

| # | 问题 | 修复 |
|---|---|---|
| 1 | 单桅渔船也显示 15 个插槽 | 模块按船级开放：1 级仅 **6 个** |
| 2 | 色块与插槽错位 | 新增 `ship_silhouette.gd` 纯代码绘制船影，插槽锚点与船影同一坐标系 |
| 3 | 旗杆可装旧独有旗 | 新增 `SLOT_ALLOWED` 白名单，旗杆只允许 4 面设计内旗帜 |
| 4 | 船模看不出是船 | 绘制船体轮廓、船艏斜桅、甲板线、桅杆与帆；船级决定 1/2/3 桅 |

## 2. 船级与模块

| 船级 | 模块数 | 说明 |
|---|---|---|
| 1~2 | 6 | 帆/舵/仓/宿/厨/炮门 |
| 3~4 | 9~10 | +瞭望台/船长室/甲板 |
| 5~6 | 12~13 | +工坊/医疗室 |
| 7~8 | 14~15 | +旗杆、更多炮门层 |
| 9~10 | 15+ | 满层甲板与炮门 |

## 3. 船影

| 项 | 规则 |
|---|---|
| 桅杆数 | 1~2 级 1 桅、3~4 级 2 桅、5 级以上 3 桅 |
| 绘制内容 | 船体轮廓、船艏斜桅、甲板线、桅杆、帆 |
| 插槽 | 读取 `ModuleDef.anchor`，与船影同一 0~1 坐标系 |

## 4. 验收

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 1 级船 6 个模块、无旗杆 | ✅ |
| 2 | 10 级船 ≥15 模块、3 层甲板 | ✅ |
| 3 | 旗帜白名单过滤旧旗 | ✅ |
| 4 | 所有锚点位于船影内 | ✅ |

**测试**：66 单元 + 995 集成
