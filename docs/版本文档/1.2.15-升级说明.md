# 1.2.15 升级说明（银行面板原地更新）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.2.14 |
| 目标版本 | **1.2.15** |
| 状态 | 已发布（2026-11-18） |
| 单一功能点 | 银行面板数字原地刷新，不再整块重建 |

## 1. 方案 A

| 区域 | 方式 |
|---|---|
| 现金 / 存款 / 未还贷款摘要 | **只改 Label.text**，控件常驻 |
| 存款与取出按钮 | 常驻，仅更新 disabled |
| 贷款列表 / 新增贷款档位 | 条目数会变，仍重建 |

## 2. 结构

    _rebuild_bank_rows()
      ├ 首次：_build_bank_skeleton()（建骨架，存 Label 引用）
      ├ 每次：_refresh_bank_numbers()（只改文字）
      └ 每次：_rebuild_bank_body()（只重建动态列表）

## 3. 效果

| 项 | 之前 | 现在 |
|---|---|---|
| 点击存款 | 整树重建，可能闪烁 | 两个数字就地变化 |
| 控件引用 | 全部重建 | 骨架常驻，焦点不丢 |
| 叠加 bug | 曾出现 | 结构上不可能再出现 |

## 4. 验收

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 连续 3 次存款后骨架行数不变 | ✅ |
| 2 | 存款数字实时变为 3000 | ✅ |
| 3 | 现金标签存在且随操作更新 | ✅ |

**测试**：66 单元 + 729 集成
