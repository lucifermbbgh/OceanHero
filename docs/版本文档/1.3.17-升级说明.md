# 1.3.17 升级说明（兑换交互与声望条打磨）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.3.16 |
| 目标版本 | **1.3.17** |
| 状态 | 已发布（2026-11-20） |
| 功能组 | 声望不足时禁止确认、失败原因弹窗、声望条着色 |

## 1. 兑换交互修正

| 项 | 之前 | 现在 |
|---|---|---|
| 声望不足的物品 | 可点开、可直接确认、只写底部日志 | 弹窗可查看详情，**确认按钮禁用**，并显示「声望不足，无法兑换」 |
| 确认失败 | 只在底部滚动条提示 | **弹窗提示**「兑换失败 + 原因」，确定 / ESC 关闭 |

提示弹窗实现：`AcceptDialog`，标题「兑换失败」，正文为具体原因（声望不足 / 金币不足 / 物品不在列表）。

## 2. 声望条着色

| 数值 | 颜色 |
|---|---|
| 正 | 绿 |
| 负 | 红 |
| 0 | 灰 |

作用于总览页 7 条与单势力页 1 条。
