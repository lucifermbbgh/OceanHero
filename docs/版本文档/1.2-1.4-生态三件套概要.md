# 生态三件套概要（1.2.0 / 1.3.0 / 1.4.0）

| 项 | 内容 |
|---|---|
| 归属 | 1.x 大版本后半程 |
| 调整说明 | 1.1/1.2/1.3 合并为 1.1.0 一次交付，生态三件套整体前移到 1.2 / 1.3 / 1.4 |
| 原因 | 生态设计复杂度高，需先有多国与贸易数据积累 |
| 状态 | 概要设计（详细规格待各自版本启动时编写） |

## 1. 1.2.0 多国海军与外交

### 1.1 六国

| 国家 | 定位 | 特征 |
|---|---|---|
| 澜国 | 海军强国 | 火力与装甲最硬，声望门槛最高 |
| 赤鳞 | 商会联邦 | 贸易最发达，收购价最好 |
| 霜屿 | 北方岛国 | 耐寒船体，船员耐久高 |
| 玄礁 | 海盗诸岛 | 松散联盟，黑市繁荣，通缉风险低 |
| 白鲸 | 渔业邦联 | 谷物木材产出高，物价低 |
| 苍梧 | 新兴王国 | 均衡，对各阵营开放 |

### 1.2 机制

| 项 | 规则 |
|---|---|
| 声望 | 各国独立 0~10000，当前单一海军声望按最高者映射 |
| 私掠证 | 绑定具体国家；持 A 国证劫掠 B 国合法，劫掠 A 国视为叛国 |
| 外交关系 | 同盟 / 中立 / 敌对 |
| 关税 | 按两国关系与声望档位浮动，替换 1.1.0 的三阵营分档 |
| 赏金猎人 | 来源国按通缉度决定 |

### 1.3 验收要点

| # | 验收点 |
|---|---|
| 1 | 六国声望独立可查 |
| 2 | 私掠证绑定国家，跨国劫掠判定正确 |
| 3 | 盟国商船不可劫掠，敌对国商船可劫掠 |
| 4 | 关税按关系浮动 |
| 5 | 声望面板显示六国关系 |

## 2. 1.3.0 NPC 居民与真实需求

### 2.1 居民

| 项 | 内容 |
|---|---|
| 人口 | 按城镇等级：港村 200 / 港镇 800 / 港城 3000 |
| 职业 | 渔民 / 工匠 / 商人 / 官吏（比例按等级） |
| 收入 | 按职业与城镇等级决定周收入 |

### 2.2 需求

| 项 | 规则 |
|---|---|
| 消费量 | 人口 × 品类人均消费量 |
| 价格响应 | 价格高则消费降低（弹性由居民收入决定） |
| 需求曲线 | 由实际消费数据拟合，替代 0.19.4 时代的虚构曲线 |
| 收入弹性 | 有收入变量后可计算 |

### 2.3 验收要点

| # | 验收点 |
|---|---|
| 1 | 每港有居民人口与职业构成 |
| 2 | 居民按周消费商品，消耗港口库存 |
| 3 | 价格随消费量变化 |
| 4 | 需求曲线来自实测数据 |
| 5 | 收入弹性可计算并展示 |

## 3. 1.4.0 生态整合

### 3.1 闭环

| 环节 | 内容 |
|---|---|
| 生产 | 种植园 / 工坊 / 矿场产出入库 |
| 贸易 | 生产端供给影响价格 |
| 消费 | 居民消费消化库存 |
| 传导 | 生产冲击沿贸易路线传播到消费端 |

### 3.2 可用的分析工具

| 指标 | 数据来源 |
|---|---|
| 规模经济曲线（LAC） | 连续产量数据 |
| 收入弹性 | 居民收入与消费 |
| 交叉弹性实测 | 关联商品价格与消费量 |

### 3.3 验收要点

| # | 验收点 |
|---|---|
| 1 | 生产设施产出改变港口供给 |
| 2 | 价格随供给与消费双向变化 |
| 3 | 冲击可沿贸易路线传导 |
| 4 | 规模经济曲线可由数据绘制 |
