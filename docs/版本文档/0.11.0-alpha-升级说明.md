# 0.11.0-alpha 升级说明

| 项 | 内容 |
|---|---|
| 基线版本 | 0.10.0-alpha |
| 目标版本 | 0.11.0-alpha |
| 状态 | 待确认 |
| 主题 | 黑市：销赃、违禁品、稀有货与黑帆委托 |

## 1. 背景

当前的通缉度只有负面作用（被海军追杀），玩家一旦被通缉，正规港口的高价卖货渠道等于断了，
「当海盗」这条路线走不通。原作的黑市正是为此存在：**给灰色路线一条经济出口**。

## 2. 原作的黑市在做什么（参考）

| 原作功能 | 说明 |
|---|---|
| 销赃 | 抢夺来的货物在正规港口被拒收或压价，黑市照收 |
| 违禁品 | 伪造旗帜、私掠许可证、特殊弹药等正规渠道买不到的东西 |
| 稀有货 | 不定期刷出稀有装备与船员，价格波动大 |
| 海盗委托 | 接黑帆的劫掠任务，换取海盗阵营的声望与报酬 |

## 3. 我们的黑市设计

### 3.1 定位

| 项 | 内容 |
|---|---|
| 一句话 | **销赃与违禁渠道**，让被通缉的玩家仍有经济出路 |
| 与拍卖行区别 | 拍卖行是高端**合法**市场；黑市是灰色渠道，无竞价、价格差、有风险 |
| 阵营关联 | 黑帆同盟的专属经济入口 |

### 3.2 入口与准入

| 项 | 规则 |
|---|---|
| 位置 | 每张图 1 处，位于「黑帆巢穴」（固定为某座岛，标记为黑市） |
| 准入条件 | 通缉度 ≥ 20 **或** 黑帆声望 ≥ 1000 |
| 拒绝条件 | 海军声望 ≥ 3000（正人君子不给进） |
| 界面 | 与港口面板同构，但配色偏暗，标题显示「黑市」 |

### 3.3 四个功能

**1) 销赃**

| 项 | 规则 |
|---|---|
| 收购价 | 合法市场价的 **60%** |
| 优势 | **不受通缉度惩罚**，正规港口此时可能拒收 |
| 上限 | 每次卖出不超过 200 单位（黑市吞吐有限） |

**2) 违禁品商店**

| 商品 | 效果 |
|---|---|
| 私掠许可证 | 劫掠商船不再降低商会声望（一次有效） |
| 伪造旗帜 | 下一场战斗中敌方索敌半径 −50% |
| 重型火药 | 下一场战斗首轮齐射伤害 +50% |
| 麻醉剂 | 接舷战成功率提升（船员伤害 +30%，一次有效） |

**3) 稀有货**

| 项 | 规则 |
|---|---|
| 刷新 | 每周 1~2 件 |
| 内容 | SR 以上装备 / SSR 以上船员 |
| 价格 | 拍卖行起拍价的 **1.5~2.5 倍**（贵，但不用竞价，先到先得） |

**4) 黑帆委托**

| 项 | 规则 |
|---|---|
| 类型 | 劫掠指定商船 / 击沉海军巡逻 / 运送走私货 |
| 奖励 | 金币 + 黑帆声望，**不扣海军声望**（隐秘行动） |
| 频率 | 每周 2~3 个 |

### 3.4 代价与风险

| 项 | 规则 |
|---|---|
| 通缉度 | 每次交易 **+2** |
| 海军声望 | 每月 **−50** |
| 投资 | 黑市交易**不计入**城市投资额 |
| 曝光 | 通缉度 ≥ 80 时黑市临时关闭一周（被海军盯上） |

### 3.5 经济定位（对应经济学参考文档）

| 现象 | 理论 | 参考章节 |
|---|---|---|
| 同一商品在合法市场与黑市价格不同 | 市场分割 / 价格歧视 | 第七章 市场结构和企业行为 |
| 正规渠道受阻时的替代交易 | 市场失灵与替代机制 | 第十章 政府的经济作用 |
| 黑市收购价低于市场价 | 风险溢价与交易成本 | 第六章 成本理论 |

## 4. 验收标准

| # | 验收点 |
|---|---|
| 1 | 仅有 1 处黑市，位于固定的黑帆巢穴 |
| 2 | 通缉度 < 20 且黑帆声望 < 1000 时无法进入 |
| 3 | 海军声望 ≥ 3000 时拒绝进入 |
| 4 | 销赃价为合法市场价 60%，且不受通缉惩罚 |
| 5 | 单次销赃不超过 200 单位 |
| 6 | 违禁品可购买，效果持续到下场地战斗结算 |
| 7 | 稀有货每周刷新 1~2 件 |
| 8 | 黑帆委托完成后加黑帆声望、不扣海军声望 |
| 9 | 每次黑市交易通缉度 +2 |
| 10 | 通缉度 ≥ 80 时黑市关闭并提示 |
| 11 | 黑市交易不计入城市投资额 |

## 5. 不做

- 不做竞拍威慑（拍卖行已确认不做）
- 不做玩家间交易
- 不做动态违禁品价格
