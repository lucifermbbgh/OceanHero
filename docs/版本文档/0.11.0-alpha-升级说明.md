# 0.11.0-alpha 升级说明

| 项 | 内容 |
|---|---|
| 基线版本 | 0.10.0-alpha |
| 目标版本 | 0.11.0-alpha |
| 状态 | 待确认 |
| 主题 | 黑市：销赃、违禁品、私掠许可证 |

## 1. 背景

当前通缉度只有负面作用（被海军追杀），玩家一旦被通缉，正规港口压价甚至拒收，
「当海盗」这条路线等于自断财路。黑市就是为了给灰色玩法一条经济出口。

## 2. 设计说明（重要）

> 上一版文档把黑市写成《海战英豪》原作内容，那是**推断而非查证**，已更正。
> 本作黑市是**同类玩法通用做法 + 本作自有设计**，规则以本节为准。

## 3. 定位

| 项 | 内容 |
|---|---|
| 一句话 | **独立的地下市场**，买卖正规渠道拿不到或卖不掉的东西 |
| 位置 | **每个城市的港口都有**（村落与乡镇没有） |
| 阵营 | **不与海盗阵营绑定**，谁都能来，只要找得到门路 |
| 与拍卖行区别 | 拍卖行是公开的高端合法市场；黑市是私下的灰色渠道 |

## 4. 三大功能

### 4.1 销赃（主要用途）

| 项 | 规则 |
|---|---|
| 可卖 | 劫掠所得商品、正规渠道不收购的违禁品 |
| 收购价 | 合法市场价 × 0.6（量大可议到 0.75） |
| 为什么需要 | 通缉状态下正规港口压价甚至拒收，黑市是唯一出货口 |
| 上限 | 单次 ≤ 200 单位 |

### 4.2 违禁品

| 类别 | 例子 | 来源 |
|---|---|---|
| 军用品 | **海军专属高级装备**（非海军身份无法正规获得） | 击沉海军舰船缴获 |
| 违禁药物 | 兴奋剂类，提升船员状态但有副作用 | 黑市购入 |
| 伪造品 | 伪造旗帜、伪造通行证 | 黑市购入 |

### 4.3 私掠许可证

| 获取途径 | 条件 | 效果 | 代价 |
|---|---|---|---|
| **正规途径（声望交易）** | 海军声望达到阈值 | 攻击海军敌对阵营商船不降海军声望 | 价格正常 |
| **黑市途径** | 无声望要求 | 同上，灰色持有 | 价格 2~3 倍，通缉度 +5 |

## 5. 风险

| 项 | 规则 |
|---|---|
| 通缉度 | 每次交易 +2 |
| 曝光 | 通缉度 ≥ 80 时黑市关闭一周 |
| 投资 | 黑市交易不计入城市投资额 |

## 6. 未来扩展（本版不做）

**海军拆分为多个国家的海军**

| 项 | 内容 |
|---|---|
| 拆分 | 皇家海军 / 法兰西海军 / 西班牙海军等多个国家海军 |
| 声望 | 每个国家海军独立声望，当前单一「海军声望」按最高者映射 |
| 私掠许可证 | 绑定具体国家；持英国证劫掠法国商船合法，劫掠英国商船视为叛国 |
| 影响 | 声望面板、赏金猎人来源、私掠合法性判定 |

> 该拆分登记在版本规划的未来条目中。

## 7. 验收标准

| # | 验收点 |
|---|---|
| 1 | 每座城市港口都有黑市入口，村落与乡镇没有 |
| 2 | 黑市不要求任何阵营声望即可进入 |
| 3 | 销赃价为合法市场价 60%，且不受通缉惩罚 |
| 4 | 单次销赃不超过 200 单位 |
| 5 | 可出售缴获的海军专属装备与违禁品 |
| 6 | 声望达标的玩家可在声望交易买到正规私掠许可证 |
| 7 | 黑市可用 2~3 倍价格买到私掠许可证，并附带通缉度 +5 |
| 8 | 持私掠许可证攻击海军敌对阵营商船不降海军声望 |
| 9 | 每次黑市交易通缉度 +2 |
| 10 | 通缉度 ≥ 80 时黑市关闭并提示 |
| 11 | 黑市交易不计入城市投资额 |

## 8. 不做

- 不做多国海军拆分（未来版本）
- 不做玩家间交易
- 不做竞拍机制（黑市是一口价）
