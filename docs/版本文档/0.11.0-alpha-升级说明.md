# 0.11.0-alpha 升级说明

| 项 | 内容 |
|---|---|
| 基线版本 | 0.10.0-alpha |
| 目标版本 | 0.11.0-alpha |
| 状态 | 已发布（2026-11-17） |
| 主题 | 黑市：销赃、违禁品、私掠许可证 |

## 1. 背景

当前通缉度只有负面作用（被海军追杀），玩家一旦被通缉，正规港口压价甚至拒收，
「当海盗」这条路线等于自断财路。黑市就是为了给灰色玩法一条经济出口。

## 2. 设计说明（重要）

> 上一版文档把黑市写成《海战英豪》原作内容，那是**推断而非查证**，已更正。
> 本作黑市是**同类玩法通用做法 + 本作自有设计**，规则以本节为准。

### 2.1 已查证的原作资料（SeaFight）

| 来源 | 内容 |
|---|---|
| 官方论坛 ES「PNJ Contrabandista」 | **走私犯（Contrabandista）是驻在「安全港口」的 NPC，只有玩家被标记为「亡命之徒（forajido）」时才会激活**；出售多种特殊装备（如「闪电炮」），存货按 **24~72 小时**周期补充 |
| 官方论坛 ES「Sistema de Licencias」 | 赏金猎人服有**许可证制度**：无有效许可证进行 PvP 会变成亡命之徒；许可证是**消耗品**，限时生效，可从港口的许可证商人处购买，分区域版与通用版 |

**对设计的启示**

1. 原作黑市 = **有条件的走私 NPC**（门槛是「被通缉」），不是独立建筑
2. 允许交易**正规渠道买不到的特殊装备**
3. **周期性补货**，不是永久货架
4. 原作的「许可证」与我们设想的私掠许可证高度对应，但原作是**PvP 合法性凭证 + 限时消耗品**

**我们的取舍**

| 原作做法 | 我们的做法 | 原因 |
|---|---|---|
| 仅有通缉时才激活 | 每个城市常驻，但**销赃**是主要用途 | 单机没有 PvP，通缉门槛会让黑市大部分时间不可用 |
| 消耗品式限时许可证 | 一次性购买、长期有效的私掠证 | 单机不需要按小时计费 |
| 周期性补货的特殊装备 | 保留（每周刷新） | 与拍卖行形成节奏差异 |

## 3. 定位

| 项 | 内容 |
|---|---|
| 一句话 | **独立的地下市场**，买卖正规渠道拿不到或卖不掉的东西 |
| 位置 | **每个城市的港口都有**（村落与乡镇没有） |
| 阵营 | **不与海盗阵营绑定**，谁都能来，只要找得到门路 |
| 与拍卖行区别 | 拍卖行是公开的高端合法市场；黑市是私下的灰色渠道 |

## 4. 三大功能

### 4.1 销赃（主要用途）

| 项 | 规则 |
|---|---|
| 可卖 | 劫掠所得商品、正规渠道不收购的违禁品 |
| 收购价 | 合法市场价 × 0.6（量大可议到 0.75） |
| 为什么需要 | 通缉状态下正规港口压价甚至拒收，黑市是唯一出货口 |
| 上限 | 单次 ≤ 200 单位 |

### 4.2 违禁品

| 类别 | 例子 | 来源 |
|---|---|---|
| 军用品 | **海军专属高级装备**（非海军身份无法正规获得） | 击沉海军舰船缴获 |
| 违禁药物 | 兴奋剂类，提升船员状态但有副作用 | 黑市购入 |
| 伪造品 | 伪造旗帜、伪造通行证 | 黑市购入 |

### 4.3 私掠许可证

| 获取途径 | 条件 | 效果 | 代价 |
|---|---|---|---|
| **正规途径（声望交易）** | 海军声望达到阈值 | 攻击海军敌对阵营商船不降海军声望 | 价格正常 |
| **黑市途径** | 无声望要求 | 同上，灰色持有 | 价格 2~3 倍，通缉度 +5 |

## 5. 风险

| 项 | 规则 |
|---|---|
| 通缉度 | 每次交易 +2 |
| 曝光 | 通缉度 ≥ 80 时黑市关闭一周 |
| 投资 | 黑市交易不计入城市投资额 |

## 6. 未来扩展（本版不做）

**海军拆分为多个国家的海军**

| 项 | 内容 |
|---|---|
| 拆分 | 皇家海军 / 法兰西海军 / 西班牙海军等多个国家海军 |
| 声望 | 每个国家海军独立声望，当前单一「海军声望」按最高者映射 |
| 私掠许可证 | 绑定具体国家；持英国证劫掠法国商船合法，劫掠英国商船视为叛国 |
| 影响 | 声望面板、赏金猎人来源、私掠合法性判定 |

> 该拆分登记在版本规划的未来条目中。

| 3 | 销赃价为合法市场价 60%，且不受通缉惩罚 |

### 实现说明

- 违禁品表在 `GameState.CONTRABAND`（4 种）：违禁药物 / 伪造旗帜 / 伪造通行证 / 海军制式火炮
- 销赃、买违禁品、买私掠证三个动作统一调用 `_black_mark_activity()`（通缉度 +2）
- 私掠证区分 `license_is_legal`：正规途径不涨通缉度，黑市途径 +5
- `tick_auctions(npc_bid_enabled)` 增加参数，便于测试中关闭 NPC 竞价
- 黑市状态（违禁品库存、私掠证、关闭周）全部进存档
