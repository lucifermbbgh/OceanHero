# 0.13.2 升级说明（涨跌配色修正）

| 项 | 内容 |
|---|---|
| 基线版本 | 0.13.1 |
| 目标版本 | 0.13.2 |
| 状态 | 已发布（2026-11-17） |
| 主题 | 周涨跌颜色对调：涨红跌绿 |

## 1. 背景

0.13.1 的周涨跌列沿用「涨绿跌红」的西式习惯，与国内玩家看行情盘面的直觉相反。
按需求改为**涨红跌绿**（与中式行情一致）。

## 2. 变更

| 状态 | 颜色 | 色值 |
|---|---|---|
| 上涨 | **红色** | RGB(0.92, 0.45, 0.42) |
| 下跌 | **绿色** | RGB(0.45, 0.85, 0.55) |
| 持平 / 无数据 | 灰色 | 不变 |

## 3. 验收

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 上涨显示红色 | ✅ |
| 2 | 下跌显示绿色 | ✅ |
| 3 | 持平与「—」仍为灰色 | ✅ |
| 4 | 其余功能不受影响 | ✅ 501 集成全过 |
