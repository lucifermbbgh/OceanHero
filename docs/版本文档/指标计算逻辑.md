# 指标计算逻辑手册

> 记录经济系统每个指标**怎么算、属于什么类型、参数在哪**。
> 玩家界面上看到的所有数字，都能在这里找到来源。

## 1. 弹性（Elasticity）

### 1.1 供给价格弹性（已实现 · 0.13）

**公式**

    库存比例 ratio = 当前库存 / 满值
    弹性系数 e   = piecewise_elasticity(ratio)
    公式价       = 基础价 × (1 + e × (1 − ratio))

**分段规则（piecewise_elasticity）**

| 库存比例 | e | 含义 |
|---|---|---|
| > 70% | **0.35** | 货多，价格对库存不敏感 |
| 30% ~ 70% | **0.55** | 中间区 |
| < 30% | **0.90** | 缺货，价格陡涨 |

**弹性类型判定**

| e 范围 | 类型 | 玩家说法 |
|---|---|---|
| e ≥ 0.70 | **富有弹性** | 库存一变，价格剧烈波动 |
| 0.40 ≤ e < 0.70 | **单位弹性附近** | 库存与价格大致同幅变化 |
| e < 0.40 | **缺乏弹性** | 库存再多再少，价格都很稳 |

**算例**：谷物基础价 10，库存 190/400

    ratio = 190/400 = 0.475 → 中间区 → e = 0.55
    公式价 = 10 × (1 + 0.55 × 0.525) = 12.89
    买价   = 12.89 × 1.05 = 13.53 → 取整 14

（与游戏内实际显示一致）

### 1.2 交叉弹性（0.14 规划）

    商品 A 涨价 → 商品 B 需求变化
    ΔB = A 的价格变动率 × 交叉系数

| 关系 | 系数符号 | 含义 |
|---|---|---|
| 替代品 | 正 | A 贵了，买 B 的人变多 |
| 互补品 | 负 | A 贵了，B 也跟着少 |

## 2. 供需（Supply & Demand）

| 指标 | 公式 | 当前来源 |
|---|---|---|
| 需求量 | 本港该商品周消耗 | PortDef.demand |
| 供给量 | 周产出 + 库存 | PortDef.production + stock |
| 库存比例 | stock / max_stock | 实时 |
| 缺口率 | 1 − 库存比例 | 实时 |
| 均衡价 | 基础价 × (1 + e × (1 − ratio)) | 公式价 |
| 偏离度 | 当前价 / 均衡价 − 1 | 漂移倍率 − 1 |

### 2.1 市场漂移（已实现 · 0.13）

每周计算一次：

    目标值 target = 事件倍率（无事件为 1.0）
    漂移 = mean_revert(当前, target, 25%) + 噪声
    噪声 = seeded_noise(港口 + 商品 + 周, ±3%)
    漂移 = clamp(漂移, 0.85, 1.15)

| 参数 | 值 |
|---|---|
| 回归速度 | 25%/周 |
| 噪声幅度 | ±3% |
| 单周上限 | ±15% |
| 漂移区间 | 0.85 ~ 1.15 |

## 3. 边际（Marginal · 0.14）

| 指标 | 公式 | 说明 |
|---|---|---|
| 边际成本 MC | 当前买价 | 整单同一价模型下 = 显示价 |
| 边际收益 MR | 目标港卖价 | 卖出一件的所得 |
| 边际利润 MP | MR − MC | 再买一件的净收益 |
| 边际效用 | diminishing_return(已投资, 上限) | 投资多一份的折扣增量 |

**含容量余量的算法**

    可用容量 = 货舱上限 − 当前载货
    可买数量 = min(可用容量 / 单位体积, 该港库存)
    逐件累加 MP，直到 MP ≤ 0 或达到可买数量
    结果：「还能吃进 N 件」或「再买 M 件后不划算」

## 4. 成本（Cost · 0.15）

| 指标 | 定义 | 本作映射 |
|---|---|---|
| 会计成本 | 实际付出的钱 | 采购价 + 维修 + 薪酬 |
| 经济成本 | 会计成本 + 机会成本 | 加上这笔钱本可以存银行的利息 |
| 沉没成本 | 已付出且无法收回 | 已花费的修理费、建造费 |
| 固定成本 FC | 不随产量变化 | 船只基础维护 |
| 可变成本 VC | 随规模变化 | 船员薪酬、火炮维护 |
| 平均成本 AC | (FC + VC) / 规模 | 每艘船每周维护 |

## 5. 规模经济（Scale · 0.15）

    规模报酬 = scale_return(吞吐量, 指数)

| 指数 | 类型 | 含义 |
|---|---|---|
| > 1 | **规模报酬递增** | 投入翻倍，产出超过翻倍（大港优势） |
| = 1 | **规模报酬不变** | 线性 |
| < 1 | **规模报酬递减** | 投入翻倍，产出不足翻倍（管理成本上升） |

**当前体现**：港口等级系数（村 1.20 / 镇 1.00 / 城 0.85）是规模效应的简化版。0.15 会量化成连续曲线。

## 6. 定价（Pricing · 0.16）

| 差别定价类型 | 定义 | 本作映射 |
|---|---|---|
| 一级（完全差别定价） | 对每个买家收不同价 | 暂不做 |
| 二级（数量差别） | 买得多单价低 | 大宗交易 95 折 |
| 三级（市场分割） | 不同市场/群体不同价 | 港口等级系数、声望折扣 |

## 7. 生产（Production · 0.17）

| 指标 | 公式 |
|---|---|
| 生产函数 | 产出 = a × 投入^b |
| 边际产量 | Δ产出 / Δ投入 |
| 平均产量 | 总产出 / 总投入 |

## 8. 税收（Tax · 未来）

| 税种 | 作用 |
|---|---|
| 关税 | 跨阵营贸易成本 |
| 消费税 | 特定商品加价 |

依赖多国海军拆分，排在 0.18 之后。

## 8.1 均值与回归（回答「均值在哪」）

| 指标 | 公式 | 展示 |
|---|---|---|
| 均衡价（均值） | 基础价 × (1 + e × (1 − ratio)) | 商品弹窗指标区 |
| 偏离度 | 当前价 / 均衡价 − 1 | 同上 |
| 回归速度 | 25%/周 | 同上 |
| 本周步长 | (均衡价 − 当前价) × 25% | 同上 |

**这四项合起来，就是「均值回归」的完整呈现**：均值是均衡价，偏离度说明贵了多少，步长说明下周会怎么变。

## 8.2 关税（定值）

| 项 | 值 |
|---|---|
| 税率 | **5%** |
| 触发 | 卖出商品的海域 ≠ 买入时的海域 |
| 扣费 | 从卖出所得中扣除 |
| 未来 | 多国海军拆分后改为按阵营浮动 |
