# 经济系统深化路线图（方案 C 全量 · 分五步）

| 项 | 内容 |
|---|---|
| 范围 | 方案 C 全量（E1~E12） |
| 拆法 | 按依赖关系拆成 **6 个版本**逐版交付 |
| 总工作量 | 约 14 轮（含 0.18 财报） |
| 当前 | 待确认后从 0.13.0-alpha 开始 |

## 1. 为什么这样拆

12 条条目之间有明确的依赖链：

    价格引擎（弹性/回归/事件）
        ↓ 有了会波动的价格
    决策辅助（边际/历史/交叉弹性）
        ↓ 有了可解释的决策
    成本与规模（成本结构/规模报酬/投资递减）
        ↓ 有了完整的成本侧
    定价与市场结构（差别定价）
        ↓
    生产函数与经济总览

每一层都建立在前一层之上，倒过来做会反复返工。

## 3. 算法库与函数库设计

这 12 条本质是「同一批数学函数 + 不同参数」，所以先建函数库，后续每版只加参数、加事件、加展示。

### 3.1 新增三个文件

| 文件 | 职责 | 内容 |
|---|---|---|
| econ_math.gd | **纯数学函数库**（全 static、无状态） | 分段弹性、均值回归、平滑、衰减、插值、边际计算 |
| market_events.gd | **市场事件系统** | 事件表、生成、影响施加与到期回收 |
| econ_stats.gd | **统计与历史** | 环形缓冲历史价、环比、波动率、趋势判定 |

### 3.2 econ_math.gd 函数清单

| 函数 | 用途 | 用于 |
|---|---|---|
| piecewise_elasticity(stock_ratio, alpha) | 分段弹性曲线 | E1 |
| mean_revert(current, target, speed) | 向均衡值回归 | E2 |
| noise(seed, magnitude) | 确定性随机扰动 | E2 |
| marginal_profit(price, cost, capacity_left) | 边际利润 | E3 |
| cross_effect(src_delta, coef) | 交叉弹性传导 | E4 |
| fixed_plus_variable(fixed, variable, scale) | 成本分解 | E5 |
| scale_return(volume, exponent) | 规模报酬曲线 | E6 |
| diminishing_return(invested, cap) | 边际回报递减 | E7 |
| price_discriminate(base, tier, rep) | 差别定价 | E8 |
| production_curve(input, a, b) | 生产函数 | E12 |

**设计原则**：全部 static、不持有状态（便于单测）、参数走 BalanceConfig（可热调）、随机扰动用种子控制可复现。

### 3.3 性能评估

| 场景 | 计算量 | 耗时估计 |
|---|---|---|
| 单次市场交易算价 | 约 10 次浮点运算 | **< 0.01 ms** |
| 打开市场页面（30 港 × 4 商品） | 120 次算价 + 走势绘制 | **< 1 ms** |
| 每周结算（回归 + 事件 + 衰减） | 120 次更新 × 约 10 运算 = 1,200 次 | **< 1 ms** |
| 历史环形缓冲 | 30 × 4 × 8 = 960 个 int | 约 4 KB 内存 |
| 同时生效事件 | ≤ 8 条 | 可忽略 |

**结论：性能影响可忽略。** 一帧预算 16.7 ms，本系统每周结算不到 1 ms，且不在逐帧循环里跑。真正要防的是数值震荡（价格来回跳），靠回归速度与变动上限约束。

### 4.2 世界市场（改造现有页面）

    港口          海域 距离  谷物  木材  边际提示
    白帆渔村·村   1图  2     11↓   16↑   还能吃进 120 件
    青礁港城·城   3图  6      9↑   13↓   还能吃进 60 件
    赤砂港镇·镇   2图  4     12→   15→   已到边际（不划算）

**边际提示的计算（E3，含容量余量）**

    可用容量 = 货舱上限 − 当前载货
    可买数量 = min(可用容量 / 单位体积, 该港库存)
    逐件累加价差直到边际为负
    全程为正 → 「还能吃进 N 件」；否则 → 「再买 M 件后不划算」

## 5. 每版交付的可见变化

| 版本 | 玩家能看到什么 |
|---|---|
| 0.13 | 价格开始自己波动；市场页出现事件页签与涨跌原因 |
| 0.14 | 商品行出现走势线；世界市场出现「还能吃进 N 件」 |
| 0.15 | 周结算出现维护成本清单；港口吞吐与折扣随规模变化 |
| 0.16 | 声望/阵营影响买价 |
| 0.17 | 建筑产出曲线；经济总览页 |

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 价格震荡过猛 | 单周变动上限 + 回归速度限制 |
| 参数难调 | 全部进 BalanceConfig，可热重载 |
| 界面信息过载 | 走势线只在本地市场显示，世界市场只显示箭头 |
| 存档膨胀 | 历史只存 8 周，环形缓冲 |
