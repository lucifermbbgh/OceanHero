# 1.4.0 升级说明（1.3 遗留修复）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.3.18 |
| 目标版本 | **1.4.0** |
| 状态 | 已发布（2026-11-20） |
| 功能组 | 工坊产量引用修复、巡逻队可攻击、禁运影响关税 |

## 1. 修复项

| # | 问题 | 修复 |
|---|---|---|
| 1 | `building_level(&"sawmill")` 引用不存在的建筑，工坊产量恒为 1 批 | 改绑「织帆坊」(`sailmaker`)；3 处（生产与界面） |
| 2 | 巡逻队无法被玩家锁定攻击 | 索敌纳入巡逻队；巡逻队 `take_damage` 支持字典伤害 |
| 3 | 势力事件不影响关税 | 禁运生效时该国港口关税提升至 15% |

## 2. 细节

| 项 | 说明 |
|---|---|
| 巡逻队名称 | 「<势力>巡逻舰」，带装甲 2 |
| 巡逻队受伤 | 字典伤害取 `hull + crew*0.5` |
| 禁运判定 | `faction_embargo(港口所属势力)` |

## 3. 验收

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 织帆坊 3 级时每周 3 批产出 | ✅ |
| 2 | 巡逻队可被字典伤害击伤 | ✅ |
| 3 | 禁运国港口关税 15% | ✅ |
