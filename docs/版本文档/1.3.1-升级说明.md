# 1.3.1 升级说明（31 张地图与港口归属）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.3.0 |
| 目标版本 | **1.3.1** |
| 状态 | 已发布（2026-11-18） |
| 单一功能组 | 地图扩充到 31 张 + 分国归属 + 港口继承 |
| 破坏性 | **是**（旧存档不兼容，需删档重开） |

## 1. 地图体系

| 级别 | 数量 | 归属 |
|---|---|---|
| 0 | 1 | 母港 |
| 1~10 | 每级 3 张，共 30 张 | 六国 + 海盗 + 交界 |

**分配**

| 级别 | 三张图归属 |
|---|---|
| 1 | 澜国 ×3 |
| 2 | 澜国 · 赤鳞 · 交界 |
| 3 | 赤鳞 ×3 |
| 4 | 霜屿 ×3 |
| 5 | 霜屿 · 玄礁 ×2 |
| 6 | 玄礁 ×2 · 交界 |
| 7 | 白鲸 ×3 |
| 8 | 白鲸 · 苍梧 ×2 |
| 9 | 苍梧 ×2 · 交界 |
| 10 | 交界 ×2 · 海盗 |

校验：六国各 4 张、海盗 1 张、交界 5 张 = 30。

## 2. 数据结构

| 字段 | 说明 |
|---|---|
| MapDef.tier | 大级别 1~10 |
| MapDef.nation | 所属国 id；交界图为空 |
| MapDef.contested | 是否交界/争夺 |
| port_registry[].nation | 港口继承所在图国家 |

## 3. 破坏性说明

| 项 | 处理 |
|---|---|
| 旧存档 | **不兼容**，需删除后重开 |
| 地图编号 | 由 1~9 扩展为 1~30，旧进度无意义 |
| 岛屿种子 | 1~9 图保持原种子（不影响布局），10~30 为新种子 |

| 4 | 港口继承国家并正确显示 | ✅ |
| 5 | 海图索引上限 30 | ✅ |
