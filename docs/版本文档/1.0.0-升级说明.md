## 2. 基础框架与玩法闭环

### 2.1 首个可玩版本（0.1.0）

| 项 | 内容 |

| 引擎 | Godot 4.7.2，GL Compatibility，1600×900 |

## 3. 航海与战斗

### 3.1 交战规则（0.2.0）

> 核心决策：**锁定不等于开战**。玩家需主动开火或进入敌对状态才触发战斗。

| 项 | 规则 |
|---|---|
| 锁定 | 仅目标指示，不引发仇恨 |
| 开战 | 首次开火或主动撞击 |
| 脱战 | 距离 > 1200 且持续 8 秒 |
| 演练 | 自动开火被否决，保持逐轮手动 |

### 3.2 航行与寻路（0.4.0）

| 项 | 内容 |
|---|---|
| 转向 | 数据为度/秒，代码经 deg_to_rad 转换（修复 57 倍过快） |
| 风向 | 顺风加速、逆风减速 |
| 边缘换图 | 靠近地图边缘 110px 触发，按蛇形邻接表切换 |

## 5. 市场与经济

### 5.1 市场合并与动态（0.9.0）

| 项 | 内容 |
|---|---|
| 页面 | 本地市场 / 世界市场双页签 |
| 动态 | 每周库存向满值回归 2% |
| 阶梯溢价 | 跨度越大售价越高，最高 +300% |
| 投资 | 五档 5000 / 20000 / 60000 / 150000，52 周升格 |

### 5.2 世界市场与拍卖行（0.10.0）

| 项 | 内容 |
|---|---|
| 世界市场 | 所有港口可见，岛屿港口同样有页签 |
| 升格广播 | EventBus.islands_upgraded，场景即时刷新 |
| 拍卖行 | 仅城市，每周刷新 3~5 件，2 周结算 |
| 货品权重 | 整船 40% / 装备 30% / 船员 20% / 魔法船 10% |
| 竞价 | 出价需不低于当前价 1.05 倍；NPC 40% 概率加价 8~15% |

### 5.3 黑市（0.11.0）

| 项 | 规则 |
|---|---|
| 入口 | 城市专属（tier 3），村与镇没有 |
| 销赃 | 合法价 × 60%，单次不超过 200 单位 |
| 违禁品 | 违禁药物 / 伪造旗帜 / 伪造通行证 / 海军制式火炮 |
| 私掠证 | 正规：声望 3000 + 6000 金；黑市：2.5 倍价 + 通缉度 5 |
| 风险 | 每次交易通缉度 +2；通缉度 ≥80 关闭一周 |

### 5.4 价格引擎（0.13.0）

| 项 | 数值 |
|---|---|
| 分段弹性 | 库存 >70% 用 0.35；30~70% 用 0.55；<30% 用 0.90 |
| 均值回归 | 每周向均衡价靠拢 25% |
| 噪声 | 种子噪声 ±3%，可复现 |
| 单周上限 | ±15%（漂移区间 0.85~1.15） |
| 市场事件 | 8 种，每港每周 15% 概率，持续 1~3 周，全局不超过 8 条 |

### 5.5 决策辅助（0.14.0）

| 项 | 内容 |
|---|---|
| 走势线 | 每港每商品 8 周迷你折线（涨红跌绿） |
| 边际提示 | 按货舱余量与两地价差逐件累加，给出还能吃进 N 件 |
| 交叉弹性 | 朗姆酒与香料 0.4；谷物→朗姆酒 -0.3；木材与铁矿 0.2 |
| 传导阈值 | ±5% 触发，上限 ±8%，单层不级联 |

### 5.6 成本与规模（0.15.0）

| 项 | 内容 |
|---|---|
| 固定成本 | 船体维护（船队估值 2%）+ 停泊费（村 5 / 镇 15 / 城 40） |
| 增量成本 | 船员薪酬 + 火炮维护（每门 8） |
| 规模报酬 | 村落 0.90 递减 / 乡镇 1.00 不变 / 城市 1.15 递增 |
| 投资折扣 | 连续曲线，150,000 处正好 50%（归一化） |

### 5.7 差别定价（0.16.0）

| 声望档 | 买价折扣 | 称呼 |
|---|---|---|
| 0 ~ 999 | 0% | 陌生人 |
| 1000 ~ 2999 | 2% | 熟客 |
| 3000 ~ 5999 | 4% | 老主顾 |
| 6000 以上 | 6% | 自家人 |

### 5.8 生产函数与经济总览（0.17.0）

## 6. 银行与财务

### 6.1 银行基础（0.12.0）

| 项 | 数值 |
|---|---|
| 存款周利率 | 0.1%（年约 5.2%） |

### 6.2 贷款分级与多笔并发（0.12.1）

| L3 | 20,000 | 半年 / 一年 |
| L4 | 50,000 | 半年 / 一年 |
| L5 | 100,000 | 仅一年 |

| 期限 | 周利率 |
|---|---|
| 一季 12 周 | 0.2% |
| 半年 26 周 | 0.3% |
| 一年 52 周 | 0.5% |
