## 3. 批次原则

| 原则 | 说明 |
|---|---|
| 单张出图 | 4×4 网格会画成一张连续场景，切格全错——改为逐张生成（约 40~60s/张），串行不出并发 |
| 抠底 | 图标白/近白 → alpha；头像保留油画背景不抠底 |
| 接入即验收 | 每批接入对应 UI 并加断言（文件存在/可加载/面板显示） |
| 风格统一 | 图标/头像/立绘统一 DreamShaper 厚涂（NoobAI 出图自带文字横幅与四宫格，弃用） |
