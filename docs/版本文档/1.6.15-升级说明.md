# 1.6.15 升级说明（艺术岛屿取代矢量圆岛）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.6.14 |
| 目标版本 | **1.6.15** |
| 状态 | 已发布（2026-11-28） |
| 单一功能 | 海面/小地图岛屿改用母版艺术精灵，三图完全对应 |

## 1. 变更

| 项 | 之前 | 现在 |
|---|---|---|
| 海面岛屿 | 橄榄色同心圆 | 母版裁剪的艺术岛精灵（RGBA） |
| 小地图岛屿 | 沙色圆 / 艺术裁剪 | 同一批精灵印章 + 港口点 |
| 补充岛 | 随机圆 | 复用母版精灵，画风一致 |
| 精灵来源 | 无 | art/islands/isl_<区域>_<序号>.png（70 张） |

## 2. 数据

| 文件 | 内容 |
|---|---|
| data/generated/region_islands.json | 每区域 sea_rect + 岛屿（x/y/r/w/h/sprite） |
| tools/map_pipeline/make_island_sprites.py | 从母版+掩膜提取精灵（间距过滤、锐化） |

间距过滤：同区域岛屿中心距小于半径和 + 1500 时丢弃，保证航道宽度。

## 3. 玩法接口不变

岛屿条目仍为 [位置, 半径, 等级, 名称, 特产, ...]，避障/港口/任务全部沿用，
仅追加精灵字段。航线规划迭代上限 8 提升到 14 以适配艺术岛布局。
