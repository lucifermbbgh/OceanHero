# 1.2.9 升级说明（数据校验层与分类修正）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.2.8 |
| 目标版本 | **1.2.9** |
| 状态 | 已发布（2026-11-18） |
| 单一功能点 | 静态数据校验 + 修复错误分类 |

## 1. 问题

| 商品 | 原分类 | 后果 |
|---|---|---|
| 朗姆酒 | food（旧值） | 出现在食物页签，港村按基础品类 40% 供货 |
| 香料 | luxury（五大类里不存在） | **在任何页签都不显示**，买不到卖不掉 |

根因：引入五大类时只给新商品写分类，旧 4 种沿用早期值，未做迁移与校验。

## 2. 修复

| 项 | 改动 |
|---|---|
| rum.tres | category → consumer |
| spice.tres | category → consumer |
| 新增 validate_defs() | 商品分类/价格/体积、配方引用、建造需求引用、建筑字段 |

**校验项清单**

| 检查 | 说明 |
|---|---|
| 商品分类合法 | 必须是五大类之一 |
| 商品 id 唯一 | 重复即报错 |
| 价格 > 0、体积 > 0 | 防止零价/零体积 |
| 配方产出与原料存在 | 引用完整性 |
| 配方数量 > 0 | 防止空配方 |
| 建造需求材料存在 | 引用完整性 |
| 建筑解锁等级 1~3、slot_id 非空 | 字段完整性 |

## 3. 验收

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 全部静态数据通过校验（0 错误） | ✅ |
| 2 | 朗姆酒与香料归入消费品 | ✅ |
| 3 | 五大类下均有商品，且总数与商品总数一致 | ✅ |
| 4 | 港村不再有消费品库存 | ✅ |

**测试**：66 单元 + 724 集成
