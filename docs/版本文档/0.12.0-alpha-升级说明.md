# 0.12.0-alpha 升级说明

| 项 | 内容 |
|---|---|
| 基线版本 | 0.11.0-alpha |
| 目标版本 | 0.12.0-alpha |
| 状态 | 待确认 |
| 主题 | 银行系统 + 违禁品战斗效果 + 母港黑市 |

## 1. 背景

三件事要一起收口：

- **银行**：玩家遇到想要的商品或拍卖货品但资金不足时，没有周转手段
- **违禁品**：0.11 只做了买得到、存得住，战斗效果还没接进流程，是半成品
- **母港黑市**：按设计黑市只在城市开放，母港升级到港口城市后应当出现，0.11 漏了

## 2. 银行系统

### 2.1 定位

| 项 | 内容 |
|---|---|
| 一句话 | 资金周转工具，不是核心玩法 |
| 位置 | **仅港口城市**（岛屿城市 + 升级后的母港） |
| 功能 | 存款 / 取款 / 贷款 / 还款 / 利息 |
| 利率 | **固定值**，不做浮动 |

### 2.2 存贷利率

| 项 | 数值 | 换算 |
|---|---|---|
| 存款周利率 | **0.2%** | 年约 10.4% |
| 贷款周利率 | **0.5%** | 年约 26% |
| 利息结算 | 按周计息，**每月（4 周）从现金扣一次** | — |
| 贷款期限 | 最长 **52 周**，到期一次性还清本息 | — |

> 存贷利差 0.3%/周 是银行收益来源，也解释了为什么借钱不还很亏。

### 2.3 贷款规则

| 项 | 规则 |
|---|---|
| 前提 | 1) 在该银行**有存款**；2) 贷款总额不超过申请时的**存款额** |
| 额度 | 单笔 ≤ 存款额，累计未还 ≤ 存款额 |
| 期限 | 可选 12 / 26 / 52 周 |
| 放款 | 立即到账现金 |
| 提前还款 | 允许，按已过周数结算利息 |
| 到期 | 一次性还本息 |

**示例**：存款 10,000，最多贷 10,000；借 52 周，利息 = 10,000 × 0.5% × 52 = 2,600，到期还 12,600。

### 2.4 破产

| 触发 | 付息日或还款日**现金不足** |
|---|---|
| 后果 1 | 清空存款与现金 |
| 后果 2 | 海军声望归零 |
| 后果 3 | 被海军通缉（通缉度 +60） |
| 后果 4 | 贷款记录清空，可重新开户 |

> 破产不是 game over：船与装备保留，靠重新打捞东山再起。

### 2.5 界面

    存款 10,000（周息 0.2%，月结 80）
    [存入 1,000] [存入 10,000] [全部取出]

    贷款 0 / 可贷 10,000
    [借 12 周] [借 26 周] [借 52 周]
    下次付息：第 3 周（预计 100）

## 3. 违禁品战斗效果（补 0.11 半成品）

| 违禁品 | 效果 | 生效方式 |
|---|---|---|
| 伪造旗帜 | 下场战斗**敌方索敌半径 −50%** | 进入海域时消耗 1 个 |
| 违禁药物 | 下场战斗**船员上限 +20%** | 进入海域时消耗 1 个 |
| 伪造通行证 | **一次通缉免检**（不触发赏金猎人） | 赏金猎人将生成时消耗 |
| 海军制式火炮 | 装备型：持有即**火炮伤害 +10%** | 不消耗，占用一个装备位 |

**规则**

- 战斗类效果**每场战斗最多各生效一次**，进入海域时消耗
- 未消耗的违禁品保留在库存，可跨图携带
- 效果在 HUD 播报：「伪造旗帜生效：敌方索敌 −50%」

## 4. 母港黑市

| 项 | 规则 |
|---|---|
| 开放条件 | 母港等级 ≥ **港口城市**（tier 3） |
| 功能 | 与岛屿黑市一致：销赃 / 违禁品 / 私掠许可证 |
| 入口 | 母港左侧菜单新增「黑市」按钮（仅城市级出现） |
| 关闭规则 | 通缉度 ≥ 80 时同样关闭一周 |

> 这与黑市只在城市的设计一致：渔港村落与乡镇没有黑市。

## 5. 验收标准

| # | 验收点 |
|---|---|
| 1 | 银行只在港口城市出现（岛屿城市与城市级母港） |
| 2 | 存款后每周按 0.2% 计息，每月从现金结算一次 |
| 3 | 无存款时不能贷款 |
| 4 | 贷款额不超过申请时的存款额 |
| 5 | 贷款按 0.5%/周计息，到期一次性还本息 |
| 6 | 付息日现金不足 → 破产：清空存款与现金、海军声望归零、通缉度 +60 |
| 7 | 破产后船与装备保留，可重新开户 |
| 8 | 伪造旗帜进入海域时消耗，敌方索敌半径减半 |
| 9 | 违禁药物进入海域时消耗，船员上限 +20% |
| 10 | 伪造通行证在赏金猎人将生成时消耗，本次不生成 |
| 11 | 海军制式火炮持有即 +10% 火炮伤害，不消耗 |
| 12 | 母港升级到城市后左侧出现「黑市」按钮 |
| 13 | 母港黑市功能与岛屿黑市一致 |
| 14 | 所有新增状态进存档，旧存档可正常读取 |

## 6. 不做

- 不做浮动利率
- 不做多国银行（等海军多国拆分后再议）
- 不做股票/期货
- 不做玩家间借贷
