# 0.12.0-alpha 升级说明

| 项 | 内容 |
|---|---|
| 基线版本 | 0.11.0-alpha |
| 目标版本 | 0.12.0-alpha |
| 状态 | 已发布（2026-11-17） |
| 主题 | 银行系统 + 违禁品战斗效果 + 母港黑市 |

## 1. 背景

三件事要一起收口：

- **银行**：玩家遇到想要的商品或拍卖货品但资金不足时，没有周转手段
- **违禁品**：0.11 只做了买得到、存得住，战斗效果还没接进流程，是半成品
- **母港黑市**：按设计黑市只在城市开放，母港升级到港口城市后应当出现，0.11 漏了

## 2. 银行系统

### 2.1 定位

| 项 | 内容 |
|---|---|
| 一句话 | 资金周转工具，不是核心玩法 |
| 位置 | **仅港口城市**（岛屿城市 + 升级后的母港） |
| 功能 | 存款 / 取款 / 贷款 / 还款 / 利息 |
| 利率 | **固定值**，不做浮动 |

### 2.2 存贷利率

**存款利率（全城统一）**

| 项 | 数值 | 换算 |
|---|---|---|
| 存款周利率 | **0.1%** | 年约 5.2% |
| 利息结算 | 按周计息，**每月（4 周）从现金结算一次** | — |

**贷款利率（按期限分三档）**

| 期限 | 周利率 | 年化约 | 借 10,000 到期利息 |
|---|---|---|---|
| 一季（12 周） | **0.2%** | 10.4% | 240 |
| 半年（26 周） | **0.3%** | 15.6% | 780 |
| 一年（52 周） | **0.5%** | 26% | 2,600 |

> 期限越长利率越高（银行承担的不确定性更大），但长借的周供压力小。
> 存款月结 0.4%、一年期贷款周息 0.5%，利差即银行收益。

### 2.3 贷款规则

| 项 | 规则 |
|---|---|
| 前提 | 1) 在该银行**有存款**；2) 贷款总额不超过申请时的**存款额** |
| 额度 | 单笔 ≤ 存款额，累计未还 ≤ 存款额 |
| 期限 | 三档：一季 12 周 / 半年 26 周 / 一年 52 周 |
| 放款 | 立即到账现金 |
| 提前还款 | 允许，按已过周数结算利息（用该笔贷款的原利率） |
| 到期 | 一次性还本息 |

**示例**：存款 10,000，最多贷 10,000。

| 借期 | 利息 | 到期还款 |
|---|---|---|
| 一季 | 10,000 × 0.2% × 12 = 240 | 10,240 |
| 半年 | 10,000 × 0.3% × 26 = 780 | 10,780 |
| 一年 | 10,000 × 0.5% × 52 = 2,600 | 12,600 |

### 2.4 账户互通（全城通用）

| 项 | 规则 |
|---|---|
| 账户 | **全局唯一**，不按城市拆分 |
| 存款 | 在 A 城存入，到 B 城可取出 |
| 贷款 | 在 A 城借的款，到 B 城可还；资质按全局存款判定 |
| 利率 | 全城统一，无地区差异 |
| 破产 | 在任意银行触发，全局生效 |

> 设计意图：银行是**势力级机构**而不是店铺，避免玩家在城际之间搬运现金。

### 2.5 破产

| 触发 | 付息日或还款日**现金不足** |
|---|---|
| 后果 1 | 清空存款与现金 |
| 后果 2 | 海军声望归零 |
| 后果 3 | 被海军通缉（通缉度 +60） |
| 后果 4 | 贷款记录清空，可重新开户 |

> 破产不是 game over：船与装备保留，靠重新打捞东山再起。

### 2.6 界面

    银行 · 白帆港城（全城通存通取）      现金 42,000
    存款 10,000（周息 0.1%，月结 40）
    [存入 1,000] [存入 10,000] [全部取出]

    贷款 0 / 可贷 10,000
    [借一季 0.2%/周] [借半年 0.3%/周] [借一年 0.5%/周]
    下次付息：第 3 周（预计 200）

## 3. 违禁品战斗效果（补 0.11 半成品）

| 违禁品 | 效果 | 生效方式 |
|---|---|---|
| 伪造旗帜 | 下场战斗**敌方索敌半径 −50%** | 进入海域时消耗 1 个 |
| 违禁药物 | 下场战斗**船员上限 +20%** | 进入海域时消耗 1 个 |
| 伪造通行证 | **一次通缉免检**（不触发赏金猎人） | 赏金猎人将生成时消耗 |
| 海军制式火炮 | 装备型：持有即**火炮伤害 +10%** | 不消耗，占用一个装备位 |

**规则**

- 战斗类效果**每场战斗最多各生效一次**，进入海域时消耗
- 未消耗的违禁品保留在库存，可跨图携带
- 效果在 HUD 播报：「伪造旗帜生效：敌方索敌 −50%」

## 4. 母港黑市

| 项 | 规则 |
|---|---|
| 开放条件 | 母港等级 ≥ **港口城市**（tier 3） |
| 功能 | 与岛屿黑市一致：销赃 / 违禁品 / 私掠许可证 |
| 入口 | 母港左侧菜单新增「黑市」按钮（仅城市级出现） |
| 关闭规则 | 通缉度 ≥ 80 时同样关闭一周 |

> 这与黑市只在城市的设计一致：渔港村落与乡镇没有黑市。

### 实现说明

- 银行状态（存款、贷款本金/期限/利率/剩余周/已付利息/月计数器）全部进存档
- 周结算 `bank_tick_week()`：每 4 周付息，到期还本息，资金不足立即破产
- 破产：清空存款与现金、海军声望归零、通缉度 +60，船与装备保留
- 违禁品效果在 `sea_scene._apply_contraband_effects()` 统一消耗，HUD 播报
- 海军制式火炮加成在 `sea_ship._fire_at()`，四池伤害同乘 1.10
