# 1.4.1 升级说明（舰船模块数据模型）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.4.0 |
| 目标版本 | **1.4.1** |
| 状态 | 已发布（2026-11-20） |
| 功能组 | 12 类模块定义、分层规则、4 岗位、锚点表 |

## 1. 模块定义（data/modules/*.tres）

| 模块 | 可装装备 | 可置岗位 | 锚点 | 属性键 |
|---|---|---|---|---|
| 舵轮 | rudder | 大副 | (0.655,0.505) | turn |
| 甲板 | armor / figurehead | 水手 | (0.144,0.634) | crew_max |
| 炮门 | cannon | 炮手 | (0.375,0.528) | guns |
| 风帆 | sail | 水手 | (0.462,0.241) | speed |
| 瞭望台 | telescope | 水手 | (0.462,0.066) | view |
| 旗杆 | flag | — | (0.857,0.514) | rep_gain |
| 船长室 | — | — | (0.806,0.634) | all |
| 医疗室 | — | 船医 | (0.811,0.864) | heal |
| 宿舍 | — | 水手 | (0.609,0.636) | crew_max |
| 仓库 | — | 水手 | (0.616,0.867) | cargo |
| 厨房 | — | 水手 | (0.812,0.745) | recover |
| 工坊 | — | 水手 | (0.615,0.748) | repair |

## 2. 分层规则

| 船级 | 甲板层 | 炮门层 |
|---|---|---|
| 1~2 | 0 | 1 |
| 3~4 | 1 | 2 |
| 5~6 | 2 | 2 |
| 7~8 | 2 | 3 |
| 9~10 | 3 | 4 |

## 3. 岗位

| 岗位 | id | 归属 |
|---|---|---|
| 大副 | mate | 舵轮 |
| 炮手 | gunner | 炮门 |
| 船医 | surgeon | 医疗室 |
| 水手 | sailor | 其余模块 |

## 4. 接口

| 接口 | 说明 |
|---|---|
| `ship_modules()` | 返回当前船模块实例（含分层） |
| `deck_layers(tier)` / `gundeck_layers(tier)` | 分层查询 |
| `module_level(mid, layer)` / `set_module_level(...)` | 强化等级（0~5） |

## 5. 验收

| # | 验收点 | 结果 |
