# 1.3.12 升级说明（兑换结算与入库）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.3.11 |
| 目标版本 | **1.3.12** |
| 状态 | 已发布（2026-11-20） |
| 功能组 | 兑换校验、扣款、物品入库 |

## 1. 结算流程

    校验声望 → 校验金币 → 扣金币 → 扣声望 → 发放物品 → 失败则退款

| 情况 | 结果 |
|---|---|
| 声望不足 | 拒绝，提示所需声望 |
| 金币不足 | 拒绝，提示所需金币 |
| 发放失败 | 全额退款（金币 + 声望） |

## 2. 入库规则

| 类型 | 入库位置 |
|---|---|
| gear | `gear_owned` 装备库（去重） |
| ship | `ships_owned` 船只列表（去重，默认停母港） |

## 3. 数据修正

物品表原先引用了尚未创建的 `fx_*` 资源，导致「发放失败」。
已把 22 行全部指向**现有资源**：

| CSV id | 实际资源 |
|---|---|
| fx_yunlan_sail | sail_double |
| fx_chilin_hold | armor_plank |
| fx_youming_clipper 等船只 | schooner / brig / longship / sand_junk |

> 名称仍显示专属名（云澜快帆等），效果沿用被引用资源的数值。
> 真正独立的专属数值留到 1.3.13 一起做。
