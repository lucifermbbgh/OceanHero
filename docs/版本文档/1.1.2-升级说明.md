| 项 | 内容 |
|---|---|
| 基线版本 | 1.1.1 |
| 目标版本 | **1.1.2** |
| 状态 | 已发布（2026-11-18） |
| 主题 | 岛屿市场商品详情弹窗 + 多建筑并行升级 |

## 1. 岛屿市场商品详情弹窗

岛屿港口市场每行新增「交易」按钮，点开弹窗：

    供给弹性 0.35（缺乏弹性）　库存 200/400
    均衡价 12.0　当前买价 14　偏离 +16.7%
    关税 5%（按声望）
    数量 [ 10 ]
    [买入] [卖出]

| 项 | 规则 |
|---|---|
| 数量 | 买入上限为该港库存，卖出上限为持有量 |
| 买入 | 按显示买价成交 |
| 卖出 | 按显示卖价成交，非母港扣关税 |
| 指标 | 弹性 / 库存比例 / 均衡价 / 偏离 / 关税 |

## 2. 多建筑并行升级

| 项 | 规则 |
|---|---|
| 并行 | 每座建筑独立计时，互不影响 |
| 工期 | 2 周 |
| 花费 | 2000 ×（当前等级 + 1）金币 |
| 限制 | 同一建筑不能重复开工 |
| 完成 | 周结算自动升到目标等级并播报 |

**界面**：基地建设面板新增「并行升级（每座独立计时）」一行按钮，
以及建筑列表中的「升级中 N/2 周 → LvX」进度文本。
