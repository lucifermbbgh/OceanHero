## 2. 岛屿复用母港面板

| 项 | 母港 | 其他岛屿 |
|---|---|---|
| 市场交易 | ✅ | ✅ |
| 酒馆招募 | ✅ | ✅ |
| 任务板 | ✅ | ✅ |
| 船厂与装备 | ✅ | ✅ |
| 交易所 | ✅ | ✅（港城） |

**术语澄清**：不是「其他岛不能升级母港」，而是「玩家不能在别人的岛上建造建筑」。

## 3. 城镇升级重构（采纳建议并细化）

### 3.1 为什么改

当前「港口升级」需要提交木材/石材/铁矿 + 金币，与建筑建造的消耗**重复**，
玩家看不出这笔钱花在哪——建筑已经在消耗材料了，港口升级再收一次说不通。

### 3.2 新规则：升级条件 = 建筑等级达标

| 升级 | 门槛 |
|---|---|
| **港村 → 港镇** | 总督府 Lv3；酒馆、仓库、织帆坊、瞭望塔 均 Lv2 |
| **港镇 → 港城** | 总督府 Lv4；船坞、铸造厂 **Lv2**；港村四座建筑 **Lv4** |
| 港城 | 最高级 |

**代价**：不再额外收取材料；建筑升级本身已消耗金币与材料，港口升级只作为**里程碑**。

### 3.3 条件展示（新增要求）

港口升级按钮**上方**必须列出全部条件，每条带状态指示：

    升级条件
      总督府        Lv1 / Lv3   未完成
      酒馆          Lv0 / Lv2   未完成
      仓库          Lv1 / Lv2   未完成
      织帆坊        Lv0 / Lv2   未完成
      瞭望塔        Lv0 / Lv2   未完成

| 状态 | 显示 | 颜色 |
|---|---|---|
| 未达标 | 未完成 | 红 |
| 达标 | 已完成 | 绿 |

> 玩家不需要猜——升级需要什么、差多少，一眼看完。

### 3.4 按钮状态

| 状态 | 显示 |
|---|---|
| 条件未达标 | 灰色「港口升级（条件未达成）」+ 列出未达标项 |
| 条件达标 | 绿色「港口升级 → 港镇」可点击 |
| 已达最高级 | 「已是港城」 |

### 3.5 为什么这个设计更好

| 维度 | 旧（交材料） | 新（建筑等级） |
|---|---|---|
| 可视化 | 只看到数字 | 面板上一眼看到哪座建筑没达标 |
| 与建造的关系 | 重复消耗 | 建造是唯一消耗入口，逻辑单一 |
| 引导性 | 无 | 明确告诉玩家下一步该建什么 |

## 4. 仓库界面（新增）

### 4.1 入口

左侧菜单「仓库」（母港与岛屿均有，属于玩家自身功能）。

### 4.2 面板内容（全屏）

    仓库与货舱
    货舱 542 / 260  ← 超载标红
    仓库 542 / 800

    [货舱] [仓库] [全部]

    商品     分类    数量    单位体积   占用
    木材     原材料   300     1.0       300
    铁矿     原材料   120     0.6        72
    石材     原材料   150     0.8       120

| 列 | 说明 |
|---|---|
| 数量 | 该容器内数量 |
| 单位体积 | 来自商品定义 |
| 占用 | 数量 × 单位体积 |

### 4.3 操作

| 操作 | 说明 |
|---|---|
| 装船 | 从仓库转货舱，受货舱余量限制 |
| 存仓 | 从货舱转仓库，受仓库余量限制 |
| 容量条 | 顶部显示两个容器的占用/上限 |
