# 0.3.0-alpha 升级说明

| 项 | 内容 |
|---|---|
| 基线版本 | 0.2.0-alpha |
| 目标版本 | 0.3.0-alpha |
| 状态 | ✅ 已发布（2026-11-16，commit 9f3262e） |
| 主题 | 任务追踪与阵营生态 |
| 测试 | 65 单元 + 285 集成 |

## 1. 背景

接到任务出海后没有任何追踪 UI；海面上只有玩家与敌人，缺少「活的世界」感。

## 2. 需求与实现

- 出海后左上角「任务追踪」面板：标题 / 进度 / 阵营
- 每条任务带「导航」按钮：运输→哨站、采集→打捞点、讨伐→最近敌人
- 护航任务显示商船血量与距离，丢失显示「失联」
- 单位头顶阵营标签：海盗（红）/ 商船（绿）/ 海军（蓝紫）
- 同势力标识：声望 ≥3000 的阵营单位显示「同势力」
- 阵营生态 AI：海军↔海盗、海盗↔商船/玩家互殴
- 战力优势 1.25 倍才主动追击，否则只被动还击
- NPC 互殴不产出战利品（防捡漏刷钱）

## 3. 验收结果

- 修复 NPC 无目标时原地打转（无目标分支返回了常量舵角 0.2，等于永久满舵）
- 海怪触手由线性累加改为 sin 摆动，不再绕圈

## 4. 影响范围

`scripts/sea/sea_scene.gd、scripts/ui/sea_hud.gd、scripts/ship/`

## 5. 遗留问题

高级图出场即被十几个单位围攻；转向抽搐
