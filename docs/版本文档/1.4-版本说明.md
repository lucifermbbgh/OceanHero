# 1.4 特性版本说明（舰船模块化）

| 项 | 内容 |
|---|---|
| 特性版本 | **1.4**（舰船模块化） |
| 小版本范围 | 1.4.0 ~ 1.4.20 |
| 状态 | 已完结（2026-11-21） |

## 1. 目标与完成情况

| 目标 | 结果 |

| 舰船拆分为 12 类模块 | ✅ 舵轮/甲板/炮门/风帆/瞭望台/旗杆/船长室/医疗室/宿舍/仓库/厨房/工坊 |

| 装备按模块归属 | ✅ 舵/帆/装甲板/船艏像/望远镜/旗帜 |
| 人员按岗位归属 | ✅ 大副/炮手/船医/水手 4 类 |
| 模块强化取代旧强化 | ✅ 旧装备强化/合成/改装全部移除 |
| 舰船面板 | ✅ 船影 + 双页签插槽 + 属性栏 + 强化弹窗 |
| 每船独立模块状态 | ✅ 换船随船封存，船库可存取 |

## 3. 破坏性变更

| 项 | 说明 |
|---|---|
| 存档 | **1.4 之前的存档不兼容**，需重开 |
| 旧系统 | 装备强化、装备合成、船只改装（火炮位/帆具）删除 |
| 岗位 | 8 类合并为 4 类（舵手/帆手/瞭望/木匠 → 水手） |
| 装备槽 | 旧 `armor` 槽迁移为 `plate`（装甲板） |

## 4. 已知限制

| # | 项 | 说明 |
|---|---|---|
| 1 | 医疗室 / 厨房 | 依赖「船员健康度」系统，本版挂起 |
| 2 | 船影与插槽 | 色块与代码绘制，待 1.6 美术资源替换 |
| 3 | 火炮装备 | 炮门暂未开放火炮安装（旧改装并入模块） |
| 4 | 势力专属船 | 特化定位，不参与主线数值单调性 |
