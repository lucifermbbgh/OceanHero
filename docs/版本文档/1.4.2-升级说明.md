# 1.4.2 升级说明（模块接入属性管线）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.4.1 |
| 目标版本 | **1.4.2** |
| 状态 | 已发布（2026-11-20） |
| 功能组 | 模块强化等级接入 `stats()`，契约不变 |

## 1. 接入规则

| 模块 | 等级作用 |
|---|---|
| 风帆 | 航速 +4% / 级 |
| 舵轮 | 转向 +4% / 级 |
| 宿舍 + 甲板各层 | 船员上限 +5% / 级（累加） |
| 仓库 | 货舱 +6% / 级 |
| 瞭望台 | 视野 +0.03 / 级 |
| 炮门各层 | 舷侧炮 +1 门 / 级（累加） |
| 船长室 | 船体 +1% / 级 |

**非战斗加成字段**（写入 stats，供后续系统读取）：

| 字段 | 来源 |
|---|---|
| `rep_gain_bonus` | 旗杆 +5% / 级 |
| `heal_bonus` | 医疗室 +10% / 级 |
| `recover_bonus` | 厨房 +8% / 级 |
| `repair_bonus` | 工坊 +10% / 级 |

## 2. 兼容性

> `stats()` 原有字段全部保留，战斗/贸易/UI 无需改动。
