# 0.19.3 升级说明（表格与曲线修正）

| 项 | 内容 |
|---|---|
| 基线版本 | 0.19.2 |
| 目标版本 | 0.19.3 |
| 状态 | 已发布（2026-11-18） |
| 主题 | 交易按钮移出表格、成本明细表格化、边际曲线修复 |

## 1. 问题与修复

| # | 问题 | 原因 | 修复 |
|---|---|---|---|
| 1 | 表格仍有「操作」表头，交易按钮被塞进单元格 | 上一版保留了一个操作单元格 | 删除该列单元格；交易按钮直接放在行右侧，与单元格同间距 |
| 2 | 经济总览没有成本明细，只有一行文字 | 信息未表格化 | 新增成本明细表：成本项 / 本周 / 本年累计 / 说明，含合计行 |
| 3 | 章节名不符 | — | 改为「年度经济信息（年资产负债表）」「年度营收信息（年利润表）」，支出字样统一为成本 |
| 4 | 买 10 件、100 件后边际曲线无变化，只有买光才变 | 弹窗用了 TIER_STOCK_REF（村落 40）当满值，而实际库存上限是 800 → 比例恒被 clamp 到 1 → 买价恒定 | 弹窗改用港口真实 max_stock；MC 每步按实际库存递减 |
