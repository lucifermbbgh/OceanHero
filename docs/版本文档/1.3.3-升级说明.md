# 1.3.3 升级说明（国家关系与关税）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.3.2 |
| 目标版本 | **1.3.3** |
| 状态 | 已发布（2026-11-18） |
| 功能组 | 国家关系矩阵 + 关税按港口归属国计算 |

## 1. 关系矩阵

| 关系 | 国家对 |
|---|---|
| 敌对 | 澜国×玄礁、赤鳞×玄礁、白鲸×玄礁、霜屿×玄礁 |
| 同盟 | 澜国×霜屿、赤鳞×苍梧、白鲸×苍梧 |
| 中立 | 其余组合 |

> 海盗势力（玄礁水域）与所有正道国家敌对，这是 1.3.5 巡逻队交战的判定依据。

## 2. 关税

| 港口 | 依据 | 税率 |
|---|---|---|
| 有归属国 | 玩家与该国声望 | 见下表 |
| 交界 / 母港 | 固定 | 5% |

| 声望 | 关系 | 关税 |
|---|---|---|
| < 2000 | 敌视/冷淡 | 10% |
| 2000 ~ 4999 | 中立 | 5% |
| 5000 ~ 7999 | 友好 | 3% |
| 8000+ | 盟友 | 1% |

## 3. 改动点

| 项 | 说明 |
|---|---|
| GameState.nation_relation_between(a, b) | 对称关系查询 |
| GameState.tariff_rate_for_port(pid) | 按港口归属国声望算税 |
| 市场卖出 | 改用 tariff_rate_for_port |
| 商品弹窗 | 关税显示改为港口归属国口径 |
