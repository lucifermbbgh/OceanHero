| 项 | 内容 |

| 主题 | 生产函数 + 经济总览（E12） |

## 1. 需求

### 1.1 生产函数

    产出 = 基础产出 × 等级^指数

| 建筑 | 指数 | 类型 |
|---|---|---|
| 交易所 | 0.95 | 递减（越大越难管） |
| 船坞 | 1.00 | 不变 |
| 仓库 | 0.90 | 递减 |

**边际产量**：每升一级多出的产出，显示在建筑面板。

### 1.2 经济总览面板

母港新增「经济」页签：

    现金 42,000 ｜ 存款 10,000 ｜ 未还贷款 0
    船队估值 68,000 ｜ 库存估值 12,400 ｜ 净资产 132,400

    本周收入 3,200（贸易 3,000 / 战利品 200）
    本周支出 1,850（维护 850 / 采购 1,000）
    本周净利 +1,350

    各港投资：白帆 60,000 ｜ 青礁 20,000 ｜ 赤砂 5,000
    贸易收益排行：谷物→白帆 1,200 ｜ 香料→青礁 900
