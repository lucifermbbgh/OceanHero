# 1.6.14 升级说明（三图一致：世界图/小地图/海面）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.6.13 |
| 目标版本 | **1.6.14** |
| 状态 | 已发布（2026-11-27） |
| 单一功能 | 海面岛屿与小地图裁剪对齐世界海图母版 |

## 1. 问题

小地图上的沙色圆岛与世界海图母版的艺术岛位置不一致（玩家圈出）。

## 2. 方案

| 项 | 做法 |
|---|---|
| 海域矩形 | 构建脚本为每个区域计算「海域矩形」（区域内海面像素 bbox） |
| 岛屿来源 | 海域矩形内的陆地连通域 → `region_islands.json`（60 座） |
| 海面场景 | 岛屿位置/半径取自 json（局部坐标 × SEA_SIZE） |
| 小地图 | 底图裁剪 = 海域矩形；港口点 = 海面岛屿位置 |
| 补充岛 | 艺术岛不足 4 座时随机补，且与已有岛保持 ≥1100 间距 |

## 3. 一致性

| 视图 | 岛屿来源 |
|---|---|
| 世界地图 | 母版艺术（区域级） |
| 小地图 | 母版艺术裁剪（海域矩形）+ 港口点 |
| 海面场景 | region_islands.json（与小地图同源） |

## 4. 验收

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 小地图港口点落在艺术岛上 | ✅ |
| 2 | 海面岛屿与小地图同源 | ✅ |
| 3 | 避障/航线测试全过 | ✅ |
| 4 | 集成 1068 全过（35 秒） | ✅ |

## 5. 遗留

| # | 项 |
|---|---|
| 1 | 被推离出生点/中心的岛屿与小地图艺术略有偏移 |
| 2 | 大陆型区域的海域矩形偏小，裁剪以海面为主 |

**测试**：66 单元 + 1068 集成
