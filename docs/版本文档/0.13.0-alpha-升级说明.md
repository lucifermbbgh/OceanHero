## 1. 背景

当前价格只有一条线性弹性曲线：库存越低越贵，但没有惯性、没有趋势、没有原因。
玩家感受不到「市场」，只能感受到一张静态价目表。

本版让价格**活起来**：分段弹性 + 向均衡回归 + 事件驱动，并让玩家能看见波动的原因。

## 2. 需求

### 2.1 E1 分段供给弹性

| 库存比例 | 弹性系数 | 效果 |
|---|---|---|
| > 70% | 0.35 | 货多，价格平缓 |
| 30% ~ 70% | 0.55 | 中间区，接近现状 |
| < 30% | 0.90 | 缺货，价格陡涨 |

- 曲线在分段点**连续**（避免价格跳变）
- 参数进 BalanceConfig

### 2.2 E2 均值回归与波动

    每周：价格 = 回归(当前价 → 均衡价, 速度) + 扰动(库存, 事件)

| 项 | 规则 |
|---|---|
| 均衡价 | 由基础价 × 供需系数得出 |
| 回归速度 | 每周向均衡价靠拢 25% |
| 随机扰动 | ±3%，由（港口 id + 商品 id + 周序号）做种子，可复现 |
| 单周变动上限 | **±15%**（防止暴涨暴跌）|
| 库存影响幅度 | 库存越偏离均衡，扰动越大（最高 ×2） |

### 2.3 E9 市场事件

| 项 | 规则 |
|---|---|
| 生成 | 每周每个港口 15% 概率生成 1 个事件 |
| 持续 | 1~3 周 |
| 同时生效 | 全局 ≤ 8 条 |

**事件表（首批 8 种）**

| 事件 | 影响 | 说明 |
|---|---|---|
| 丰收 | 谷物供给 +25% | 价格下跌 |
| 歉收 | 谷物供给 −25% | 价格上涨 |
| 林木茂盛 | 木材供给 +20% | — |
| 港口地震 | 铁矿产出 −40% | 价格暴涨 |
| 战争阴云 | 香料需求 +15% | 价格上涨 |
| 朗姆酒节 | 朗姆酒需求 +30% | 价格上涨 |
| 海盗封锁 | 该港全部商品供给 −20% | 全面涨价 |
| 商队抵达 | 该港全部商品供给 +15% | 全面降价 |

## 3. 算法库（本版先建）

新建 `scripts/systems/econ_math.gd`，先实现本版需要的 3 个函数：

| 函数 | 用途 |
|---|---|
| piecewise_elasticity(ratio, alpha_lo, alpha_mid, alpha_hi) | 分段弹性 |
| mean_revert(current, target, speed) | 均值回归 |

其余 7 个函数在后续版本按需补充。

## 5. 验收标准

| # | 验收点 |
|---|---|
| 1 | 库存低于 30% 时价格涨幅明显大于满库存时（分段弹性生效） |
| 2 | 价格曲线在分段点连续，无跳变 |
| 3 | 每周价格向均衡价回归约 25% |
| 4 | 同一存档同样输入下，扰动结果可复现 |
| 5 | 单周价格变动不超过 ±15% |
| 6 | 每周每港有 15% 概率生成事件，持续 1~3 周 |
| 7 | 事件同时生效不超过 8 条 |
| 8 | 事件到期后影响自动消失 |
| 9 | 市场页出现「事件」页签，列出当前事件 |
| 10 | 受事件影响商品在本地市场有标记 |
| 11 | 所有事件与价格历史进存档 |

## 5.1 实际完成情况

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 库存低于 30% 时涨幅明显更大 | ✅ 弹性 0.35/0.55/0.90 三段 |
| 2 | 分段点连续 | ✅ 中间区取 0.55 |
| 3 | 每周向均衡价回归 25% | ✅ mean_revert |
| 4 | 扰动可复现 | ✅ 哈希种子，同输入同输出 |
| 5 | 单周变动不超过 ±15% | ✅ clamp 0.85~1.15 |
| 6 | 每港每周 15% 概率生成事件 | ✅ 哈希判定 |
| 7 | 事件持续 1~3 周 | ✅ |
| 8 | 全局同时生效 ≤ 8 条 | ✅ |
| 9 | 事件到期自动移除 | ✅ |
| 10 | 市场页有「市场事件」页签 | ✅ 母港市场第三页签 |
| 11 | 受事件影响价格有变化 | ✅ 供给/需求系数映射 |
| 12 | 事件与漂移进存档 | ✅ |

**测试**：65 单元 + 495 集成（新增 16 项）

### 实现说明

- 价格 = 公式价 × 漂移倍率 × 事件倍率；漂移与事件均存 GameState
- 漂移每周：`mean_revert(当前, 事件目标, 25%) + 种子噪声(±3%)`，再 clamp 到 0.85~1.15
- 事件由「港口 key + 周序号」哈希决定，可复现
- 本地市场商品行显示涨跌箭头（↑+5% / ↓-3% / →）
- 岛屿港口价格同样接入漂移与事件
