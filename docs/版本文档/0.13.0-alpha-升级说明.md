## 3. 三条可能的范围方案

### 方案 A：最小闭环（推荐）

**E1 + E2 + E3**（约 2 轮）

| 条目 | 变化 |
|---|---|
| E1 | 价格曲线从线性改为分段（库存越低涨得越陡） |
| E2 | 每周价格向均衡值回归 + 随机扰动，形成趋势 |
| E3 | 世界市场直接告诉玩家「还能买几件才划算」 |

**效果**：市场第一次有了「自己的脾气」，玩家决策从「哪里便宜」变成「还能吃进多少」。

### 方案 B：加上成本与规模

**E1 + E2 + E3 + E5 + E6 + E7**（约 3.5 轮）

额外带来：舰队维护成本随规模变化、港口规模效应量化、投资回报递减。

### 方案 C：全量

**E1~E10**（约 8 轮）

E11/E12 依赖多国拆分，暂不做。

## 4. 建议

选 **方案 A**。理由：

1. E1~E3 都是**价格模型内部**的改动，互相关联，一起做最自然
2. 完成后玩家能立刻感受到「市场会动」，这是当前经济最缺的
3. 成本与规模（E5/E6）会牵动战斗与建造，等市场稳定后再做更稳

## 5. 不做

- E11 关税、E12 生产函数：依赖多国海军拆分，本阶段不做
- 期货、股票等金融衍生品：已明确不做
- 玩家间交易：单机不做
