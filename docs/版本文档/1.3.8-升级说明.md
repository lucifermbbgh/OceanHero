## 1. 击沉接入（补 1.3.6 缺口）

1.3.6 定义了势力声望函数，但**没有任何调用点**，玩家击沉船只声望不变。本版接通：

| 击沉目标 | 归属势力 |
|---|---|
| 海盗 | 幽溟 |
| 某国海军 / 商船 | 所在海图所属国 |
| 交界图船只 | 该图 nations 列表首个国家 |

声望变化：目标势力 −L，其敌国 +max(1, L/2)，L = 船只等级。

## 2. 旧国家 id 映射

| 海图 id | 新势力 id |
|---|---|
| lan | **yunlan** |
| chilin / shuangyu / xuanjiao / baijing / cangwu | 同名 |

新增 `faction_id_of()` 与 `NATION_TO_FACTION`，避免 1.3.6 改名后海图数据失配。
