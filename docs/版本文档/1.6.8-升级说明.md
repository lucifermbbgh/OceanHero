# 1.6.8 升级说明（世界地图母版 v1）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.6.7 |
| 目标版本 | **1.6.8** |
| 状态 | 已发布（2026-11-26） |
| 单一功能 | 产出第一张完整世界地图母版，作为拆分基准 |

## 1. 母版内容

| 要素 | 实现 |
|---|---|
| 海面 | 深蓝渐变 + 分形噪声 + 波纹 + 罗经线 |
| 陆地 | 6 块，羊皮纸纹理 + 阴影 + 双线墨边 |
| 区域 | 30 个 Voronoi 海域，势力色淡染 + 编号 |
| 分级 | 左侧 1级 ~ 10级 |
| 势力 | 7 个圆徽 + 图例 |
| 方位 | N / E / S / W + 罗盘 |
| 装饰 | 标题饰框、比例尺、外框 |

产物：`art/world_map/master_map_v1.png`（2048×1152）。

## 2. 工作流（母版 → 拆分）

| 步骤 | 内容 |
|---|---|
| 1 | 母版定稿 `master_map_v1.png` |
| 2 | 按母版在 Tiled 中拉区域多边形（`world_regions.tmj`） |
| 3 | 构建 `world_regions.json` / `land_masses.json` |
| 4 | 游戏读取区域矢量 + 底图分层 |
| 5 | 后续改图：先改母版，再同步 Tiled 与底图 |

## 3. 验收

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 母版含全部要素 | ✅ |
| 2 | 30 区域与分级可读 | ✅ |
| 3 | 势力色与徽标可见 | ✅ |
| 4 | 文字为代码绘制（中文正常） | ✅ |

## 4. 说明

| 项 | 说明 |
|---|---|
| 与游戏的区别 | 母版是「设计总图」，游戏仍是矢量区域 + 分层底图 |
| 为何不直接用母版当底图 | 母版含区域色与编号，游戏需要动态迷雾/选中/航线 |
| 后续 | 母版可作为读图界面/加载图/宣传图 |

**测试**：66 单元 + 1064 集成（无代码改动）
