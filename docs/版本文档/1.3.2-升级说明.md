# 1.3.2 升级说明（邻接图航行）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.3.1 |
| 目标版本 | **1.3.2** |
| 状态 | 已发布（2026-11-18） |
| 单一功能点 | 航行由等级跳转改为邻接图通行 |

## 1. 为什么改

原方案「同级三图任选」是**行政规则**，与未来的**世界地图地理规则**会冲突。
改为邻接图后：

| 目标 | 实现 |
|---|---|
| 同级任选 | 同级三图互相邻接（三角） |
| 跨级推进 | 相邻级别三图全连 |
| 世界地图兼容 | 世界地图只是同一张邻接图的渲染 |

## 2. 邻接生成规则

| 关系 | 连接数 |
|---|---|
| 同级三图 | 两两相邻（3 条边） |
| 相邻级别 | 三对三全连（9 条边） |
| 母港 | 连接 1 级三张图 |

## 3. 通行规则

| 规则 | 说明 |
|---|---|
| 相邻 | 目标必须在当前图的 neighbors 中 |
| 解锁 | 目标级别 ≤ 已通关最高级别 + 1 |
| 母港 | 始终可回 |

## 4. 地图命名

显示名改为「级别-序号 + 归属」，例如：

    1-1 澜国水域
    1-2 澜国水域
    2-1 澜国水域
    2-3 交界海域
    10-3 玄礁海盗水域

让玩家一眼看出所处级别，避免误入高级海域。

## 5. 交互

走到前进航门按 E → 弹出「选择航线」面板，列出相邻海域：

    1-2 澜国水域    1 级   [前往]
    1-3 澜国水域    1 级   [前往]
    2-1 澜国水域    2 级   [未解锁]

## 6. 验收

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 同级三图两两相邻 | ✅ |
| 2 | 跨级三对三相连 | ✅ |
| 3 | 母港邻接 1 级 | ✅ |
| 4 | 同级相邻图可直接前往 | ✅ |
| 5 | 未通关时上级海域锁定 | ✅ |
| 6 | 通关后上级解锁 | ✅ |
| 7 | 地图显示名为「级别-序号」 | ✅ |
