# 1.4.17 升级说明（强化失败：铁矿键不匹配）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.4.16 |
| 目标版本 | **1.4.17** |
| 状态 | 已发布（2026-11-20） |
| 功能组 | 修复模块强化永远提示铁矿不足；失败原因可见 |

## 1. 根因

| 项 | 值 |
|---|---|
| 开局发放 | `warehouse[&"iron_ore"]`（铁矿，商品 id 为 iron_ore） |
| 强化检查 | `warehouse.get("iron")`（不存在的键） |
| 结果 | 永远判定「铁矿不足（需要 18）」，强化静默失败并关闭弹窗 |

## 2. 修复

| # | 修复 |
|---|---|
| 1 | 强化消耗映射 `iron → iron_ore` |
| 2 | `START_RES` 键统一为 `iron_ore` |
| 3 | 强化失败时**不关闭弹窗**，在弹窗内红字显示失败原因 |

## 3. 验收

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 开局直接强化风帆成功 | ✅ |
| 2 | 等级变为 1 | ✅ |
| 3 | 1 级船第二次强化被上限拒绝 | ✅ |
| 4 | 失败原因在弹窗内可见 | ✅（代码路径） |

**测试**：66 单元 + 1023 集成
