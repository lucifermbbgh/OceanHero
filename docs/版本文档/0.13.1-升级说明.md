## 2. 需求

### 2.1 全屏独占

| 项 | 规则 |
|---|---|
| 尺寸 | 顶部状态栏以下完全占满（约 1600×820） |
| 背景 | 不透明底板，**看不到背后的港口场景** |
| 关闭 | 右上角「关闭」按钮或 ESC |

### 2.2 表格化（本地市场）

| 商品 | 买价 | 卖价 | 周涨跌 | 库存 | 船上 | 仓库 | 操作 |
|---|---|---|---|---|---|---|---|
| 谷物 | 14 | 12 | ↑1% | 190 | 10 | 0 | 买10/卖10/→仓/→船/明细 |

**周涨跌列规则**

| 情况 | 显示 |
|---|---|
| 首次进入、没有上周数据 | `—`（灰色） |
| 变动绝对值 < 0.5% | `持平`（灰色） |
| 上涨 | `↑N%`（绿） |
| 下跌 | `↓N%`（红） |

### 2.3 价格明细（提前实现最简版）

点某商品行的「明细」，展开该价格的推导：

    谷物 买价明细
    基础价            10
    库存弹性(0.35)    +3      库存 190/400（48%）
    事件倍率 ×1.00    +0      无事件影响
    市场漂移 ×1.012   +0.2    本周回归后
    ────────────────────────
    最终买价          14

### 2.4 指标可见

在本地市场底部增加一行「本周市场指标」：

| 指标 | 含义 |
|---|---|
| 供给弹性 | 当前库存档位下的弹性系数（0.35/0.55/0.90） |
| 库存比例 | 当前库存 / 满值 |
| 回归速度 | 每周向均衡价靠拢的比例（25%） |
| 漂移倍率 | 当前价格相对公式价的倍率 |
| 生效事件 | 影响本港的事件数量 |

### 2.5 世界市场与事件页签同步表格化

- 世界市场加表头：港口 / 海域 / 距离 / 谷物 / 木材 / 朗姆酒 / 香料 / 趋势
- 事件页签加表头：港口 / 事件 / 影响 / 剩余周数
