# 1.3.10 升级说明（旧三阵营声望清理）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.3.9 |
| 目标版本 | **1.3.10** |
| 状态 | 已发布（2026-11-20） |
| 功能组 | 移除旧三阵营声望的产出与展示，任务奖励改发势力声望 |

## 1. 改动

| 位置 | 之前 | 现在 |
|---|---|---|
| 击沉结算 | 改海军/商会/黑帆声望 | **只改通缉度**，势力声望由 1.3.8 逻辑处理 |
| 任务完成 | 对应阵营 +120 | 对应势力 **+6** |
| 声望面板 | 三阵营列表 + 捐赠 | 提示前往「势力声望」面板 |
| 海面港口面板 | 海军/商会/黑帆数值 | **七大势力声望**概览 |

### 任务阵营映射

| 旧阵营 | 新势力 |
|---|---|
| royal_navy | 当前海图所属国 |
| merchant | 赤鳞 |
| black_sail | 幽溟 |

## 2. 保留

| 项 | 说明 |
|---|---|
| 通缉度 | 仍存于 `reputation` 字典，机制不变（保释、衰减、黑市关闭） |
| 旧函数 | `rep_of` / `add_rep` 保留但无产出，待后续版本彻底删除 |
