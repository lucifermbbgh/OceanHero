# 1.6.2 升级说明（Tiled 世界地图流水线）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.6.1 |
| 目标版本 | **1.6.2** |
| 状态 | 已发布（2026-11-23） |
| 单一功能 | Tiled 源文件 → 构建脚本 → 运行时多边形世界地图 |

## 1. 流水线

| 环节 | 文件 | 说明 |
|---|---|---|
| 编辑源 | `data/source/world_regions.tmj` | 30 个 Polygon 对象，画布 4096×2304 |
| 构建 | `tools/map_pipeline/build_world_map.py` | TMJ → 归一化 JSON（0~1），计算质心 |
| 运行时 | `data/generated/world_regions.json` | 游戏读取 |
| 渲染 | `scripts/ui/world_map.gd` | 多边形向质心内缩 8%，露出海面 |

## 2. 使用方式

| 步骤 | 操作 |
|---|---|
| 1 | 用 Tiled 打开 `data/source/world_regions.tmj` |
| 2 | 拖动多边形顶点调整海域形状 |
| 3 | 保存后运行 `python3 tools/map_pipeline/build_world_map.py` |
| 4 | 游戏内按 M 查看效果 |

## 3. 渲染效果

| 项 | 表现 |
|---|---|
| 已探索 | 势力色填充 + 编号 |
| 未探索 | 深色块 +「?」 |
| 当前海域 | 金色描边 |
| 选中 | 青色描边 + 右侧详情 |
| 航线 | 黄色虚线 |
| 区域间隙 | 内缩 8%，露出深蓝海面 |
