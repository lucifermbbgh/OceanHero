# 1.4.11 升级说明（回归 Penpot 设计稿坐标）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.4.10 |
| 目标版本 | **1.4.11** |
| 状态 | 已发布（2026-11-20） |
| 功能组 | 插槽位置回归设计稿、船影按设计稿比例重绘 |

## 1. 问题定性

1.4.10 我用「自创区域布局」替换了设计稿中的相对位置，导致实现与设计稿跑偏。
**设计稿本身没有问题，是我的实现偏离了约定。**

## 2. 修复

| 项 | 恢复内容 |
|---|---|
| 锚点 | 12 类模块全部回到设计稿相对位置（0~1 归一化） |
| 分层 | 甲板行距 0.121、炮门行距 0.110，按设计稿行距下移 |
| 船影 | 船体 0.46 ~ 0.95，三桅位于 0.213 / 0.463 / 0.713 |
| 斜桅 | 与船首衔接 |

## 3. 设计稿 vs 模型的一处差异（待确认）

| 项 | 设计稿 | 当前模型 |
|---|---|---|
| 风帆槽 | **3 个**（每桅一个） | **1 个**（整船帆具） |

处理建议：把风帆拆成按桅杆分层（1~3 层），每层可单独装帆，属性叠加。

## 4. 验收

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 插槽位置与设计稿一致 | ✅ |
| 2 | 甲板 3 层、炮门 4 层按行距排列 | ✅ |
| 3 | 三桅按设计稿位置绘制 | ✅ |
| 4 | 插槽均在船影范围内（≤0.95） | ✅ |

**测试**：66 单元 + 999 集成
