# 1.4.13 升级说明（清理旧强化/合成/改装）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.4.12 |
| 目标版本 | **1.4.13** |
| 状态 | 已发布（2026-11-20） |
| 功能组 | 删除旧装备强化/合成/改装逻辑，旧入口并入舰船面板 |

## 1. 删除内容

| 旧系统 | 处理 |
|---|---|
| 装备强化（gear_level / gear_upgrade） | 删除实现，改由模块强化承担 |
| 装备合成（gear_combine） | 删除，调用返回「已移除」 |
| 船只改装（ship_mods / mod_cannon / mod_sail） | 删除实现 |
| 侧栏「装备强化」「船只改装」入口 | 移除，点击旧入口跳转舰船面板 |

## 2. 兼容层

| 接口 | 行为 |
|---|---|
| `mod_sail()` | 转发为强化风帆模块 |
| `mod_cannon()` | 转发为强化炮门模块 |
| `gear_upgrade(gid)` | 按装备槽找到模块并强化 |
| `gear_level_of(gid)` | 返回对应模块等级 |
| `gear_combine(...)` | 返回失败「合成已移除」 |

## 3. 顺带修复

| # | 问题 | 修复 |
|---|---|---|
| 1 | `reset_new_game()` 未清空模块等级与模块船员 | 开局显式清空 |
| 2 | 读档缺模块等级字段 | 从 `module_levels` 读取，缺省为空 |

## 4. 验收

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 旧强化/改装接口转发到模块 | ✅ |
| 2 | 装备合成返回已移除 | ✅ |
| 3 | 旧入口跳转舰船面板 | ✅ |
| 4 | 新开档模块等级为 0 | ✅ |
