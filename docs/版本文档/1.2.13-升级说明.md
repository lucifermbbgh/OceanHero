# 1.2.13 升级说明（面板重复叠加修复）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.2.12 |
| 目标版本 | **1.2.13** |
| 状态 | 已发布（2026-11-18） |
| 单一功能点 | 修复面板操作后内容重复叠加 |

## 1. 问题

在银行面板点「存入 1000」，面板会在下方**再复制一整套内容**，点几次叠几套。

## 2. 根因

两处叠加：

| 层 | 原因 |
|---|---|
| 调用层 | `_bank_deposit()` 等操作直接调 `_rebuild_bank_rows()`，而该函数**不清空**旧节点，只追加 |
| 引擎层 | 清空循环里只用 `queue_free()`，它是**延迟删除**，同一帧内紧接着 `add_child()` 会出现新旧并存 |

## 3. 修复

| 改动 | 说明 |
|---|---|
| `_rebuild_bank_rows()` 自清空 | 所有入口都先清空再重建，不再依赖调用方 |
| 清空改为 `remove_child + queue_free` | 立刻摘出树，避免延迟删除导致的叠加 |
| 全量排查 | 20 处「清空后重建」统一改为同一写法 |

## 4. 验收

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 连续 3 次存款，行数不变 | ✅ |
| 2 | 黑市重建不叠加 | ✅ |
| 3 | 仓库重建不叠加 | ✅ |

**测试**：66 单元 + 746 集成
