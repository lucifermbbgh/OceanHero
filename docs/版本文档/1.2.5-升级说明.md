# 1.2.5 升级说明（城镇等级门禁）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.2.4 |
| 目标版本 | **1.2.5** |
| 状态 | 已发布（2026-11-18） |
| 单一功能点 | 菜单按当前城镇等级显示可用功能 |

## 1. 门禁表

| 功能 | 港村 | 港镇 | 港城 |
|---|---|---|---|
| 市场 / 酒馆 / 任务 / 仓库 / 船员 / 装备 / 改装 | ✅ | ✅ | ✅ |
| 船厂与装备 | ❌ | ✅ | ✅ |
| 交易所 / 声望 / 拍卖 / 银行 / 黑市 | ❌ | ❌ | ✅ |
| 基地建设（建造） | 仅母港 | 仅母港 | 仅母港 |
| 投资 | 岛屿 | 岛屿 | 岛屿 |

实现：`GameState.visit_has(service)` 按 `visit_port_tier()` 判定，
菜单不再用写死的 `home_has()`。

## 2. 顺带修复

| 项 | 问题 | 修复 |
|---|---|---|
| 1 | 靠近航门时若附近有沉船残骸，提示被残骸抢占 | 航门提示优先于打捞提示 |

## 3. 验收

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 港城提供交易所/银行/黑市 | ✅ |
| 2 | 港村无交易所、无船厂 | ✅ |
| 3 | 港镇有船厂、无银行 | ✅ |
| 4 | 非母港不能建造 | ✅ |
| 5 | 母港可建造 | ✅ |
| 6 | 航门提示优先于打捞 | ✅ |

**测试**：66 单元 + 704 集成
