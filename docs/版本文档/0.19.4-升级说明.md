# 0.19.4 升级说明（经济总览分页表格）

| 项 | 内容 |
|---|---|
| 基线版本 | 0.19.3 |
| 目标版本 | 0.19.4 |
| 状态 | 已发布（2026-11-18） |
| 主题 | 经济总览改为六页签表格，默认周利润表 |

## 1. 结构

    经济总览
      [年资产负债表] [年利润表] [周利润表] [上年资产负债表] [上年利润表] [上周利润]

默认展示**周利润表**，六个页签全部为带边框表格。

| 页签 | 数据来源 | 说明 |
|---|---|---|
| 年资产负债表 | 实时库存估值 + 现金/存款/贷款 | 资产 = 现金+存款+库存；净资产 = 资产−负债 |
| 年利润表 | finance.income / expense | 本年累计收入与成本 |
| **周利润表**（默认） | weekly_upkeep + week_income/expense | 本周成本与收入，净利 = 收入−成本 |
| 上年资产负债表 | reports[0] | 上一年年末快照 |
| 上年利润表 | reports[0].income/expense | 上一年累计 |
| 上周利润 | last_week_income/expense | 上周交易与维护 |

## 2. 数据支撑

新增周账目滚动：

    week_income / week_expense     本周累计
    last_week_income / week_expense 上周快照（周结算时滚动）
