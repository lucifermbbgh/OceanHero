# 1.6.12 真·海图母版 v3（AI 艺术底图 + 导航叠加）

| 项 | 内容 |
|---|---|
| 日期 | 2026-11-26 |
| 产物 | `art/world_map/master_chart_v3.png`（2048×1152） |
| 底图 | `art/world_map/chart_base_v3.png`（无叠加，供游戏使用） |

## 1. 管线（先画后拆）

| 步骤 | 内容 |
|---|---|
| 1 | ComfyUI 生成俯视彩色海图（ai_map_try3，分形海岸/浅滩环/森林沙漠） |
| 2 | 颜色分类提取陆地掩膜（tan/green vs teal） |
| 3 | 掩膜按区域裁剪 → 每海域岛屿列表（52 座） |
| 4 | 区域锚点若落陆地则螺旋外移到海面 |
| 5 | 叠加导航层：节点+势力环、实/虚航路、编号、分级、图例、罗盘、标题、比例尺、边框 |

## 2. 与之前版本的差别

| 项 | v1/v2（色块） | v3（真海图） |
|---|---|---|
| 海岸线 | 平滑 blob | AI 分形海岸 + 浅滩环 |
| 陆地内容 | 纯色 | 森林/沙漠/山脉纹理 |
| 海面 | 程序噪声 | AI 刻线海纹 |
| 信息层 | 色块主导 | 细线导航符号主导 |

## 3. 游戏接入计划（下一步）

| 项 | 做法 |
|---|---|
| 世界地图底图 | chart_base_v3.png |
| 命中/迷雾 | land_mask_v2.png 像素判定 |
| 海域岛屿 | region_islands.json 驱动海面场景与小地图 |
| 小地图 | 裁剪世界底图当前区域 + 玩法标记 |
