## 1. 问题

当前 `GameState.buildings` 是全局单份数据：

- 在岛屿城镇界面看到的总督府/仓库，实际是**母港**的建筑
- 岛屿画面上画出来的建筑与岛屿无关

## 2. 方案

    building_levels: {port_key: {building_id: level}}

| 项 | 规则 |
|---|---|
| 数据结构 | 按港口 key 分桶 |
| 母港 | key = jadehaven |
| 岛屿 | key = 岛屿 key（m1_island0 等） |
| 读取 | building_level(bid) 默认读当前访问港口 |
| 兼容 | 旧存档 buildings 迁移为 jadehaven 分桶 |

## 2.1 实际完成

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 母港与岛屿建筑等级互不影响 | ✅ 分桶存储 |

| 3 | 建造/升级影响当前港口 | ✅ |
| 4 | 旧存档自动迁移 | ✅ 读档恢复分桶，缺省建母桶 |
