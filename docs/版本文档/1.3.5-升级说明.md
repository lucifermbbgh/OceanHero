# 1.3.5 升级说明（势力巡逻队与轻量交战）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.3.4 |
| 目标版本 | **1.3.5** |
| 状态 | 已发布（2026-11-19） |
| 功能组 | 按海图归属生成巡逻队、敌对势力轻量交战、击沉无掉落 |

## 1. 设计约定

| 项 | 决定 |
|---|---|
| 模拟范围 | 仅当前海图，离图销毁，不做后台模拟 |
| 交战方式 | 每秒互扣血（轻量结算），不做完整舰队 AI |
| 战利品 | **不产生**，避免海上物品爆量 |
| 玩家 | 本版不参与（1.3.6 再开放） |

## 2. 巡逻队配置

| 海图类型 | 队伍 |
|---|---|
| 腹地（单国） | 该国 2 队 |
| 交界（两国） | 每国 2 队，共 4 队 |
| 争夺（三国） | 每国 2 队，共 6 队 |
| 海盗水域 | 2 队 |

**交界图国家分配**

| 图 | 国家 |
|---|---|
| 6 | 澜国 × 赤鳞 |
| 15 | 玄礁 × 白鲸 |
| 24 | 苍梧 × 白鲸 |
| 28 | 澜国 × 玄礁 × 霜屿 |
| 29 | 赤鳞 × 苍梧 × 白鲸 |

## 3. 交战规则

| 项 | 规则 |
|---|---|
| 索敌 | 420 像素内最近的敌对国巡逻队 |
| 敌对 | 依据 1.3.3 的国家关系矩阵 |
| 开火 | 每秒一次，伤害 = 炮数 × 6 |
| 沉没 | 血量归零即移除，**无金币、无货物** |
| 中立 | 同图两国若为中立/同盟则互不攻击 |

## 4. 实现

| 文件 | 职责 |
|---|---|
| scripts/sea/patrol_ship.gd | 巡逻舰实体：航线巡航、索敌、开火、血条 |
| scripts/sea/sea_scene.gd | 按配置生成/清理巡逻队 |
| scripts/core/game_state.gd | patrol_config_for_map、NATION_COLORS |
