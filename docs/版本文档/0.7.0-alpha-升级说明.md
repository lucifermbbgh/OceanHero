# 0.7.0-alpha 升级说明

| 项 | 内容 |
|---|---|
| 基线版本 | 0.6.0-alpha |
| 目标版本 | 0.7.0-alpha |
| 状态 | ✅ 已发布（2026-11-17，commit b51a9d4） |
| 主题 | 岛屿三级、港口分级、边缘换图 |
| 测试 | 65 单元 + 366 集成 |

## 1. 背景

所有岛屿规格一模一样且只是装饰；航门切换不符合原作；采集玩法与「港口」定位重复。

## 2. 需求与实现

- 岛屿三级：渔港村落(240~320) / 乡镇(360~450) / 港口城市(500~620)
- 每张图 1 城 + 1 镇 + 其余村落，每岛有名字与特产
- 靠岸（岛半径 +160px 内）按 E 停靠任意岛屿港口
- 市场只卖 谷物 + 木材 + 本岛特产，存货按等级 40/90/160
- 废弃岛屿采集功能
- 取消固定航门：驶到任意边界即切图
- 东出→新图西侧、南下→新图北侧，另一轴坐标保持不变
- 前进需击败当前海域 Boss，回退无限制
- 战斗系统冻结：Boss/海怪不加技能，差异只靠装备与属性
- 新增美术资源开发设计文档

## 3. 验收结果

- 边缘带提示：「向东继续航行即可进入 XX」/「击败本图 Boss 才能通航」
- 文档体系合并为四份主文档 + 版本文档目录

## 4. 影响范围

`scripts/sea/sea_scene.gd、docs/`

## 5. 遗留问题

三级港口服务尚未分级；母港没有成长线
