# 1.6.20 升级说明（船员头像 24 枚）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.6.19 |
| 目标版本 | **1.6.20** |
| 状态 | 已发布（2026-11-28） |
| 单一功能 | 船员头像 24 枚（4 岗位 × 6 面孔）生产与接入 |

## 1. 生产

| 项 | 内容 |
|---|---|
| 模型 | DreamShaper 8（工作流 `39fcfc2b`），512×640，26 步，CFG 默认 |
| 提示词骨架 | `painterly game character portrait, bust of <look>: 18 世纪中国海盗 <岗位>, <衣着/道具>, dramatic warm side light, muted dark teal background, head and shoulders, centered, oil painting` |
| 负面 | text / watermark / signature / frame / border / banner / panel / grid / collage / multiple views / logo |
| 出图 | 24 张逐张串行，约 14s/张（未并发） |
| 处理 | 512×512 方裁（纵向偏移 40px）→ LANCZOS 256×256；保留油画背景，不做抠底 |
| 产物 | `art/icons/crew/crew_<post>_<look>.png` 24 枚 + `_contact.png` 联系表 |
| 源图 | `art/source/crew_<post>_<look>.png` |
| 工具 | `tools/map_pipeline/process_crew_portraits.py` |

岗位与面孔：`mate`（大副）/ `gunner`（炮手）/ `surgeon`（船医）/ `sailor`（水手），每岗位 6 种长相。

## 2. 选脸规则

| 项 | 规则 |
|---|---|
| 面孔索引 | `CrewPortrait.look_of(c)` = `posmod(hash(姓名|id), 6)`，同一船员恒定同一张脸 |
| 岗位映射 | 岗位名即目录名；`collector` 复用大副、`raider` 复用炮手，未知岗位回落水手 |
| 稀有度 | 不占用面孔（游戏只有 5 档稀有度），改为头像 2px 外框色（`Rarity.color`） |

## 3. 接入

| 页面 | 表现 |
|---|---|
| 陆上酒馆「名册」 | 行首 40px 头像 |
| 陆上酒馆「招募」 | 行首 40px 头像 |
| 船员名单面板 | 行首 40px 头像；角色列改中文岗位，稀有度列改名称并按稀有度上色 |
| 海上港口酒馆 | 行首 36px 头像 |

新增脚本 `scripts/ui/crew_portrait.gd`（静态缓存贴图 + 生成头像控件），
`base_scene.gd` / `sea_scene.gd` 各接入。

## 5. 备注

- 头像未抠底：深色油画背景与面板底色接近，在行内呈"卡片"效果；如需透明头像，后续按白底重出。
