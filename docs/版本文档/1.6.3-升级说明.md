# 1.6.3 升级说明（海图底图 + 有机区域）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.6.2 |
| 目标版本 | **1.6.3** |
| 状态 | 已发布（2026-11-23） |
| 单一功能 | 程序绘制海图底图 + Voronoi 有机海域 + Tiled 蒙板 |

## 1. 做法（按「先画地图再拆分」）

| 步骤 | 内容 |
|---|---|
| 1 | Python/PIL 绘制海图底图（深蓝海、羊皮纸大陆、岛屿、罗盘、边框） |
| 2 | 用 30 个种子做 Voronoi 切分，生成有机海域多边形 |
| 3 | 写入 `data/source/world_regions.tmj`（Tiled 可编辑蒙板） |
| 4 | `build_world_map.py` 转归一化 JSON |
| 5 | Godot 叠加：底图 + 半透明区域 + 虚线航线 |

## 2. 效果

| 项 | 表现 |
|---|---|
| 底图 | 2048×1152 程序海图（可替换为 AI 图） |
| 区域 | 有机多边形，已探索淡色填充，未探索暗色 |
| 区域边界 | 细线，缩放/拖拽时与底图同步 |
| 当前/选中/航线 | 金框 / 青边 / 黄虚线 |

## 3. 已知问题

| # | 问题 | 后续 |
|---|---|---|
| 1 | 海域多边形覆盖到陆地上方 | 需要用陆地蒙板裁剪区域（多边形布尔运算） |
| 2 | 底图是程序占位图，非最终美术 | 1.6.4 用 AI/手绘替换 |
| 3 | 未探索区域仍显示边界线 | 可改为仅显示海面底图 |
