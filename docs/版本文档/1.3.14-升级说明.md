# 1.3.14 升级说明（巡逻队按声望敌对玩家）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.3.13 |
| 目标版本 | **1.3.14** |
| 状态 | 已发布（2026-11-20） |
| 功能组 | 势力声望跌到死敌/敌对时，该势力巡逻队主动攻击玩家 |

## 1. 规则

| 声望档位 | 巡逻队行为 |
|---|---|
| 死敌（-100~-76） | **主动攻击玩家** |
| 敌对（-75~-51） | **主动攻击玩家** |
| 敌视及以下 | 不主动攻击 |

攻击判定：距离 420 像素内，每秒造成 炮数×3 的船体伤害。

## 2. 实现

| 项 | 说明 |
|---|---|
| 玩家入组 | `player` 加入 group，供巡逻队索敌 |
| 索敌优先 | 玩家敌对时优先锁定玩家，否则找敌对巡逻队 |
| 伤害 | 复用 `take_damage` 的船体伤害通道 |

## 3. 验收

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 玩家已入组 | ✅ |
| 2 | 中立势力不攻击玩家 | ✅ |
| 3 | 死敌势力攻击玩家并造成伤害 | ✅ |

## 4. 未做（后续）

| 项 | 说明 |
|---|---|
| 玩家主动攻击巡逻队 | 需把巡逻队纳入玩家可锁定目标列表 |
| 巡逻队被击沉后的声望连带 | 已由 1.3.8 逻辑覆盖（若玩家攻击） |

**测试**：66 单元 + 885 集成
