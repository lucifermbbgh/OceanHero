# 1.4.4 升级说明（船员按模块归属）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.4.3 |
| 目标版本 | **1.4.4** |
| 状态 | 已发布（2026-11-20） |
| 功能组 | 岗位简化为 4 类、船员安排到模块槽 |

## 1. 岗位简化

| 之前 8 类 | 现在 4 类 |
|---|---|
| 舵手 / 水手长 / 操帆长 / 瞭望员 / 木匠 | **水手** |
| 大副 | **大副** |
| 炮手 | **炮手** |
| 军医 | **船医** |

生成权重：水手 5 / 炮手 2 / 大副 1 / 船医 1。

## 2. 模块岗位归属

| 模块 | 接受岗位 |
|---|---|
| 舵轮 | 大副 |
| 炮门 | 炮手 |
| 医疗室 | 船医 |
| 甲板 / 宿舍 / 风帆 / 瞭望台 / 厨房 / 仓库 / 工坊 | 水手 |
| 旗杆 / 船长室 | 不设岗位 |

## 3. 接口

| 接口 | 说明 |
|---|---|
| `assign_crew_to_module(crew_id, mid, layer)` | 安排船员，校验岗位与占位 |
| `clear_module_crew(mid, layer)` | 撤离 |
| `module_crew_of(mid, layer)` | 查询 |
| `assigned_crews()` | 合并旧列表与模块船员（去重） |

### 规则

| 规则 | 说明 |
|---|---|
| 岗位匹配 | 模块不接受该岗位时拒绝 |
| 唯一占位 | 一名船员只能占一个模块 |
| 不设岗位 | 旗杆 / 船长室拒绝任何船员 |

## 4. 验收

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 生成岗位只含四类 | ✅ |
| 2 | 水手不能进炮门 | ✅ |
| 3 | 炮手可进炮门 | ✅ |
| 4 | 同一船员不能占两槽 | ✅ |
| 5 | 仓库不设岗位 | ✅ |
| 6 | 在岗船员计入 stats | ✅ |
| 7 | 可撤离 | ✅ |
