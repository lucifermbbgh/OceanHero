# 0.8.0-alpha 升级说明

| 项 | 内容 |
|---|---|
| 基线版本 | 0.7.0-alpha |
| 目标版本 | 0.8.0-alpha |
| 状态 | ✅ 已发布（2026-11-17） |
| 主题 | 三级港口的功能分级 + 母港成长线 |

## 1. 背景

0.7 让岛屿有了三级结构（渔港村落 / 乡镇 / 港口城市），但三级之间的**服务没有差别**——
无论停靠哪种岛，打开的面板都一样。母港也仍然是一开始就全功能的状态。

本版本解决这两件事：让等级真正有意义，让母港从渔村成长起来。

## 2. 需求

### 2.1 港口服务按等级开放

| 服务 | 渔港村落 | 乡镇 | 港口城市 |
|---|---|---|---|
| 维修 | ✅ | ✅ | ✅ |
| 市场（谷物/木材/特产） | ✅ | ✅ | ✅ |
| 任务交付 | ✅ | ✅ | ✅ |
| 本地换船 | ✅ | ✅ | ✅ |
| 船厂（买船/装备） | ❌ | ✅ | ✅ |
| 酒馆（招募船员） | ❌ | ✅ | ✅ |
| 交易所（订单/期货） | ❌ | ❌ | ✅ |
| 声望与战功 | ❌ | ❌ | ✅ |

未开放的服务**不显示入口**（而不是显示后禁用）。

### 2.2 母港成长线

| 阶段 | 名称 | 升级条件 | 解锁 |
|---|---|---|---|
| Lv1 | 渔港村落（开局） | — | 维修、市场、酒馆、任务板 |
| Lv2 | 乡镇 | 5,000 金 + 100 木材 + 50 铁矿 | + 船厂与装备、基地建设 |
| Lv3 | 港口城市 | 30,000 金 + 400 木材 + 200 铁矿 | + 交易所、声望与战功 |

- 升级入口在母港左侧按钮区（「帮助」上方），条件不足时显示所需资源
- 升级后新面板立即出现，不需要重进场景

### 2.3 岛屿港口 UI 统一

现在岛屿港口（sea_scene 内）与母港（base_scene）是两套独立 UI。
本版本抽出公共组件：标题栏 / 资源行 / 商品行 / 服务按钮，两边复用。

### 2.4 特产价格差异化

同一特产在不同等级港口的买价不同：

```
渔港村落  基础价 ×1.20
乡镇      基础价 ×1.00
港口城市  基础价 ×0.85
```

形成「小岛贵、大城便宜」的贸易路线，配合原有的库存浮动。

## 3. 验收标准

| # | 验收点 |
|---|---|
| 1 | 停靠村庄级港口时，面板里没有船厂/酒馆/交易所/声望入口 |
| 2 | 停靠乡镇级港口时，船厂与酒馆出现，交易所仍不存在 |
| 3 | 停靠城市级港口时，四个高级入口全部出现 |
| 4 | 母港初始为渔港村落，只能看到维修/市场/酒馆/任务板 |
| 5 | 资源满足后点升级，母港变乡镇，船厂与建设面板出现 |
| 6 | 再升级到港口城市后，交易所与声望出现 |
| 7 | 同一特产在村/镇/城三处的买价呈递减梯度（差异 ≥ 15%） |
| 8 | 全部旧存档能正常读取（缺字段时按 Lv3 兼容，避免老玩家被降级） |

## 3.1 实际完成情况

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 村庄级港口无船厂/酒馆/交易所/声望入口 | ✅ 未解锁的入口不显示 |
| 2 | 乡镇级出现船厂与酒馆，无交易所 | ✅ 船厂可购炮并换装、酒馆可雇人 |
| 3 | 城市级四个高级入口全部出现 | ✅ 交易所显示本港行情、声望显示三轴数值 |
| 4 | 母港初始为渔港村落 | ✅ 只显示 维修/市场/酒馆/任务板 |
| 5 | 升级到乡镇后船厂与建设面板出现 | ✅ 重新进入母港后生效 |
| 6 | 升级到城市后交易所与声望出现 | ✅ |
| 7 | 三级特产价格递减梯度 ≥15% | ✅ 1.20 / 1.00 / 0.85（村比城贵 41%） |
| 8 | 旧存档可读（缺字段按 Lv3） | ✅ 已实现并有测试覆盖 |

**测试**：65 单元 + 394 集成（新增 28 项）

### 实现说明

- 岛屿港口的船厂/酒馆/交易所/声望是**真实可用**的简化版，不是占位：
  船厂可购炮并直接换装，酒馆可雇佣（3 名候选），交易所显示本港三件商品行情，声望显示三轴与战功
- 母港升级按钮常驻左侧菜单末位，条件不足时显示所需资源
