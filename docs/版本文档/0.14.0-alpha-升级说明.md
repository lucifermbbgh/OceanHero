## 1. 背景

0.13 让价格会动了，但玩家仍然**看不出该不该买**：

- 只有一个瞬时价格和涨跌箭头，看不出趋势
- 不知道买多少才算划算（买了会不会砸手里）
- 商品之间的联动（朗姆酒涨了，香料会怎样）还没有

本版把「该不该做这笔交易」变成界面上可以直接读到的结论。

## 2. 需求

### 2.1 价格历史走势线（E10）

| 项 | 规则 |
|---|---|
| 数据 | 每港口每商品保留最近 **8 周**的价格 |
| 存储 | 环形缓冲，int 数组 |
| 展示 | 本地市场商品行，宽 80px 的折线 |
| 颜色 | 相对首周上涨红色、下跌绿色（与涨跌列一致） |
| 空数据 | 不足 2 周时显示「—」 |

### 2.2 边际利润提示（E3 · 含货舱余量）

**算法**

    可用容量 = 货舱上限 − 当前载货
    可买数量 = min(可用容量 / 单位体积, 该港库存)
    对每件：MP = 目标港卖价 − 本港买价
    累计到 MP ≤ 0 或达到可买数量

**展示（世界市场每行末尾）**

| 情况 | 显示 |
|---|---|
| 全程为正 | `还能吃进 N 件`（绿） |
| 中途转负 | `再买 M 件后不划算`（黄） |
| 一开始就负 | `不划算`（红） |
| 容量为 0 | `货舱已满`（灰） |

### 2.3 交叉弹性（E4）

| 项 | 规则 |
|---|---|
| 关系表 | 替代品 / 互补品，每条带系数 |
| 触发 | 某商品周涨跌超过 ±5% 时，影响关联商品 |
| 强度 | 传导值 = 涨跌幅 × 交叉系数（上限 ±8%） |
| 范围 | 仅同港口，不跨港传导 |

**首批关系**

| A | B | 关系 | 系数 |
|---|---|---|---|
| 朗姆酒 | 香料 | 互补（一起消费） | 0.4 |
| 谷物 | 朗姆酒 | 替代（都能填肚子） | -0.3 |
| 木材 | 铁矿 | 互补（都要建房） | 0.2 |

### 2.4 指标透明化扩展（承接 0.13.1）

| 位置 | 新增 |
|---|---|
| 世界市场行 | 「评估」按钮 → 展开预计成本/营收/净利/ROI |
| 市场底部 | 指标行增加「弹性类型」（富有/单位/缺乏） |

## 3. 验收标准

| # | 验收点 |
|---|---|
| 1 | 每港每商品保留 8 周历史，跨周追加 |
| 2 | 本地市场商品行显示 8 点折线，涨红跌绿 |
| 3 | 不足 2 周数据显示「—」 |
| 4 | 世界市场每行显示边际提示 |
| 5 | 边际提示按货舱余量计算（载满时显示「货舱已满」） |
| 6 | 边际利润逐件累加计算，转负即停 |
| 7 | 交叉弹性在商品涨跌超 ±5% 时传导到关联商品 |
| 8 | 传导幅度不超过 ±8% |
| 9 | 交叉关系可在 BalanceConfig 调整 |
| 10 | 历史与交叉配置进存档（历史随时间滚动） |
