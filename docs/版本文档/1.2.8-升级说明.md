# 1.2.8 升级说明（市场库存上限统一）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.2.7 |
| 目标版本 | **1.2.8** |
| 状态 | 已发布（2026-11-18） |
| 单一功能点 | 市场库存上限统一按当前城镇等级 |

## 1. 问题

| 位置 | 旧值 | 后果 |
|---|---|---|
| 岛屿市场 | 800（无港口定义时的兜底） | 港村岛库存按 800 算，远超 40 的设计值 |
| 本周指标行 | 硬编码 400 | 与市场表不一致 |

结果：同一商品在表格里显示库存 320，指标行却按 400 满值算弹性，两头对不上。

## 2. 修复

四处库存上限统一改为 `GameState.visit_port_max_stock()`：

| 城镇等级 | 上限 |
|---|---|
| 港村 | 40 |
| 港镇 | 90 |
| 港城 | 160 |

## 3. 验收

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 市场表格库存与等级上限一致 | ✅ |
| 2 | 指标行弹性按同一上限计算 | ✅ |
| 3 | 商品弹窗与市场一致 | ✅ |
| 4 | 世界市场行一致 | ✅ |

**测试**：66 单元 + 713 集成
