# 1.2.14 升级说明（移除交易所）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.2.13 |
| 目标版本 | **1.2.14** |
| 状态 | 已发布（2026-11-18） |
| 单一功能点 | 删除交易所功能 |

## 1. 决策

| 判断 | 理由 |
|---|---|
| 行情无用 | 商品本身「越远越贵」，加上市场事件已经提供远地机会，全量行情属于信息噪音 |
| 远洋订单与任务板重合 | 都是「带货到某地」，两者并存只会让玩家困惑该走哪条路 |
| 期货过度设计 | 单机小体量游戏不需要金融衍生品；银行 + 投资已覆盖金融需求 |
| 大宗交易重复 | 与市场批量买卖是同一件事 |

**结论**：整个交易所功能删除。

## 2. 删除内容

| 项 | 处理 |
|---|---|
| 左侧菜单「交易所」入口 | 移除 |
| 交易所面板（行情/远洋订单/大宗交易/期货） | 移除 |
| 相关函数（9 个）与常量（EX_TABS） | 移除 |
| 港城服务门禁中的 exchange 判定 | 菜单不再调用 |

## 3. 保留项（需说明）

「交易所」作为**建筑**仍然存在，效果是每级 +3% 卖出价。
它现在是纯被动加成建筑，没有面板入口。

> 后续可考虑改名为「商会」，使名称与作用一致（另开补丁）。
