## 1. 设计要点

| 元素 | 做法 |
|---|---|
| 深海 | 深蓝平涂 + 细横纹 |
| 浅滩 | 岛屿外围双层描边环（MID + SHALLOW） |
| 陆地 | 米白平涂 + 深色海岸线 |
| 海域节点 | 琥珀圆点 + **势力色外环** |
| 航路 | 同层实线 / 跨层虚线 |
| 区域边界 | 细虚线（弱化） |
| 图例 | 左下角，六项符号说明 |
| 罗盘 | 左上角 |
| 标题 | 顶部饰框 |
| 方向/比例尺 | N/E/S/W + 10 里标尺 |
