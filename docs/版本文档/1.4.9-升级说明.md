# 1.4.9 升级说明（换船入口与面板版面优化）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.4.8 |
| 目标版本 | **1.4.9** |
| 状态 | 已发布（2026-11-20） |
| 功能组 | 舰船面板内换船入口、版面放大、船影随船级增厚 |

## 1. 换船入口

| 项 | 说明 |
|---|---|
| 之前 | 只能在「船厂与装备 → 本港船队」换乘，且需要港口等级 ≥ 港镇 |
| 现在 | 舰船面板右侧新增「更换船只」按钮，列出本港停泊船只 |
| 无船时 | 提示「本港没有其他船只，可前往港镇以上的船厂购买」 |

**与建筑的关系**：换船不绑定建筑，绑定的是**港口等级**（船厂服务在港镇及以上开放）。

## 2. 版面调整

| 项 | 之前 | 现在 |
|---|---|---|
| 船模区 | 940 × 600 | **1150 × 690** |
| 属性栏 | 360 宽 | 320 宽 |
| 船体高度 | 固定 | 随船级增加（最高 +6%） |
| 甲板线 | 固定 3 条 | 随船级 1~4 条 |

## 3. 验收

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 面板内有「更换船只」按钮 | ✅ |
| 2 | 无船时显示提示 | ✅ |
| 3 | 10 级船四层炮门插槽不重叠 | ✅ |
| 4 | 插槽仍位于船体轮廓内 | ✅ |

**测试**：66 单元 + 995 集成
