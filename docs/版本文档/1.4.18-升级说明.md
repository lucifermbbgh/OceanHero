# 1.4.18 升级说明（每船独立模块与满级显示）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.4.17 |
| 目标版本 | **1.4.18** |
| 状态 | 已发布（2026-11-20） |
| 功能组 | 模块状态随船独立、换船自动封存、满级按钮、声望/修理加成 |

## 1. 每船独立模块

| 项 | 之前 | 现在 |
|---|---|---|
| 模块等级 | 全局共享 | **随船独立** |
| 模块船员 | 全局共享 | 随船独立 |
| 换船 | 装备随船，模块不随 | 等级/船员/装备一并封存到原船，读取目标船 |
| 船库存档 | 只存装备 | 增加 `module_levels` / `module_crew` |

## 2. 满级显示

| 状态 | 按钮 |
|---|---|
| 未满级 | 「强化」可点 |
| 已满级 | 「已满级」灰色禁用 |

## 3. 未引用模块的接入情况

| 模块 | 效果 | 接入 |
|---|---|---|
| 旗杆 | 声望获取 +5%/级 | ✅ 正向声望增益乘算 |
| 工坊 | repair_bonus +10%/级 | ✅ 修理费最高减免 50% |
| 医疗室 | heal_bonus | ⬜ 待接入战后恢复 |
| 厨房 | recover_bonus | ⬜ 待接入每周船员恢复 |

## 4. 验收

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 换乘后读取目标船模块等级 | ✅ |
| 2 | 原船强化不带入新船 | ✅ |
| 3 | 换回原船保留强化 | ✅ |
| 4 | 满级按钮灰显 | ✅（代码路径） |
| 5 | 声望/修理加成生效 | ✅ |
