## 1. 背景

0.13~0.14 解决了「价格怎么动」和「该不该买」，但还缺两块：

- **收入看得见，成本看不见**：玩家只知道修船花了多少，不知道养船每周要花多少
- **大港为什么便宜说不清**：现在只有「村 1.20 / 镇 1.00 / 城 0.85」三个数，没有解释
- **投资越投越不划算**这件事没被量化**

本版把成本侧补齐，并让规模效应与投资回报变成可计算的曲线。

## 2. 需求

### 2.1 E5 成本结构（固定 + 可变）

**周维护费 = 固定成本 + 可变成本**

| 成本项 | 类型 | 公式 |
|---|---|---|
| 船体维护 | 固定 | 船级基础值 × (1 + 损伤率) |
| 停泊费 | 固定 | 所在港口等级：村 5 / 镇 15 / 城 40 |
| 船员薪酬 | 可变 | 船员数 × 职级工资 |
| 火炮维护 | 可变 | 炮数 × 每门维护 |

**每周结算展示**

    本周维护：420 金
      船体维护  180（三级战列舰基础 150 + 损伤 20%）
      停泊费     40（港口城市）
      船员薪酬  150（12 人）
      火炮维护   50（50 门）

**经济含义**

| 指标 | 说明 |
|---|---|
| 固定成本 FC | 不随规模变化的那部分（船体 + 停泊） |
| 可变成本 VC | 随规模变化（船员 + 火炮） |
| 平均成本 AC | (FC + VC) / 船员数 |
| 沉没成本 | 已花的修理费、建造费，界面上标注为「已投入，不影响决策」 |

### 2.2 E6 规模报酬曲线

**港口吞吐量 = 基础吞吐 × 规模系数**

    规模系数 = scale_return(港口投资额, exponent)

| 港口等级 | exponent | 规模报酬类型 |
|---|---|---|
| 渔港村落 | 0.90 | **递减**（管理成本高） |
| 乡镇 | 1.00 | **不变** |
| 港口城市 | 1.15 | **递增**（规模优势） |

**展示**

- 港口面板标题下方：`规模报酬：递增（指数 1.15）`
- 世界市场港口行：在等级后加标记 `城·递增`

### 2.3 E7 投资边际回报递减

**当前**：固定档位 5000/20000/60000/150000 对应 10/20/35/50% 折扣。
**本版**：改为连续曲线并显示边际回报率。

    折扣 = 50% × (1 − e^(−k × x)) / (1 − e^(−k))
    x = min(投资额 / 150000, 1)
    k = 1.6（控制曲线弯曲程度）

| 投资额 | 折扣（曲线） |
|---|---|
| 5,000 | 约 3.3% |
| 20,000 | 约 12.0% |
| 60,000 | 约 29.6% |
| 100,000 | 约 40.6% |
| 150,000 | **50%（上限）** |

- 界面上投资面板显示：`当前折扣 24.0%（边际 +0.29%/千）`
- 达到 150,000 时折扣**正好 50%**（预设上限），之后不再增加
