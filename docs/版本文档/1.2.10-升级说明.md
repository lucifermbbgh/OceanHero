# 1.2.10 升级说明（成长数值生效）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.2.9 |
| 目标版本 | **1.2.10** |
| 状态 | 已发布（2026-11-18） |
| 单一功能点 | 船员职级 / 装备强化 / 船只改装 的数值真正作用到舰船属性 |

## 1. 问题

1.1.x 做完了这三套成长系统的**数据与界面**，但 `stats()` 没有读取它们：

| 系统 | 玩家能做的事 | 之前的效果 |
|---|---|---|
| 船员职级 | 攒经验升职 | 无 |
| 装备强化 | 花金币与铁矿升到 +3 | 无 |
| 船只改装 | 升帆具与火炮位 | 仅航速接了一处，火炮位无 |

玩家投入的资源没有任何回报。

## 2. 接入规则

| 系统 | 生效方式 |
|---|---|
| 船员职级 | 在岗船员职级之和：每级 +2% 装填、+1% 命中、+1 接舷 |
| 装备强化 | 已装备强化等级之和：每级 +1% 航速/转向、+2 装甲 |
| 火炮位改装 | 每级 +2 门舷侧火炮 |
| 帆具改装 | 每级 +6% 航速 |

全部在 `GameState.stats()` 里统一叠加，`StatsLib.compute()` 保持纯函数。

## 3. 验收

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 改装火炮位后舷侧炮数 +2 | ✅ |
| 2 | 改装帆具后航速提升 | ✅ |
| 3 | 装备强化后装甲提升 | ✅ |
| 4 | 船员职级提升后装填加成提高 | ✅ |

**测试**：66 单元 + 729 集成
