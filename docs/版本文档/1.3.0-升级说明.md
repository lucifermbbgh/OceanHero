| 模块 | 涉及系统 | 预估 |
|---|---|---|
| 六国与分国声望 | GameState + 声望面板 + 存档 | 2 轮 |
| 港口归属与国家关系 | GameState + 港口数据 | 1.5 轮 |

| 私掠证绑定国家 | 黑市 + 掠夺判定 | 1 轮 |

| 敌方分级 | 敌人表 + 生成逻辑 | 1 轮 |
| 赏金目标 | 任务 + 掉落 | 1 轮 |

| **合计** | | **约 10.5 轮** |

## 1. 本版（1.3.0）范围

### 1.1 六国

| 国家 | id | 定位 |
|---|---|---|
| 澜国 | lan | 海军强国 |
| 赤鳞 | chilin | 商会联邦 |
| 霜屿 | shuangyu | 北方岛国 |
| 玄礁 | xuanjiao | 海盗诸岛 |
| 白鲸 | baijing | 渔业邦联 |
| 苍梧 | cangwu | 新兴王国 |

### 1.2 分国声望

| 项 | 规则 |
|---|---|
| 范围 | 每国 0 ~ 10000 |
| 初始 | 全部 1000（中立） |
| 增益 | 击沉该国敌对目标、完成该国任务 |
| 减益 | 劫掠该国商船、击沉该国军舰 |
| 与旧阵营声望 | 旧三阵营声望保留不变，国家声望独立记录 |

### 1.3 关系分档

| 声望 | 称呼 |
|---|---|
| 0 ~ 499 | 敌视 |
| 500 ~ 1999 | 冷淡 |
| 2000 ~ 4999 | 中立 |
| 5000 ~ 7999 | 友好 |
| 8000+ | 盟友 |

### 1.4 声望面板

母港「声望与战功」新增「六国声望」区块，逐行显示国家、声望、关系称呼。
