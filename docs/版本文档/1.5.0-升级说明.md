# 1.5.0 升级说明（世界地图坐标与探索状态）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.4.20 |
| 目标版本 | **1.5.0** |
| 状态 | 已发布（2026-11-21） |
| 单一功能 | 30 张海图世界坐标 + 探索状态记录 |

## 1. 范围

| 项 | 内容 |
|---|---|
| MapDef.world_pos | 每张图归一化坐标 |
| GameState.explored_maps | 进入海图时记录 |
| 存档 | explored_maps 随档保存 |
| 接口 | is_map_explored() / mark_map_explored() |

## 2. 布局

| 项 | 规则 |
|---|---|
| 海图数 | 30 张（10 级 × 3 列） |
| 行 | 每级一行，y = 0.08 + (级-1) × 0.085 |
| 列 | x = 0.22 / 0.50 / 0.78 |
| 母港 | map1 位于 (0.22, 0.08) |

## 3. 验收

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 30 张图均有坐标 | ✅ |
| 2 | 同级坐标不重叠 | ✅ |
| 3 | 开局母港已探索 | ✅ |
| 4 | 进入海图自动标记 | ✅ |
| 5 | 存档恢复探索状态 | ✅ |

**测试**：66 单元 + 1044 集成
