# 1.4.12 升级说明（风帆按桅分层 + 顶栏船型刷新）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.4.11 |
| 目标版本 | **1.4.12** |
| 状态 | 已发布（2026-11-20） |
| 功能组 | 风帆按桅杆分层、各桅帆装备叠加、换船后顶栏刷新 |

## 1. 风帆分层

| 船级 | 帆槽数 | 说明 |
|---|---|---|
| 1~2 | 1 | 单桅 |
| 3~4 | 2 | 双桅 |
| 5~10 | 3 | 三桅 |

| 项 | 规则 |
|---|---|
| 装备键 | `sail0` / `sail1` / `sail2`（按桅） |
| 属性 | 各桅帆的航速加成**叠加** |
| 强化 | 各桅模块等级独立，效果累加 |
| 显示 | 插槽标注「帆1/帆2/帆3」 |

## 2. 顶栏刷新

| 问题 | 换船后顶栏仍显示旧船型 |
|---|---|
| 修复 | 打开舰船面板与换船后调用 `_refresh()`，重新读取当前船型 |
