# 1.4.3 升级说明（装备品类扩充与槽位映射）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.4.2 |
| 目标版本 | **1.4.3** |
| 状态 | 已发布（2026-11-20） |
| 功能组 | 装甲板 / 望远镜 / 旗帜，装备槽映射到模块 |

## 1. 新增装备（9 件）

| 品类 | 装备 | 数值 |
|---|---|---|
| 装甲板 | 硬木板 / 铁板 / 铜板 | 装甲 +2 / +4 / +6 |
| 望远镜 | 单筒 / 透镜 / 长筒 | 视野 +5% / +10% / +15% |
| 旗帜 | 疾风旗 | 航速 +8% |
| 旗帜 | 烈焰旗 | 装填 +10% |
| 旗帜 | 声望旗 | 声望获取 +15% |

旧「装甲」装备 5 件统一迁移到 `plate` 槽（甲板）。

## 2. 槽位映射

| 装备槽 | 模块 |
|---|---|
| sail | 风帆 |
| rudder | 舵轮 |
| plate | 甲板（1~3 层） |
| figurehead | 甲板（0 层） |
| telescope | 瞭望台 |
| flag | 旗杆 |

## 3. 旗帜与望远镜接入

| 效果 | 接入位置 |
|---|---|
| 旗帜航速 | `stats().base_speed_px` |
| 旗帜装填 | `stats().reload_bonus` |
| 旗帜声望 | `stats().rep_gain_bonus` |
| 望远镜视野 | `stats().view_bonus` |
