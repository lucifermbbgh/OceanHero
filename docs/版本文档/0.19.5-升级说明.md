# 0.19.5 升级说明（表格层级与顺序统一）

| 项 | 内容 |
|---|---|
| 基线版本 | 0.19.4 |
| 目标版本 | 0.19.5 |
| 状态 | 已发布（2026-11-18） |
| 主题 | 利润表/资产负债表统一层级与顺序，补齐遗漏页签名 |

## 1. 统一规则

| 规则 | 说明 |
|---|---|
| 大类不缩进 | 营业收入 / 营业成本 / 资产 / 负债 |
| 细类缩进两字符 | 用两个全角空格 　　，如 「　　贸易」 |
| 细类紧跟大类 | 大类行后立即列全部细类 |
| 合计在大类之后 | 收入合计→营业成本→成本合计→净利润 |
| 全部列出 | 细类无论是否发生过、是否为 0 都显示 |
| 顺序一致 | 同一张表跨年份/跨周期采用同一顺序 |

**利润表结构（年/上年/周/上周四表通用）**

    营业收入          ← 大类
    　　贸易 / 战利品 / 任务 / 利息   ← 固定顺序细类
    收入合计
    营业成本          ← 大类
    　　采购 / 维护 / 关税 / 利息 / 建造
    成本合计
    净利润

**资产负债表结构（年/上两三表通用）**

    资产              ← 大类
    　　现金 / 银行存款 / 船舱货物 / 港口仓库 / 装备 / 船只
    资产合计
    负债              ← 大类
    　　未还贷款
    负债合计
    净资产
