# 0.4.0-alpha 升级说明

| 项 | 内容 |
|---|---|
| 基线版本 | 0.3.0-alpha |
| 目标版本 | 0.4.0-alpha |
| 状态 | ✅ 已发布（2026-11-16，commit 4b54bea） |
| 主题 | 航行与寻路：让开船真正可玩 |
| 测试 | 65 单元 + 309 集成 |

## 1. 背景

NPC 船头高频抽搐、绕岛贴边减速、高级图一进场就被围殴、玩家不知道射程有多远。

## 2. 需求与实现

- 修复 turn_rate 单位错误（数据是度/秒，代码当弧度/秒用，转向快 57 倍）
- 避障加滞回半径、绕行侧锁定、绕障期间独占转向权、死区 0.05rad
- 刷怪密度：玩家安全圈 1150px、2000px 网格 ≤3、最小间距 420px
- 迎接单位绕玩家 120° 等距分散
- 围攻上限：同时锁定玩家 ≤3，索敌半径 1500→1100
- 单位属地巡游，离出生点 >1300px 返航
- 切线绕障规划：逐段检查，遇岛插切点，最多 8 次修正
- NPC 前视避障（此前完全没有绕障）
- 锁定后显示射程圈 + 目标面板显示「距离 X / 射程 Y」

## 3. 验收结果

- 转向修复后满舵 1 秒转 45.6°，与数据一致
- 绕航点离岛边 ≥ 一个减速带，实测航线全程不穿岛
- 处理了转向抽搐、擦边减速、被围攻三个试玩反馈

`scripts/ship/sea_ship.gd、scripts/sea/sea_scene.gd、scripts/ui/sea_hud.gd`
