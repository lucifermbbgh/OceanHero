## 1. 交付范围

| 块 | 内容 | 预估 |

| B 材料与经济 | 材料四大类、市场分类分页、建造、投资、金币开销、关税分档 | 5 轮 |

## 2. A 块：岛屿与城镇

### 2.1 停泊与进入

    航行至岛屿 → HUD 提示「E 停泊」
        → 进入城镇界面（全屏，与母港同构）
        → ESC / ✕ 离岛

### 2.2 面板复用母港

| 项 | 规则 |
|---|---|
| 实现 | 岛屿城镇直接复用母港面板构建器，仅传入不同港口参数 |
| 菜单 | 按城镇等级显示可用项 |
| 差异 | 母港有「建造」，其他岛屿为「投资」 |

**功能解锁表**

| 功能 | 港村 | 港镇 | 港城 |
|---|---|---|---|
| 市场交易 | 有 | 有 | 有 |
| 酒馆招募 | 有 | 有 | 有 |
| 任务板 | 有 | 有 | 有 |
| 船厂 | 无 | 有 | 有 |
| 交易所 | 无 | 无 | 有 |
| 声望交易 | 无 | 无 | 有 |
| 拍卖行 | 无 | 无 | 有 |
| 银行 | 无 | 无 | 有 |
| 黑市 | 无 | 无 | 有 |
| 投资 | 有 | 有 | 有 |
| 建造 | 仅母港 | 仅母港 | 仅母港 |

### 2.3 母港邻近双岛

| 项 | 规则 |
|---|---|
| 数量 | 第 1 图固定 2 座 |
| 等级 | 一座港城、一座港镇 |
| 距离 | 距母港 10~30 秒航程 |
| 存档 | 生成后写入存档 |

### 2.4 命名标准化

| 等级 | 后缀 | 示例 |
|---|---|---|
| 1 | 港村 | 白沙港村 |
| 2 | 港镇 | 白沙港镇 |
| 3 | 港城 | 白沙港城 |

数据只存前缀；升格后后缀自动替换。

## 3. B 块：材料、建造与投资

### 3.1 材料四大类

| 大类 | 明细 |
|---|---|
| 食物 | 小麦 / 大米 / 土豆 / **甘蔗** / 鱼类 / 肉类 / 水果 |
| 原材料 | 木材 / 石材 / 铁矿 / 铜矿 / **硝石** / **粘土** / 棉花 / 亚麻 |
| 消费品 | 布料 / 陶器 / 工具 / **啤酒** / 朗姆酒 / 香料 |
| 消费品·军用品 | **火枪 / 火炮 / 弹药** |
| 贵金属 | 银锭 / 金锭 / 宝石 |

旧商品映射：谷物 → 小麦 / 大米 / 土豆；木材、铁矿、朗姆酒、香料直接保留。

### 3.1.1 生产链（配方）

| 产成品 | 输入 | 设施 |
|---|---|---|
| 布料 | 棉花 ×2 | 工坊 |
| 陶器 | 粘土 ×2 | 工坊 |
| 工具 | 铁矿 ×2 + 木材 ×1 | 工坊 |
| 啤酒 | 小麦 ×3 | 工坊 |
| 朗姆酒 | 甘蔗 ×3 | 工坊 |
| 火枪 | 铁矿 ×2 + 木材 ×2 | 工坊（军械） |
| 火炮 | 铁矿 ×3 + 铜矿 ×2 | 工坊（军械） |
| 弹药 | 铁矿 ×1 + 硝石 ×1 | 工坊（军械） |

### 3.1.2 替代与互补关系

| 类型 | 符号 | 例子 | 交叉弹性来源 |
|---|---|---|---|
| 替代品 | 正 | 啤酒 ↔ 朗姆酒 | 手工登记（同为饮酒需求） |
| 投入品 | 正 | 小麦 → 啤酒 | **由配方表自动生成** |
| 互补品 | 负 | 火炮 ↔ 弹药 | 手工登记（配套消耗） |

> 交叉弹性从「拍脑袋系数」变为「有生产链与消费结构作依据」。

### 3.1.3 军用品用途

| 物资 | 用途 |
|---|---|
| 火枪 | 可装备，提升接舷与船员火力 |
| 火炮 | 可装备，提升舷侧火力 |
| 弹药 | 战斗消耗品，开火时按炮数扣减 |

### 3.1.4 市场分类分页（参考《维多利亚 3》）

商品增至 21 种，市场必须分页：

    市场行情
    [食物] [原材料] [消费品] [军用品] [贵金属] [全部]

| 项 | 规则 |
|---|---|
| 默认页签 | **食物** |
| 布局 | 全屏，与现有市场面板一致 |
| 行内容 | 商品 / 买价 / 卖价 / 周涨跌 / 库存 / 船上 / 仓库 / 交易 |
| 切换 | 点页签即切换，保留港口状态 |

> 组织方式参考《维多利亚 3》的 Staple / Luxury / Industrial / Military 分类，
> 不复制其数值模型。

### 3.2 建造面板（母港）

主表（全屏）：

    建造 · 白沙港村 → 白沙港镇

    项目      需求     船舱    仓库    操作
    木材       200      120      40    [提交]
    石材       120        0      60    [提交]
    铁锭        80       20       0    [提交]
    金币     5,000    6,000       -    [提交]

提交弹窗（不全屏）：

    提交材料：木材
    船舱提交 [ 120 ]  上限 120
    仓库提交 [  40 ]  上限 40
               [提交]

| 输入规则 | 说明 |
|---|---|
| 合法值 | 0 与正整数 |
| 上限 | 该仓实际数量 |
| 超限 / 非法 | 自动回正为上限 / 0 |
| 空仓 | 禁用该输入，计 0 |
| 提交量 | 两个输入之和 |
| 金币行 | 单输入框，上限为当前金币 |

所有项目达标后，面板底部「确认升级」点亮，点击开始 52 周计时。

### 3.3 投资面板（其他岛屿）

    资金来源     可用      已投入    操作
    现金         42,000    60,000    [投资]
    银行存款     10,000         0    [投资]

| 来源 | 上限 | 扣减 |
|---|---|---|
| 现金 | 当前金币 | 直接扣减 |
| 银行存款 | 当前存款 | 从存款扣减，利息按剩余本金重算 |

## 4. C 块：生产与深度扩展

### 4.1 岛屿市场弹窗

岛屿港口接入与母港相同的商品详情弹窗（图表 + 指标 + 数量 + 买卖）。

### 4.2 多建筑并行

| 建筑 | 作用 | 等级上限 |
|---|---|---|
| 船厂 | 建造与修理速度 | 3 |
| 交易所 | 交易税减免、订单数量 | 3 |
| 仓库 | 仓储容量 | 3 |
| 声望所 | 声望获取加成 | 3 |

建筑可并行升级，各自独立计时。

### 4.3 生产模块

| 设施 | 产出大类 | 输入材料 |
|---|---|---|
| 农场 | 食物 | 无 |
| 矿场 | 原材料（铁 / 铜 / 石） | 无 |
| 工坊 | 消费品（布料 / 陶器 / 工具） | 原材料 |

产出 = 基础产出 × 等级^指数（指数见 0.17 生产函数）。

### 4.4 船员职级与技能

| 项 | 内容 |
|---|---|
| 职级 | 水手 → 舵手 → 炮长 → 大副 |
| 技能 | 每职级解锁 1 个被动（航速 / 装填 / 索敌 / 士气） |
| 成长 | 参战积累经验，经验满升职 |

### 4.5 任务类型扩展

| 类型 | 目标 |
|---|---|
| 护航 | 护送商船到达指定港口 |
| 劫掠 | 在指定海域击沉 N 艘敌对舰船 |
| 寻宝 | 按线索在指定坐标打捞 |

### 4.6 装备强化与合成

| 项 | 规则 |
|---|---|
| 强化 | 消耗材料提升装备属性，成功率递减 |
| 合成 | 三件同级同部位合成一件高一级 |

### 4.7 船只改装

| 项 | 内容 |
|---|---|
| 火炮位 | 增加 / 替换炮位 |
| 帆具 | 提升航速或逆风性能 |

### 4.8 海域与敌方扩展

| 项 | 内容 |
|---|---|
| 新增海图 | 3 张（冰海 / 珊瑚海 / 迷雾海域），每张 1 城 1 镇 |
| 敌方编成 | 按海域分级：近海弱、远洋强，首领船出现概率递增 |
| 赏金目标 | 每张新海图 1 名通缉目标，击沉获得高额赏金 |
| 海域事件 | 风暴 / 海盗潮 / 商队潮，影响该海域敌我密度 |

## 5. 关税分档（本版实现）

| 阵营声望档 | 卖出关税 | 备注 |
|---|---|---|
| 敌对（0 ~ 1999） | **10%** | 敌对港口仍可访问，但关税压制利润 |
| 中立（2000 ~ 4999） | 5% | 基准 |
| 友好（5000 ~ 7999） | 3% | — |
| 盟友（8000 以上） | 1% | — |

多国拆分后改为按国家关系计算。
