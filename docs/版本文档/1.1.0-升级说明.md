# 1.1.0 升级说明（岛屿平权与建造投资）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.0.0 |
| 目标版本 | **1.1.0** |
| 状态 | 待确认 |
| 主题 | 岛屿访问平权 + 城镇命名标准化 + 建造面板 + 投资面板 + 材料系统 |
| 大版本规划 | 见 `1.x-大版本规划.md` 第 3 节 |

## 1. 需求摘要

| # | 需求 | 来源 |
|---|---|---|
| 1 | 岛屿访问做成与母港一致的体验（停泊 → 进入 → 分级功能面板） | 用户 |
| 2 | 母港邻近固定放 1 座港城 + 1 座港镇 | 用户 |
| 3 | 城镇三级命名标准化：港村 / 港镇 / 港城，升级改名 | 用户 |
| 4 | 母港「建造」面板：材料表格 + 提交弹窗（船舱 / 仓库两输入） | 用户 |
| 5 | 岛屿「投资」面板：现金 / 存款双通道，同样的输入规则 | 用户 |
| 6 | 建造材料系统（支撑建造消耗） | 派生 |

## 2. 交互规格

### 2.1 停泊与进入

    靠近岛屿 → HUD 提示「E 停泊」
        → 按 E 进入城镇界面（全屏，与母港同构）
        → ESC / ✕ 离岛返回海面

### 2.2 城镇界面布局

    左侧菜单（按等级解锁）        右侧内容区
    市场交易 / 酒馆招募 / 任务板 / 船厂 / 交易所 / 声望 / 拍卖行 / 银行 / 黑市 / 投资

### 2.3 建造面板（母港）

**主表**

    材料     需求    船舱    仓库    操作
    木材     200     120      40     [提交]
    铁锭      80      20       0     [提交]
    布料      50       0       0     [提交]
    石料     120       0      60     [提交]

**提交弹窗**

    提交材料：木材
    船舱提交 [ 120 ]  上限 120
    仓库提交 [  40 ]  上限 40
               [提交]

| 输入规则 | 说明 |
|---|---|
| 合法值 | 0 与正整数 |
| 上限 | 该仓实际持有量 |
| 超限 | 自动置为上限 |
| 非法字符 | 自动回正为 0 |
| 空仓 | 该输入禁用并计 0 |
| 提交量 | 两输入之和 |

### 2.4 投资面板（非母港岛屿）

    资金来源     可用      已投入   操作
    现金         42,000    60,000   [投资]
    银行存款     10,000         0   [投资]

投资弹窗：

    投资来源：现金
    投入金额 [ 5000 ]  上限 42,000
              [提交]

## 3. 数据规格

| 数据 | 说明 |
|---|---|
| 城镇名称 | 只存前缀，显示时拼后缀 |
| 建造需求 | 每级一份材料清单，存 balance_config |
| 已提交材料 | 按 (港口, 材料) 记录，进存档 |
| 材料类型 | commodity 子类型，参与仓储与市场 |
| 投资来源 | cash / deposit 两种，分别记账 |

## 4. 验收标准

| # | 验收点 |
|---|---|
| 1 | 靠近岛屿提示停泊，按 E 进入全屏城镇界面 |
| 2 | 功能按等级解锁：村 3 项、镇 4 项、城 9 项 |
| 3 | 第 1 图固定生成 1 座港城与 1 座港镇 |
| 4 | 名称显示为「前缀 + 港村/港镇/港城」 |
| 5 | 升格后后缀自动替换 |
| 6 | 母港菜单有「建造」，打开全屏材料表 |
| 7 | 每行含材料 / 需求 / 船舱 / 仓库 / 提交 |
| 8 | 提交弹窗两输入框上限为各仓数量 |
| 9 | 输入仅 0 与正整数，超限回正 |
| 10 | 按输入分别扣减两仓，空仓跳过 |
| 11 | 材料合计达标后升级，52 周计时生效 |
| 12 | 非母港岛屿菜单为「投资」 |
| 13 | 投资支持现金与存款 |
| 14 | 扣款后余额与岛屿投资额同步更新 |
| 15 | 全部新增状态进存档 |
