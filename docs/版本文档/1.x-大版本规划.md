## 3. 1.1.0 详细设计

### 3.1 岛屿访问平权

**问题**：当前靠近岛屿只弹出侧栏面板，与母港体验割裂。

**目标流程**

    航行至岛屿附近 → 提示「按 E 停泊」
        → 进入岛屿城镇界面（全屏、与母港同构）
        → 按城镇等级解锁对应功能面板
        → 右上角 ✕ 或 ESC 离岛

**功能面板清单（按等级）**

| 功能 | 港村 | 港镇 | 港城 |
|---|---|---|---|
| 市场交易 | 有 | 有 | 有 |
| 酒馆招募 | 有 | 有 | 有 |
| 任务板 | 有 | 有 | 有 |
| 船厂 | 无 | 有 | 有 |
| 交易所 | 无 | 无 | 有 |
| 声望交易 | 无 | 无 | 有 |
| 拍卖行 | 无 | 无 | 有 |
| 银行 | 无 | 无 | 有 |
| 黑市 | 无 | 无 | 有 |
| 投资（本岛） | 有 | 有 | 有 |
| 建造 | 无（仅母港） | 无 | 无 |

### 3.2 母港邻近双岛

| 项 | 规则 |
|---|---|
| 位置 | 母港所在海图（第 1 图）固定 2 座邻岛 |
| 等级 | 一座固定 **港城**，一座固定 **港镇** |
| 位置约束 | 距母港一定范围内，航行 10~30 秒可达 |
| 其余岛屿 | 沿用现有随机生成 |
| 存档 | 生成后写入存档，读档不重排 |

**目的**：开局即可体验拍卖行、银行、黑市等城市功能，不必等母港升级。

### 3.3 城镇命名标准化

| 等级 | 后缀 | 全称示例 |
|---|---|---|
| 1 | **港村** | 白沙港村 |
| 2 | **港镇** | 白沙港镇 |
| 3 | **港城** | 白沙港城 |

| 规则 | 说明 |
|---|---|
| 名称构成 | 前缀（地名）+ 后缀（等级） |
| 升级改名 | 后缀随等级替换，前缀不变 |
| 数据存储 | 只存前缀，显示时拼后缀 |
| 母港 | 同样适用（初始为 xx港村） |

### 3.4 母港「建造」面板

**入口**：母港左侧菜单「建造」（替代原「升级港口」）

**主面板（全屏表格）**

    建造 · 白沙港村 → 白沙港镇

    材料        需求    船舱    仓库    操作
    木材        200     120     40      [提交]
    铁锭         80      20      0      [提交]
    布料         50       0      0      [提交]

| 列 | 说明 |
|---|---|
| 材料 | 材料名称 |
| 需求 | 升级所需总量 |
| 船舱 | 当前船舱内该材料数量 |
| 仓库 | 当前仓库内该材料数量 |
| 操作 | 提交按钮 |

**提交弹窗（不全屏）**

    提交材料：木材
    船舱提交  [ 120 ]   （上限 120）
    仓库提交  [  40 ]   （上限 40）
                  [提交]

| 输入规则 | 说明 |
|---|---|
| 取值范围 | 0 或正整数 |
| 上限 | 该仓内该材料的实际数量 |
| 非法输入 | 自动回正为 0 |
| 空仓跳过 | 该仓数量为 0 时不计入、不报错 |
| 最终提交量 | 两个输入框之和 |
| 扣减 | 按输入分别从船舱 / 仓库扣除 |

**升级判定**：所有材料均达到需求后，升级按钮点亮，点击完成升级（52 周计时保留）。

### 3.5 岛屿「投资」面板

**入口**：非母港岛屿的左侧菜单「投资」

**主面板（全屏表格）**

    投资 · 青礁港镇

    资金来源    可用      已投入    操作
    现金        42,000    60,000    [投资]
    银行存款    10,000         0    [投资]

**投资弹窗（不全屏）**

    投资资金来源：现金
    投入金额  [ 5000 ]   （上限 42,000）
                  [提交]

| 规则 | 说明 |
|---|---|
| 现金投资 | 上限为当前现金 |
| 存款投资 | 上限为银行存款，提交时从存款扣除 |
| 输入限制 | 0 或正整数，超限自动置为上限 |
| 合计 | 两笔分别提交，累计到岛屿投资额 |
| 效果 | 与现有投资折扣、52 周升格逻辑一致 |

### 3.6 建造材料系统

| 项 | 内容 |
|---|---|
| 材料种类 | 木材 / 铁锭 / 布料 / 石料（首批 4 种） |
| 数据 | 作为 commodity 的子类型，参与仓储与市场 |
| 来源 | 岛屿拾取、击沉舰船战利品、市场购买 |
| 用途 | 母港建造升级消耗 |
| 存储 | 复用船舱 / 仓库两套容器 |

## 4. 1.1.0 验收标准

| # | 验收点 |
|---|---|
| 1 | 靠近岛屿提示停泊，进入后为全屏城镇界面 |
| 2 | 城镇界面功能按等级解锁（村 / 镇 / 城） |
| 3 | 母港所在海图固定生成 1 城 + 1 镇 |
| 4 | 城镇名称按「前缀 + 港村/港镇/港城」显示 |
| 5 | 升级后名称后缀自动变化 |
| 6 | 母港菜单出现「建造」按钮，打开全屏表格 |
| 7 | 表格每行含材料 / 需求 / 船舱 / 仓库 / 提交 |
| 8 | 提交弹窗有两个输入框，上限为各仓实际数量 |
| 9 | 输入仅接受 0 与正整数，超限自动回正 |
| 10 | 提交按输入分别扣减两仓，空仓跳过 |
| 11 | 材料齐备后完成升级，52 周计时生效 |
| 12 | 非母港岛屿菜单为「投资」而非「建造」 |
| 13 | 投资支持现金与存款两种来源 |
| 14 | 投资提交后扣减对应资金并计入岛屿投资额 |
| 15 | 全部新增状态进存档 |

## 5. 风险

| 风险 | 对策 |
|---|---|
| 岛屿城镇界面与母港代码重复 | 抽出共用面板构建器，两处复用 |
| 材料来源不足导致卡关 | 首批材料产量按升级需求 2 倍配置 |
| 存款投资影响银行余额一致性 | 投资扣款统一走 GameState 接口，禁止直接改字段 |
| 固定双岛影响原有随机布局 | 生成时先占位再随机填充，冲突留空 |
