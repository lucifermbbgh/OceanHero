> **版本号不跳号**：1.1.0 → 1.2.0 → 1.3.0 → 1.4.0 连续推进。

> 生态三件套整体前移到 1.2 / 1.3 / 1.4。

## 4. 材料与生产链体系

### 4.1 四大类与明细

| 大类 | 明细材料 |
|---|---|
| **食物** | 小麦、大米、土豆、甘蔗、鱼类、肉类、水果 |
| **原材料** | 木材、石材、铁矿、铜矿、硝石、粘土、棉花、亚麻 |
| **消费品** | 布料、陶器、工具、啤酒、朗姆酒、香料 |
| **消费品·军用品** | 火枪、火炮、弹药 |
| **贵金属** | 银锭、金锭、宝石 |

> 军用品归入消费品大类，单列子类：它们由原材料加工而来，属于**产成品**。

### 4.2 生产链（配方）

| 产成品 | 输入材料 | 设施 |
|---|---|---|
| 布料 | 棉花 ×2 | 工坊 |
| 陶器 | 粘土 ×2 | 工坊 |
| 工具 | 铁矿 ×2 + 木材 ×1 | 工坊 |
| 啤酒 | 小麦 ×3 | 工坊 |
| 朗姆酒 | 甘蔗 ×3 | 工坊 |
| **火枪** | 铁矿 ×2 + 木材 ×2 | 工坊（军械） |
| **火炮** | 铁矿 ×3 + 铜矿 ×2 | 工坊（军械） |
| **弹药** | 铁矿 ×1 + 硝石 ×1 | 工坊（军械） |

食物与原材料由农场 / 矿场直接产出，无需配方。

### 4.3 替代与互补关系（交叉弹性的计算依据）

| 关系类型 | 符号 | 例子 | 传导逻辑 |
|---|---|---|---|
| **替代品** | 正 | 啤酒 ↔ 朗姆酒 | A 涨价 → 需求转向 B → B 涨价 |
| **投入品** | 正 | 小麦 → 啤酒 | 原料涨价 → 成本上升 → 成品涨价 |
| **互补品** | 负 | 火炮 ↔ 弹药 | 弹药贵 → 用炮成本高 → 火炮需求降 |

**关系的来源**：投入品关系由 4.2 的配方表**自动生成**，替代与互补关系手工登记。
这样交叉弹性不再依赖拍脑袋的系数，而是有生产链与消费结构作依据。

### 4.3.1 市场界面分类分页（参考《维多利亚 3》）

《维多利亚 3》的商品页按 **Staple / Luxury / Industrial / Military** 四大类组织，
本作对应关系：

| 本作分类 | 对应《维多利亚 3》 | 说明 |
|---|---|---|
| 食物 | Staple goods | 日常必需品 |
| 原材料 | Industrial goods | 用于加工 |
| 消费品 | Luxury goods | 加工后的高价品 |
| 军用品 | Military goods | 军械类 |
| 贵金属 | Prestige goods | 高价值 |

**界面方案**

    市场行情
    [食物] [原材料] [消费品] [军用品] [贵金属] [全部]

| 项 | 规则 |
|---|---|
| 默认页签 | **食物** |
| 页签布局 | 全屏，与现有市场面板一致 |
| 行内容 | 商品 / 买价 / 卖价 / 周涨跌 / 库存 / 船上 / 仓库 / 交易 |
| 切换 | 点页签即切换，保留当前港口状态 |

> 取值方式借鉴其「分类浏览 + 供需状态」的组织方式，不复制其数值模型。

### 4.4 金币作为建造开销

建造升级同时消耗**材料 + 金币**：材料是实物投入，金币是劳务与地租。

### 4.5 旧商品迁移

| 现有商品 | 归入 | 处理 |
|---|---|---|
| 谷物 | 食物 | 拆分为小麦 / 大米 / 土豆 |
| 木材 | 原材料 | 直接保留 |
| 铁矿 | 原材料 | 直接保留 |
| 朗姆酒 | 消费品 | 直接保留（配方：甘蔗 → 朗姆酒） |
| 香料 | 消费品 | 直接保留（热带产地直出） |

### 4.6 军用品的作用

| 物资 | 用途 |
|---|---|
| 火枪 | 可装备，提升接舷战与船员火力 |
| 火炮 | 可装备，提升舷侧火力（与现有 gear 系统对接） |
| 弹药 | 战斗消耗品，每次开火按炮数扣减 |

## 4.6 航行结构：邻接图而非等级跳转（2026-11-18 决定）

| 项 | 决策 |
|---|---|
| 现状 | 9 图线性蛇形链（1→2→…） |
| 1.3.2 方案 | 改为**邻接图**：每张图显式声明邻居，通行按邻接判定 |
| 等级的作用 | 只表示难度与解锁门槛，**不再是通行规则** |
| 同级任选如何实现 | 同级三张图互相邻接（三角），并与相邻级别的三张图互通，自然形成「同级任选」 |
| 为什么这样做 | 为未来的世界地图保留兼容性：世界地图只需渲染同一张邻接图 |

**邻接设计**

| 关系 | 连接 |
|---|---|
| 同级内 | 三张图两两相邻（3 条边） |
| 相邻级别 | 本级三张 ↔ 上级三张（9 条边） |
| 母港 | 连接 1 级三张图 |

**通行规则**

| 项 | 规则 |
|---|---|
| 入口 | 目标图必须与当前图相邻 |
| 解锁 | 目标图级别 ≤ 已通关最高级别 + 1 |
| Boss 门禁 | 跨级前进仍需击败当前级 Boss（保留原规则） |

## 5. 延后版本的概要设计

### 5.1 1.4.0 多国海军与外交

| 项 | 内容 |
|---|---|
| 国家 | 澜国 / 赤鳞 / 霜屿 / 玄礁 / 白鲸 / 苍梧 |
| 声望 | 各国独立 0~10000，替换单一海军声望 |
| 私掠证 | 绑定具体国家，劫掠他国合法、劫掠本国叛国 |
| 关税 | 按两国关系浮动：敌对 10%、中立 5%、友好 3%、盟友 1% |
| 外交关系 | 同盟 / 中立 / 敌对 |

### 5.2 1.5.0 NPC 居民与真实需求

| 项 | 内容 |
|---|---|
| 居民 | 各港人口数量与职业构成 |
| 消费 | 按人口与收入计算各品类需求量 |
| 需求曲线 | 由实际消费数据拟合，替代当前虚构曲线 |
| 收入弹性 | 有居民收入变量后可计算 |

### 5.3 1.6.0 生态整合

| 项 | 内容 |
|---|---|
| 生产—需求闭环 | 生产模块产出直接影响港口供给 |
| 规模经济曲线 | 连续产量数据支撑长期平均成本曲线 |
| 价格传播 | 生产端冲击经贸易路线传导到消费端 |
