# 1.x 大版本规划（1.1.0 ~ 2.0.0）

| 项 | 内容 |
|---|---|
| 当前正式版 | 1.0.0（说明已归档至 历史归档/1.0.0-版本说明.md） |
| 本大版本区间 | **1.1.0 ~ 1.9.x**，2.0.0 收口 |
| 版本规则 | 功能批次升次版本，同模块收尾用补丁号（1.1.1 / 1.1.2） |

## 1. 范围决策（本次确认）

### 1.1 明确不做（除非未来明确提出）

| # | 条目 | 备注 |
|---|---|---|
| 1 | 新手教程与引导 | 不做 |
| 2 | Boss 技能与差异化 | 不做（Boss 仅以装备与属性区分） |
| 3 | 音乐与音效 | 不做 |
| 4 | 成就系统 | 不做 |
| 5 | 多语言 | 不做 |
| 6 | 手柄支持 | 不做 |

### 1.2 延后三个版本（生态设计，复杂度高）

| 条目 | 原计划 | 调整后 | 原因 |
|---|---|---|---|
| 多国海军与外交 | 1.4.0 | **1.4.0（保持）** | 依赖阵营与关税体系，单独成版 |
| NPC 居民与真实需求 | 1.3.0 | **1.5.0** | 需先有多国与贸易数据 |
| 生态整合（生产—需求闭环） | — | **1.6.0** | 依赖前两者 |

> 即：生态三件套整体后移三个版本槽位，集中在 1.4 ~ 1.6 完成。

### 1.3 其余内容全部并入 1.1.0

除上述「不做」与「延后」两类外，其余已规划内容**一次性并入 1.1.0** 交付。

## 4. 材料体系（四大类）

### 4.1 分类与明细

| 大类 | 明细材料 | 说明 |
|---|---|---|
| **食物** | 小麦、大米、土豆、鱼类、肉类、水果 | 居民口粮，价格波动大 |
| **原材料** | 木材、石材、铁矿、铜矿、棉花、亚麻 | 建造与加工的基础 |
| **消费品** | 布料、朗姆酒、香料、陶器、工具 | 加工品，利润高 |
| **贵金属** | 银锭、金锭、宝石 | 高价值，体积小 |

**现状迁移**

| 现有商品 | 归入 | 处理 |
|---|---|---|
| 谷物 | 食物 | 拆分为小麦 / 大米 / 土豆 |
| 木材 | 原材料 | 直接保留 |
| 铁矿 | 原材料 | 直接保留 |
| 朗姆酒 | 消费品 | 直接保留 |
| 香料 | 消费品 | 直接保留 |

### 4.2 金币作为建造开销

建造升级同时消耗**材料 + 金币**，符合经济学逻辑：材料是实物投入，金币是劳务与地租。

## 5. 延后版本的概要设计

### 5.1 1.4.0 多国海军与外交

| 项 | 内容 |
|---|---|
| 国家 | 澜国 / 赤鳞 / 霜屿 / 玄礁 / 白鲸 / 苍梧 |
| 声望 | 各国独立 0~10000，替换单一海军声望 |
| 私掠证 | 绑定具体国家，劫掠他国合法、劫掠本国叛国 |
| 关税 | 按两国关系与声望档位浮动，替换定值 |
| 外交关系 | 同盟 / 中立 / 敌对 |

### 5.2 1.5.0 NPC 居民与真实需求

| 项 | 内容 |
|---|---|
| 居民 | 各港人口数量与职业构成 |
| 消费 | 按人口与收入计算各品类需求量 |
| 需求曲线 | 由实际消费数据拟合，替代当前虚构曲线 |
| 收入弹性 | 有居民收入变量后可计算 |

### 5.3 1.6.0 生态整合

| 项 | 内容 |
|---|---|
| 生产—需求闭环 | 生产模块产出直接影响港口供给 |
| 规模经济曲线 | 连续产量数据支撑长期平均成本曲线 |
| 价格传播 | 生产端冲击经贸易路线传导到消费端 |

## 6. 风险

| 风险 | 对策 |
|---|---|
| 1.1.0 范围过大（14 项） | 内部分三批交付；未完成部分用 1.1.1 / 1.1.2 补丁收尾 |
| 材料体系迁移影响旧存档 | 提供旧商品到新分类的映射表，读档时自动转换 |
| 岛屿城镇界面复用母港 | 抽出共用面板构建器，母港与岛屿仅传入不同参数 |
| 存款投资扣款与利息计算耦合 | 统一经 GameState 接口扣款，利息按日切分重算 |
