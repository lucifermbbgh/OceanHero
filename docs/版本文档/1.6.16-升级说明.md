# 1.6.16 升级说明（艺术岛即真岛）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.6.15 |
| 目标版本 | **1.6.16** |
| 状态 | 已发布（2026-11-28） |
| 单一功能 | 艺术岛屿承担全部玩法：碰撞/停靠/港口/小地图 |

## 1. 旧逻辑合并

| 旧 | 新 |
|---|---|
| 碰撞 = 等级半径圆 | 碰撞 = 精灵实际尺度（rad 字段，200~900） |
| 港口 = 岛心圆点 | 港口 = 岸点（px/py，朝海一侧） |
| 岛边黄圈 | 浅滩海岸环（与碰撞半径一致） |
| 精灵尺寸 = w,h 原始比例 | 精灵尺寸 = 碰撞半径 × 2.4（所见即所撞） |

## 2. 数据

| 字段 | 含义 |
|---|---|
| rad | 归一化碰撞半径（与游戏 clamp 一致） |
| px / py | 港口岸点局部坐标 |
| sprite | 2x 锐化精灵（70 张） |
