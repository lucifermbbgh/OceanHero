# 1.6.6 升级说明（陆地蒙板与区域层级修正）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.6.5 |
| 目标版本 | **1.6.6** |
| 状态 | 已发布（2026-11-26） |
| 单一功能 | 陆地蒙板遮罩 + 海域区域不压陆地 |

## 1. 变更

| 项 | 之前 | 现在 |
|---|---|---|
| 区域与陆地 | 区域色块覆盖陆地 | **先画区域，再画陆地**，陆地遮住区域色 |
| 命中 | 点到陆地也可能选中区域 | 陆地不参与命中 |
| 底图 | 旧底图自带陆地，出现双份陆地 | 换成无陆地的海面底图 `bg_sea.png` |
| 数据 | 无陆地数据 | `data/generated/land_masses.json`（6 块陆地） |

## 2. 新增文件

| 文件 | 说明 |
|---|---|
| `data/source/land_masses.json` | 陆地多边形源（归一化） |
| `data/generated/land_masses.json` | 构建产物，运行时读取 |
| `tools/map_pipeline/make_land.py` | 生成陆地蒙板 |
| `art/world_map/bg_sea.png` | 无陆地海面底图 |
| `art/world_map/composed_v3.png` | 合成图 v3（陆地置顶） |

## 3. 验收

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 区域颜色不覆盖陆地 | ✅ |
| 2 | 陆地不参与点击命中 | ✅ |
| 3 | 无双份陆地 | ✅ |
| 4 | 集成测试全过 | ✅ 1064 |

## 4. 遗留

| # | 项 |
|---|---|
| 1 | 陆地是纯色块，缺海岸纹理 |
| 2 | 海面底图仍偏暗，AI 纹理未直接使用 |
| 3 | 势力徽标仍为几何 v1 |

**测试**：66 单元 + 1064 集成
