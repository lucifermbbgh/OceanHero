# 1.4.19 升级说明（岛屿酒馆雇佣不刷新）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.4.18 |
| 目标版本 | **1.4.19** |
| 状态 | 已发布（2026-11-20） |
| 功能组 | 修复雇佣后面板不刷新；医疗室/厨房效果挂起 |

## 1. 问题

| 项 | 说明 |
|---|---|
| 现象 | 在其他岛屿的酒馆点「雇佣」，金币扣了但名单没变化，看起来像不能雇佣 |
| 原因 | `_hire_crew()` 只移除候选并写日志，**没有重建酒馆面板** |
| 影响 | 母港同样存在，只是岛屿上更容易被误认为「不允许雇佣」 |

## 2. 修复

| # | 修复 |
|---|---|
| 1 | 雇佣成功后调用 `_rebuild_tavern()` + `_refresh()` |
| 2 | 下阵操作同样立即刷新 |

## 3. 验证

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 岛屿酒馆可打开且有候选 | ✅ |
| 2 | 雇佣后名册 +1、候选 -1、扣金币 | ✅ |
| 3 | 面板雇佣按钮数量与候选池一致 | ✅ |

## 4. 医疗室与厨房（挂起）

| 项 | 说明 |
|---|---|
| 前提 | 需要「船员健康度」属性，当前尚未设计 |
| 医疗室 | 战后按健康度缺口逐日恢复 |
| 厨房 | 每日随机提供战斗增益（回复/攻防/技能） |
| 结论 | **暂不实现**，留待未来的船员健康系统版本 |

**测试**：66 单元 + 1036 集成
