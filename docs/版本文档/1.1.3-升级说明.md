# 1.1.3 升级说明（打磨与平衡回填）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.1.2 |
| 目标版本 | **1.1.3** |
| 状态 | 已发布（2026-11-18） |
| 主题 | 生产平衡、界面一致性、存档兼容 |

## 1. 平衡

### 1.1 生产受工坊等级限制

| 工坊等级 | 每周加工批次上限 |
|---|---|
| 0（未建） | 1 |
| 1 | 1 |
| 2 | 2 |
| 3 | 3 |

> 此前生产无上限，只要有原料就能无限加工，材料经济失去压力。
> 现在加工能力随工坊等级增长，建造工坊才有产能。

## 2. 界面一致性

| 项 | 调整 |
|---|---|
| 世界市场 | 按当前大类展示商品，并新增五个大类页签 |
| 本周指标行 | 按当前大类统计弹性与库存比例 |
| 岛屿市场 | 每行新增「交易」按钮（1.1.2 已加，本版统一样式） |

## 3. 存档兼容

| 项 | 处理 |
|---|---|
| 缺 ship_mods | 补默认 {cannon_slots:0, sail_tier:0} |
| 缺 building_upgrades | 补空字典 |
| 缺 gear_level / crew_xp | 补空字典 |
| 缺 build_submitted | 补空字典 |
| 缺 player 子字典 | 用默认值兜底 |

## 4. 新商品初始库存

新商品在港口首次访问时按 50% 满值初始化，保证开局可买可卖。
