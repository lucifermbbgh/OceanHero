# 1.2.11 升级说明（配方数据化）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.2.10 |
| 目标版本 | **1.2.11** |
| 状态 | 已发布（2026-11-18） |
| 单一功能点 | 生产配方从代码常量搬到数据文件 |

## 1. 为什么

配方原先写在 `GameState.RECIPES` 里，改一条配方要动代码、要重新导出版本。
搬到数据文件后：改数据即改玩法，校验层也能覆盖到。

**注意：这不是数据库**，是一个 JSON 文本文件，启动时读一次进内存。

## 2. 数据格式

`data/defs/recipes.json`

    {
      "version": 1,
      "recipes": [
        {"out": "beer", "in": {"wheat": 3}, "facility": "工坊"},
        {"out": "cannon_goods", "in": {"iron_ore": 3, "copper": 2}, "facility": "工坊（军械）"}
      ]
    }

## 3. 加载策略

| 情况 | 行为 |
|---|---|
| 文件存在且合法 | 使用 JSON 内容 |
| 文件缺失 | 回退到代码内 `RECIPES_FALLBACK` |
| JSON 解析失败 | 同上，保证游戏可启动 |

## 4. 导出

`export_presets.cfg` 的 `include_filter` 由 `*.txt` 扩展为 `*.txt,*.json`，
否则打包后文件不会进 PCK。
