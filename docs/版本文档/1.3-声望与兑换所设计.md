### 1.3 是否拆表开发

| 问题 | 结论 |
|---|---|
| items.csv 与 shops.csv 要不要分两次做 | **不拆**。两张表 + 载入器 + 校验是一个模块，一次补丁完成（≤150 行） |

## 2. 兑换所

### 2.1 刷新规则

| 项 | 规则 |
|---|---|
| 每次上架 | **10 件** |
| 构成 | 8 件随机（共享池）+ 2 件势力专属 |
| 刷新周期 | 游戏内 **1 个月**（28 天） |
| 存储 | `shop_stock[势力] = {items: [...], month: 月序号}` |
| 势力 | 六个国家 + 幽溟，**全部有兑换所** |

### 2.2 单元格

| 区域 | 内容 |
|---|---|
| 上块 | 图标占位（灰底）+ 物品名 |
| 下块 | **只显示声望等级要求**，如「声望 51」 |
| 颜色 | 声望不足 → **红**；声望足够 → **绿**（只用两色） |
| 网格 | 每行 5 格，两行共 10 格 |

### 2.3 兑换详情弹窗（点击单元格）

| 行 | 内容 |
|---|---|
| 1 | 物品名 |
| 2 | 类型（装备 / 船只） |
| 3 | 需求声望（档位说明） |
| 4 | **声望消耗** |
| 5 | **金币价格** |
| 6 | 效果说明 |
| 7 | [确认] [取消] |

| 操作 | 行为 |
|---|---|
| 确认 | 现金不足 → 提示「金币不足」并关闭；足额 → 扣金币（与声望）→ 提示「兑换成功」→ 关闭 |
| 取消 / ESC | 关闭弹窗 |
| 支付 | **只扣现金**，不动存款 |

## 3. 私掠证（最终规则）

| 项 | 规则 |
|---|---|
| 数量 | 全游戏仅一张 |
| 换证 | 必须先出售再购买 |
| 幽溟 | **不发私掠证** |

### 3.1 声望结算

| 目标 | 无证 | 持 A 证 |
|---|---|---|
| A 的敌国 | B −L，A +L/2 | B −L，**A +L**（替换） |
| A 的中立国 | B −L | B −L，**A 不扣** |
| A 的盟国 | B −L | B −L，**A −L/2** |
| A 本国 | A −L | **A −2L**（叛旗） |

### 3.2 附带效果

| 效果 | 说明 |
|---|---|
| A 国巡逻队不攻击玩家 | 持证即视为己方 |
| A 国关税再 −2% | 叠加在档位之上 |

### 3.3 交易

| 渠道 | 支持 |
|---|---|
| 黑市 | 买 + 卖（返还 30%） |
| 拍卖行 | 挂单出售 |

> 两者共用 `trade_item` 运行时结构，`kind = license`。

## 4. 兑换物品池

### 4.1 共享池（不包含资源）

| 类别 | 数量 | 来源 |
|---|---|---|
| 装备 | 6 件 | 现有 20 件装备中的 R/SR/SSR |
| 船只 | 2 艘 | 现有 10 艘船中的中级 |

### 4.2 势力专属（7 势力 × 2 件）

| 势力 | 普通（金币） | 稀有（金币 + 声望） |
|---|---|---|
| 云澜 | 云澜军帆（航速 +12%） | 云澜快帆（船：航速 +25%） |
| 赤鳞 | 赤鳞商箱（货舱 +25%） | 赤鳞商船（船：货舱 +40%） |
| 霜屿 | 寒铁舵（转向 +15%） | 霜屿破冰舰（船：船体 +25%） |
| 玄礁 | 玄礁铁甲（装甲 +6） | 玄礁夜帆（船：转向 +20%） |
| 白鲸 | 鲸骨撞角（接舷 +8） | 白鲸鲸骨船（船：船体 +30%） |
| 苍梧 | 苍梧轻帆（航速 +10%） | 苍梧猎帆船（船：航速 +20%） |
| 幽溟 | 幽溟黑帆（航速 +15%） | 幽溟鬼船（船：航速 +30%，装甲 −3） |

**不做**：军旗（声望 +10%）、海图（探索 +15%）——需新增 buff 系统，留到装备系统升级版本。
