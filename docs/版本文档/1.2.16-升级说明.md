# 1.2.16 升级说明（删除交易所建筑）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.2.15 |
| 目标版本 | **1.2.16** |
| 状态 | 已发布（2026-11-18） |
| 单一功能点 | 彻底删除交易所建筑与其效果 |

## 1. 删除内容

| 项 | 处理 |
|---|---|
| data/buildings/exchange.tres | 删除 |
| manifest 中的登记 | 删除 |
| 岛屿初始建筑计划中的交易所 | 删除（港城由 8 座变 7 座） |
| exchange_level / exchange_tab_unlocked | 删除 |
| sell_bonus() 依赖交易所 | 改为固定 0 |
| visit_has 的 exchange 分支 | 删除 |
| 并行升级快捷按钮 | 交易所换为织帆坊 |

## 2. 影响

| 项 | 变化 |
|---|---|
| 建筑总数 | 8 → **7** |
| 港城岛初始建筑 | 8 → **7 座** |
| 卖出价加成 | 原先随交易所等级最高 +15%，现恒为 0 |

> 卖出加成归零会让卖出价整体略降，属于预期变化；如后续需要，可由其他建筑或声望提供。

## 3. 验收

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 建筑总数 7 | ✅ |
| 2 | 港城岛初始 7 座 | ✅ |
| 3 | 卖出加成为 0 | ✅ |
| 4 | 无 exchange 服务门禁残留 | ✅ |

**测试**：66 单元 + 729 集成
