# 1.4.6 升级说明（舰船面板）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.4.5 |
| 目标版本 | **1.4.6** |
| 状态 | 已发布（2026-11-20） |
| 功能组 | 船模插槽 + 装备/人员双页签 + 属性栏 + 强化入口 |

## 1. 界面结构

    舰船面板
    ┌──────────────────────────────┬──────────────┐
    │  [装备] [人员]               │  舰船属性     │
    │                              │  9 项实时值   │
    │      船体占位 + 甲板条        │              │
    │      12 类模块插槽（锚点）    │              │
    └──────────────────────────────┴──────────────┘

## 2. 插槽

| 项 | 实现 |
|---|---|
| 定位 | 读取 `ModuleDef.anchor`（0~1 相对坐标）× 船模区尺寸 |
| 显示 | 模块名首字 + 层号 + 强化等级（如「炮2+1」） |
| 点击 | 弹出详情弹窗 |

## 3. 弹窗

| 页签 | 内容 |
|---|---|
| 装备 | 当前装备、可安装装备列表（按槽位过滤）、卸下 |
| 人员 | 当前船员、该岗位可选船员、撤下 |
| 通用 | 等级 / 上限 / 强化花费 + 强化按钮 |

## 4. 属性栏

船体、航速、转向、装甲、舷侧炮、货舱、船员上限、接舷、声望加成（实时读取 `stats()`）。
