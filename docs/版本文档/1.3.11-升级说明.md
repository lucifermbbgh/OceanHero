# 1.3.11 升级说明（物品表与声望兑换所）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.3.10 |
| 目标版本 | **1.3.11** |
| 状态 | 已发布（2026-11-20） |
| 功能组 | items.csv / shops.csv 载入 + 兑换所面板骨架 |

## 1. 数据表

| 表 | 行数 | 字段 |
|---|---|---|
| data/defs/items.csv | 22 | id, name, type, ref, rarity, price, desc |
| data/defs/shops.csv | 22 | shop, item, gold, rep_cost, rep_need, unique |

**shop 取值**：`exchange_<势力>` 为势力专属，`shared` 为共享池。

## 2. 兑换所规则

| 项 | 规则 |
|---|---|
| 每次上架 | 10 件 = 2 专属 + 8 共享随机 |
| 刷新 | 按游戏月（`TimeService.month()`）+ 势力哈希稳定抽样 |
| 势力 | 七势力全部可用（含幽溟） |

## 3. 界面

| 项 | 实现 |
|---|---|
| 入口 | 势力声望面板 → 页签下方「声望兑换所」 |
| 网格 | 5 列 × 2 行 |
| 单元格 | 上：物品名；下：声望需求 |
| 颜色 | 声望不足红、足够绿 |
| 点击 | 弹窗展示类型/需求/声望消耗/金币/效果 + 确认取消 |

## 4. 导出

`include_filter` 增加 `*.csv`，否则打包后表不进 PCK。
