### 顺带修正

- 代码中船与海怪的 `collision_mask` 由 1 改为 0，与"原作无船体碰撞"对齐。

### 严重缺陷：转向速率单位错误（导致船头抽搐）

- **现象**：NPC 在岛屿附近转向时船头高频左右抖动；玩家转舵也极难控制。
- **根因**：`turn_rate` 在数据表里的单位是**度/秒**（UI 也写「转向 45°/s」），
  但 `sea_ship` 里直接当**弧度/秒**用：`heading += turn_rate * delta`。
  等于转向快了 **57 倍**（45 rad/s ≈ 2578°/s），每帧转过 43°，必然过冲 → 逐帧反转。
- **修正**：`deg_to_rad(turn_rate)`。实测满舵 1 秒转 45.6°，与数据一致。
- **连带修正**：
  1. 避障增加**滞回半径**与**绕行侧锁定**，不会在左右切线间反复切换
  2. 避障期间**独占转向权**，不让返航/巡游逻辑插进来对掰
  3. 转向输出加**死区 0.05 rad**，消除对准后的微幅过冲
- **回归**：新增"150 帧内反向次数 ≤ 8"的转向稳定性测试。

### 开火方式定稿：手动逐轮

- 曾短暂做过"自动开火开关"，需求方否决：**锁定就开打会强迫玩家接受不想打的战斗**。
- 最终规则：
  1. **锁定 ≠ 交战**，锁定只是设置观察/瞄准对象
  2. 每一次齐射都必须由玩家点「开火」触发

  4. 玩家不开火时，本舰绝不主动射击
- 敌舰 AI 仍自动开火（AI 不需要玩家操作）

### 修正：航线绕障方式

- **现象**：点击岛屿另一侧或点撤离时，船直直撞上去再贴边蹭过去。
- **根因**：`_route_to()` 只插入一个"垂足点"（垂直于起终点连线），插完不检查第二段，
  也不处理多岛串联；撤离更是直接直线。
- **修正**：改为**逐段切点规划**——
  1. 逐段检查航线是否穿过任意岛屿，穿过就计算切点（`acos(r/d)`）插入
  2. 取"离目标更近"的那个切点，天然贴着外圈走
  3. 反复迭代最多 8 次直到整条航线不穿岛
  4. 起点已在圈内时先向外推出
  5. 撤离改走同一套规划

### 修正：高级图出场即被围攻

- **现象**：进入 3 图以上时，周围十几个海怪与海盗同时扑上来。
- **根因**：全部敌人都刷在玩家周围 480~1160 px 的环带里，索敌半径又是 1500 px。
- **修正**：
  1. 玩家出生圈 1150 px 内不刷怪
  2. 保留 3 个"迎接"单位在 1150~1650 px 环带，避免空海
  3. 其余单位全图均匀撒点，2000 px 网格内 ≤ 3 个
  4. 同时锁定玩家的单位上限 3，其余继续巡游
  5. 索敌半径 1500 → 1100
  6. 单位增加"属地"概念，离出生点 > 1300 px 会返航

- **二次修正（均匀性）**：仅靠网格密度不足以保证"不挤成一堆"——
  同一格内仍可能贴脸，且"迎接"单位原本是 3 次独立随机角度，可能全挤在一侧。
  - 新增**最小间距 420 px**（不够时降到 210）+ **三级降级采样**，兜底改为"最空的位置"
  - "迎接"单位改为绕玩家 **120° ± 20° 等分**

### 缺陷修复：NPC 原地打转

- 现象：海图上所有无目标的 NPC 会一直缓慢旋转。
- 根因：`_ai_steer()` 在"无目标"分支里返回了**常量 0.2** 的舵角，等价于永久满舵。
- 修复：改为巡游逻辑——每 4~9 秒随机换一次航向，航向对齐（±0.08 rad）后舵角归零；
  转向幅度限制在 ±0.6，不会像无头苍蝇一样猛打舵。
- 回归：新增行为测试，跑 180 物理帧后检查最后 0.5 秒的航向漂移 < 0.02 rad。
- 顺带修复海怪：触手原本用 `_sway * 0.7` 线性累加，视觉上绕着身体转圈；
  改为 `sin()` 来回摆动。海怪本体本来就没有旋转逻辑。
