# 1.5.1 升级说明（人员与装备展示排序）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.5.0 |
| 目标版本 | **1.5.1** |
| 状态 | 已发布（2026-11-21） |
| 单一功能 | 人员与装备展示按稀有度从高到低排序 |

## 1. 涉及的页面

### 人员展示

| # | 页面 | 列表 |
|---|---|---|
| 1 | 酒馆招募 —— 名册 | 已招募船员 |
| 2 | 酒馆招募 —— 招募池 | 本周候选 |
| 3 | 船员名单面板 | 全部船员 |
| 4 | 舰船面板 · 人员页签 | 当前模块可选船员 |

### 装备 / 物品展示

| # | 页面 | 列表 |
|---|---|---|
| 5 | 舰船面板 · 装备页签 | 当前模块可装装备 |
| 6 | 船厂 · 装备库 | 各槽位可购买装备 |
| 7 | 船厂 · 装备强化（旧面板） | 已拥有装备 |
| 8 | 仓库 / 货舱 | 商品（按种类汇总，无稀有度） |
| 9 | 声望兑换所 | 兑换项（按势力声望门槛排序） |

> 说明：仓库与兑换所的物品没有稀有度字段，未做稀有度排序。

## 2. 实现

| 项 | 说明 |
|---|---|
| 工具函数 | `_sorted_rar(items)` + `_rarity_of(x)` |
| 排序规则 | 稀有度从高到低；同稀有度保持原顺序 |
| 覆盖 | 船员名册、招募池、船员名单、模块人员、装备页签、船厂装备库、旧强化面板 |
