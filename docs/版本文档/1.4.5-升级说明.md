# 1.4.5 升级说明（模块强化经济）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.4.4 |
| 目标版本 | **1.4.5** |
| 状态 | 已发布（2026-11-20） |
| 功能组 | 模块强化成本、材料消耗、船级上限 |

## 1. 成本公式

    金币 = 1200 × 权重 × (等级+1)^1.6
    木材 = 40 × 权重 × (等级+1)
    铁矿 = 15 × 权重 × (等级+1)

### 模块权重

| 权重 | 模块 |
|---|---|
| 1.4 | 炮门 |
| 1.2 | 甲板、风帆 |
| 1.1 | 仓库、舵轮 |
| 1.0 | 船长室、宿舍、工坊 |
| 0.9 | 瞭望台、医疗室 |
| 0.8 | 旗杆、厨房 |

## 2. 上限

| 项 | 规则 |
|---|---|
| 等级上限 | min(5, 船级) |
| 1 级船 | 只能强化到 1 |
| 10 级船 | 可到 5 |

## 3. 接口

| 接口 | 说明 |
|---|---|
| `module_upgrade_cost(mid, layer)` | 返回下一级花费 |
| `upgrade_module(mid, layer)` | 校验金币/材料/上限后强化 |
| `module_level_cap()` | 当前船的上限 |

## 4. 验收

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 成本含金币/木材/铁矿 | ✅ |
| 2 | 等级越高成本越高 | ✅ |
| 3 | 1 级船上限 1 | ✅ |
| 4 | 达上限拒绝 | ✅ |
| 5 | 金币/材料不足拒绝 | ✅ |
| 6 | 成功强化扣资源并 +1 级 | ✅ |
