# 1.6.17 升级说明（商品图标 28 枚 + 市场/仓库接入）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.6.16 |
| 目标版本 | **1.6.17** |
| 状态 | 已发布（2026-11-28） |
| 单一功能 | 28 种商品图标生产与 UI 接入 |

## 1. 生产

| 项 | 说明 |
|---|---|
| 模型 | DreamShaper（逐张 512²，22 步） |
| 数量 | 28 枚（首批 28 + 返工 9 + 布料 1） |
| 后处理 | 白底抠除 → bbox 裁剪 → 128×128 RGBA |
| 校验 | 拼版接触表人工核对，坏图返工 |

## 2. 接入

| 页面 | 表现 |
|---|---|
| 本地市场行 | 名称前 26px 图标 |
| 仓库/货舱行 | 名称前 26px 图标 |
| 缓存 | static 字典，避免重复解码 |
