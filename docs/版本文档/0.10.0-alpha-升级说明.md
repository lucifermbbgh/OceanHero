# 0.10.0-alpha 升级说明

| 项 | 内容 |
|---|---|
| 基线版本 | 0.9.0-alpha |
| 目标版本 | 0.10.0-alpha |
| 状态 | 已发布（2026-11-17） |
| 主题 | 世界市场全港口可见 + 升格实时生效 + 拍卖行 |

## 1. 背景

0.9 让经济系统跑起来了，但试玩暴露两个体验问题，同时要开始做拍卖行：

- **世界市场只在母港可见**：在岛上做生意时看不到别处的行情，必须跑回母港查
- **升格不实时**：投资满额等 52 周后，系统里变了但当前这局看不到反馈
- 拍卖行作为未来模块，需要先落地设计，本版实现

## 2. 需求

### 2.1 世界市场在所有地区市场可见

| 项 | 规则 |
|---|---|
| 可见范围 | 母港市场 + **任意岛屿港口市场** |
| 数据来源 | 统一的港口注册表（已实现） |
| 差异 | 无。所有市场看到的世界市场完全一致 |
| 本地市场 | 仍只显示当前港口的商品 |

**实现要点**：世界市场是一个**共享组件**，母港与岛屿港口复用同一段逻辑，避免两套代码。

### 2.2 升格实时生效

| 项 | 旧行为 | 新行为 |
|---|---|---|
| 触发时机 | 周结算写数据 | 周结算写数据 **+ 立即刷新场景内的岛屿** |
| 玩家反馈 | 要重进海域才看到 | **当场播报**：`白帆渔村 升格为 白帆港镇！` |
| 聚落外观 | 场景内不变 | 立即按新等级重绘（半径不变、颜色/名称变化） |
| 港口服务 | 重进后生效 | 当前停靠的港口面板立即反映新等级服务 |

> 岛的面积仍然不变，只有聚落等级、名称、颜色与服务变化。

### 2.3 经济规模效应（确认，不调整）

城市买得比村落便宜是**规模效应**带来的合理优势，保留现状：

| 系数 | 村落 | 乡镇 | 城市 |
|---|---|---|---|
| 特产等级系数 | 1.20 | 1.00 | 0.85 |
| 叠加投资折扣（Lv5） | - | - | 最高再降 50% |

**未来才考量**的经济学指标（本版不做）：

- 边际利润 / 边际成本
- 均衡价格
- 规模报酬（递增 / 不变 / 递减）
- 跨港套利的自动均衡

## 3. 拍卖行（本版实现）

### 3.1 定位

| 项 | 内容 |
|---|---|
| 位置 | **仅大型岛屿的港口城市**，一张图一座 |
| 与船厂区别 | 船厂卖**空船与常规装备**；拍卖行卖**有来历的东西** |
| 结算 | 竞价，价高者得，每周刷新货品 |
| 货币 | 金币 |

### 3.2 出售内容

| 类型 | 说明 |
|---|---|
| **整船** | 基础船 + 1~2 件特殊装备 + 0~1 名稀有船员，打包出售（比单买便宜 20%） |
| **特殊装备** | 稀有度 SR 及以上的装备 |
| **特殊船员** | SSR / UR 船员 |
| **魔法船只** | 极稀有，每次刷新 20% 概率出现一件；**允许玩家获得**（原作中为 Boss 独占，本作开放为终局目标） |

### 3.3 程序化生成

```
每次刷新生成 3~5 件货品：
    类型权重：整船 40% / 装备 30% / 船员 20% / 魔法船 10%（且每刷最多 1 件）

    整船 =
        基础船：从 ShipDef 池随机（允许比玩家高 1~2 级）
        变体：通用 / 海军 / 海盗 三选一
        特殊装备：1~2 件（SR 及以上）
        特殊船员：0~1 名（SSR 及以上）

    起拍价 =
        船价 × 1.0~1.3
      + 装备价 × 1.2
      + 船员雇佣价 × 1.5
      + 稀有度溢价（魔法船额外 ×2.5）
```

### 3.4 竞价规则

| 项 | 规则 |
|---|---|
| 起拍价 | 生成时确定，显示在面板上 |
| 玩家出价 | 必须 ≥ 当前价 × 1.05 |
| NPC 出价 | 每周结算时有 40% 概率加价 8%~15%（纯概率，**不与玩家声望挂钩**，不做竞拍威慑） |
| 领先者 | 记录当前最高价与出价方（玩家 / NPC） |
| 周期 | 每件货品挂 **2 周**，到期结算 |
| 赢得 | 玩家领先 → 扣金币，货品入账 |
| 输掉 | NPC 领先 → 货品移除，金币不扣 |
| 流拍 | 无人出价 → 移除 |
| 金币不足 | 到期时若玩家领先但余额不足 → **流拍**，并记录「违约次数」 |

### 3.5 货品入账

| 类型 | 去向 |
|---|---|
| 整船 / 魔法船 | 船位（若船位已满则提示需要先腾位置，拍卖保留到下周） |
| 特殊装备 | 装备库 |
| 特殊船员 | 船员名册 |

### 3.6 界面

```
拍卖行 · 白帆港城        金币 128,000

【整船】黑曜号 · 三级战列舰·海盗型
   附带：暴风之帆(SR) / 加农炮组(SSR)
   当前价 96,000（NPC 领先）  剩 1 周    [出价 101,000]

【船员】独眼哈桑 · SSR 炮手
   当前价 42,000（你领先）    剩 2 周
```

### 实现说明

- 货品生成抽成 `scripts/systems/auction_factory.gd`，纯静态函数，便于测试
- 竞价推进放在 `GameState.tick_auctions()`，由 `WorldTick` 每周调用
- 船位不足时整船挂单**保留到下周**，不会白扣钱
- 升格实时刷新靠 `EventBus.islands_upgraded` 广播，场景收到后改岛屿等级、名称并重绘

## 5. 不做

- 不做经济学高级指标（边际利润 / 均衡价格 / 规模报酬）
- 不做黑市、银行（未来模块）
- 不做玩家间竞价（单机，对手是 NPC）
- 不调整城市/村落的规模效应系数
