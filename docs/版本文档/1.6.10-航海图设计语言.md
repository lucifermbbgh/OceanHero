# 航海图设计语言（1.6.10）

| 项 | 内容 |
|---|---|
| 日期 | 2026-11-26 |
| 目的 | 明确「航海图」与「插画/色块图」的区别，作为后续地图美术的判据 |

## 1. 航海图的本质

航海图不是风景画，而是**导航信息图**。它要回答四个问题：

| 问题 | 图面元素 |
|---|---|
| 我在哪 | 当前位置标记、经纬/网格 |
| 周围有什么 | 海岸线、岛屿、浅滩、礁石 |
| 怎么过去 | 航线（实线/虚线）、节点、距离 |
| 有什么危险 | 暗礁、浅滩、危险航线图例 |

## 2. 与插画、色块图的区别

| 维度 | 插画（错误方向） | 航海图（正确方向） |
|---|---|---|
| 目的 | 好看 | 好读、可导航 |
| 信息密度 | 装饰多、语义少 | 符号多、语义明确 |
| 颜色 | 厚涂渐变 | 有限平涂色阶 |
| 地形 | 写实山体 | 符号化山形/树形 |
| 文字 | 装饰性伪文字 | 真实地名、图例 |
| 区域 | 大色块 | 虚线边界 + 少量高亮 |

## 3. 参考图（航海板）拆解

| 元素 | 参考做法 | 我们的映射 |
|---|---|---|
| 深海 | 深蓝平涂 | 普通海域 |
| 浅滩 | 浅蓝描边环 | 岛周浅水、危险区 |
| 陆地 | 米白平涂 + 深色海岸线 | 大陆/岛屿 |
| 节点 | 琥珀色圆点 + 金边 | 30 个海域节点 |
| 常规航线 | 浅蓝实线 | 可通行连接 |
| 危险航线 | 虚线 | 高危/未探索连接 |
| 图例 | 左下角说明面板 | 必须保留 |
| 罗盘 | 左上角小罗盘 | 必须保留 |
| 标题 | 顶部饰框标题 | 世界地图标题 |

## 4. 配色（平涂）

| 用途 | 色值方向 |
|---|---|
| 深海 | #1B4A6B ~ #24597F |
| 浅滩 | #BFD9E2 |
| 陆地 | #E8DFC8 |
| 海岸线 | #17394F |
| 节点 | #E8B23A + 深边 |
| 航线 | #A9CBD8 |
| 文字 | #1B2D3A / 米白 |

## 5. 我们两个地图产品的定位

| 产品 | 风格 | 信息重点 |
|---|---|---|
| 世界总图 | **航海板示意**（参考图1） | 30 海域节点、连接、势力、迷雾 |
| 海域分图 | **局部海图**（NYMERIA） | 岛屿轮廓、浅滩、港口、航线 |

## 6. 禁止项

| 禁止 | 原因 |
|---|---|
| 大面积区域色块 | 抢视觉、无信息 |
| 厚涂写实风景 | 不可读、与俯视图冲突 |
| 装饰性伪文字 | 假信息 |
| 无图例 | 玩家无法理解符号 |

## 7. 结论

先把世界总图做成**清晰的航海板**（平涂 + 符号 + 图例 + 节点 + 航线），
再考虑海域分图的局部海岸细节。**可读性优先于装饰性。**
