# 1.4.10 升级说明（插槽严格坐标布局）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.4.9 |
| 目标版本 | **1.4.10** |
| 状态 | 已发布（2026-11-20） |
| 功能组 | 模块区域化、插槽按绝对坐标放置、船艏斜桅修正 |

## 1. 设计变更

| 项 | 之前 | 现在 |
|---|---|---|
| 定位方式 | 每个模块一个自由锚点（0~1） | **区域化布局**：甲板列 / 炮门列 / 舱室区 / 桅杆区 |
| 分层插槽 | 锚点 + 固定偏移，容易挤出船体 | 按行高均分，严格落在船体行内 |
| 船艏斜桅 | 画在左上角，脱离船体 | 贴在船首前方 |

## 2. 区域划分

| 区域 | x 范围 | 内容 |
|---|---|---|
| 桅杆区 | 0.28 ~ 0.68 | 帆、瞭望台、旗杆 |
| 甲板列 | 0.30 | 甲板各层 |
| 炮门列 | 0.52 | 炮门各层 |
| 舱室上层 | 0.66 / 0.78 | 宿舍、船长室 |
| 舱室下层 | 0.60 / 0.68 / 0.76 / 0.84 | 仓库、工坊、厨房、医疗室 |
| 艉部 | 0.89 | 舵轮 |
