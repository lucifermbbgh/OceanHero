# 1.5 系列规划（世界地图与导航）

| 项 | 内容 |
|---|---|
| 特性版本 | **1.5** |
| 主题 | 世界地图与导航 |
| 基线 | 1.4.20 |
| 预估 | 约 4.5 轮 |

## 1. 目标

| # | 目标 |
|---|---|
| 1 | 用一张世界地图展示 31 张海图的相对位置与归属 |
| 2 | 区分「已探索 / 未探索 / 未解锁」三种状态 |
| 3 | 在海图上直接查看邻接关系与所属势力 |
| 4 | 从海图前往相邻且已解锁的海域 |

## 2. 设计约束（沿用 1.3 决定）

| 约束 | 说明 |
|---|---|
| 通行规则不变 | 仍为邻接图 + 级别解锁 + Boss 门禁；世界地图只是入口 |
| 不做无缝大地图 | 世界地图是导航层，点击切场景，不做连续航行 |
| 显示简化边 | 图上画「同级三角 + 层级走廊」，实际通行按完整邻接表 |

## 3. 数据设计

### 3.1 MapDef 新增字段

| 字段 | 类型 | 说明 |
|---|---|---|
| world_pos | Vector2 | 世界地图上的归一化坐标（0~1） |

### 3.2 探索状态

| 项 | 说明 |
|---|---|
| 存储 | GameState.explored_maps（Array[int]） |
| 写入 | 进入某海图时记录 |
| 存档 | 随存档保存 |

### 3.3 布局

| 项 | 规则 |
|---|---|
| 行 | 每级一行，y = 0.08 + (级-1) × 0.085 |
| 列 | 三列，x = 0.22 / 0.50 / 0.78 |
| 母港 | (0.50, 0.02) |

## 4. 界面设计

| 区域 | 内容 |
|---|---|
| 左侧 | 世界地图画布：节点 + 连线 + 状态 |
| 右侧 | 选中海域详情：名称/等级/势力/相邻/状态 |
| 底部 | 「前往」「关闭」按钮 |

| 元素 | 表现 |
|---|---|
| 节点 | 圆点 + 编号；颜色取所属势力 |
| 当前 | 高亮描边 |
| 已探索 | 实心 + 势力色 |
| 未探索 | 空心灰 |
| 未解锁 | 深灰 + 锁标记 |
| 交界图 | 双色圆环 |
| 连线 | 已解锁实线，未解锁虚线 |

## 5. 交互

| 操作 | 行为 |
|---|---|
| 海面按 M 或点「海图」 | 打开世界地图 |
| 点击节点 | 右侧显示详情 |
| 点「前往」 | 校验邻接 + 解锁后切换海图 |
| Esc / 关闭 | 关闭面板 |

## 6. 拆分（1.5.0 ~ 1.5.3）

| 小版本 | 单一功能 | 预估 |
|---|---|---|
| **1.5.0** | MapDef.world_pos + 探索状态与存档 | 1 轮 |
| **1.5.1** | 世界地图面板（只读：节点/连线/状态/详情） | 2 轮 |
| **1.5.2** | 前往相邻海域（校验 + 切场景） | 0.5 轮 |
| **1.5.3** | 试玩与收口 | 1 轮 |

## 7. 风险

| 风险 | 对策 |
|---|---|
| 31 节点连线过密 | 图上只画简化边，详情面板列完整邻接 |
| 小屏节点拥挤 | 面板固定 1568×812，节点半径 14px |
| 与航行门冲突 | 「前往」复用 can_travel_to()，规则唯一 |
