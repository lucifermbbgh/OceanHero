# 1.5 系列规划（世界地图与导航）

| 项 | 内容 |
|---|---|
| 特性版本 | **1.5** |
| 主题 | 世界地图（只读）+ 海上小地图 |
| 基线 | 1.4.20 |
| 预估 | 约 4.5 轮 |

## 1. 目标

| # | 目标 |
|---|---|
| 1 | 世界地图展示已探索海图的相对位置与势力 |
| 2 | 未到访海图完全隐藏（迷雾，不显示名称/势力） |
| 3 | M 键开关世界地图，Esc 也可关闭 |
| 4 | 海上航行时右上角显示当前海域小地图 |

## 2. 设计约束（按 2026-11-21 决定）

| 约束 | 说明 |
|---|---|
| 只读 | **世界地图不做传送、不做导航**，仅查看 |
| 通行不变 | 航行仍走航门/邻接规则 |
| 迷雾 | 未探索海域在世界地图上不显示任何信息 |
| 未来优化 | 传送/导航留待后续版本 |

## 3. 世界地图数据

| 字段 | 说明 |
|---|---|
| MapDef.world_pos | 归一化坐标（0~1） |
| 布局 | 30 张图 = 10 级 × 3 列；母港 map1 位于 (0.22, 0.08)；每级一行 y = 0.08 + (级-1)×0.085 |
| GameState.explored_maps | 进入海图时记录，随存档 |

## 4. 世界地图界面（只读）

| 元素 | 表现 |
|---|---|
| 已探索节点 | 实心 + 势力色 + 名称 |
| 未探索节点 | 仅一个「？」灰点，**无名称/等级/势力** |
| 当前节点 | 高亮描边 |
| 交界图 | 双色圆环 |
| 连线 | 已探索之间实线，含未探索则虚线 |
| 右侧详情 | 仅已探索显示；未探索显示「未知海域」 |

| 交互 | 行为 |
|---|---|
| M | 打开 / 关闭 |
| Esc | 关闭（最上层） |
| 点击节点 | 已探索显示详情；未探索无反应 |
| 关闭按钮 | 关闭 |

无「前往」按钮。

## 5. 海上小地图

| 项 | 内容 |
|---|---|
| 位置 | 右上角，220×220 |
| 内容 | 当前海域整体俯视：岛屿轮廓、港口标记、玩家位置与朝向 |
| 坐标 | 世界坐标 × (220 / SEA_SIZE) |
| 玩家 | 三角箭头，指向当前 heading |
| 港口 | 金色圆点 |
| 边框 | 半透明底 + 细边框 |
| 刷新 | 每帧重绘（仅坐标变换，开销低） |

## 6. 拆分（1.5.0 ~ 1.5.3）

| 小版本 | 单一功能 | 预估 |
|---|---|---|
| **1.5.0** | 30 图 world_pos + 探索状态与存档 | ✅ |
| **1.5.1** | 人员/装备展示按稀有度排序 | ✅ |
| **1.5.2** | 装备/人员稀有度配色 | ✅ |
| **1.5.3** | 世界地图面板（只读 + 迷雾 + M/Esc） | ✅ |
| **1.5.4** | 应用中文名 + 世界地图改造评估 | ✅ |
| **1.5.5** | 世界地图交互增强（悬停/选中/详情/缩放/路线预览） | ✅ |
| **1.5.6** | 海上小地图（岛屿/港口/玩家） | 1 轮 |
| **1.5.7** | 试玩与收口 | 0.5 轮 |

## 7. 风险

| 风险 | 对策 |
|---|---|
| 迷雾导致地图空旷 | 未探索仅显示灰点，避免信息泄露 |
| 小地图与 HUD 重叠 | 固定右上角，HUD 顶部信息条左对齐 |
| 30 节点连线密 | 只画已探索之间的简化边 |
