# 版本开发文档

> 本文件是**版本迭代的唯一权威记录**。
> 规则：**先写升级文档 → 确认内容 → 再开发 → 测试 → 归档**，不允许先写代码后补文档。

## 1. 版本号规则

```
主版本.次版本.修订号-阶段
  0   .  7   .  0    -alpha
```

| 位 | 何时 +1 | 例子 |
|---|---|---|
| 主版本 | 玩法闭环发生根本变化 / 正式发行 | 0 → 1 |
| 次版本 | 一个完整的**功能批次**（设计+开发+测试+文档） | 0.7 → 0.8 |
| 修订号 | 不改变玩法的修复与打磨 | 0.7.0 → 0.7.1 |
| 阶段 | `alpha` 内部试玩 / `beta` 对外测试 / 无 正式版 | — |

**每次次版本必须有一份独立的升级说明，放在 `docs/版本文档/` 下：`X.Y.Z-升级说明.md`。**

## 1.0 补丁版本规则

| 情况 | 做法 |
|---|---|
| 次版本的功能没做完 | **不进下一版本**，改用补丁号继续：0.10.0 未完成 → **0.10.1** 继续完善 |
| 补丁只做同类工作的收尾 | 不新增主题，只补齐 0.10.0 验收清单里未通过的项目 |
| 补丁也要写升级说明 | `0.10.1-升级说明.md`，内容 = 未完成项清单 + 原因 |

## 3. 下一版本：0.14.0-alpha（待确认）

> 目标：让「三级岛屿」真正有功能差异，并把母港做成成长线。

### 3.1 需求清单

| # | 需求 | 说明 |
|---|---|---|
| 1 | **港口服务按等级开放** | 村庄：维修/市场/任务/换船；乡镇：+船厂+酒馆；城市：+交易所+声望 |
| 2 | **母港成长线** | 渔港村落 → 乡镇（5,000 金 + 100 木 + 50 铁）→ 港口城市（30,000 金 + 400 木 + 200 铁）；升级后解锁对应面板 |
| 3 | **岛屿港口 UI 统一** | 岛屿港口与母港共用面板组件，避免两套 UI 逻辑 |
| 4 | **特产价格差异化** | 不同等级港口特产价格不同（大港便宜、小港贵），形成贸易路线 |

### 3.2 验收标准

- 村庄级港口看不到「船厂」「酒馆」入口
- 母港升级到乡镇后，船厂与基地建设面板出现在母港
- 母港升级到城市后，交易所与声望面板出现
- 同一特产在城/镇/村三个港口价格呈梯度（差异 ≥ 15%）

### 3.3 不做

- 不做 Boss 技能
- 不做美术资源替换（走独立排期）
- 不做多存档界面重构

## 5. 未来：外交模块（不细化，仅登记）

> 海军从「单一势力」拆分为 **6 个国家**，各自独立声望与外交关系。
> 私掠许可证绑定具体国家：持 A 国私掠证劫掠 B 国商船合法，劫掠 A 国视为叛国。

| 国家 | 定位 | 特征 |
|---|---|---|
| **澜国** | 海军强国 | 舰船火力与装甲最硬，声望门槛最高 |
| **赤鳞** | 商会联邦 | 贸易与市场最发达，收购价最好 |
| **霜屿** | 北方岛国 | 耐寒船体，船员耐久高，航线偏北 |
| **玄礁** | 海盗诸岛 | 松散联盟，黑市最繁荣，通缉风险最低 |
| **白鲸** | 渔业邦联 | 谷物与木材产出高，物价低廉 |
| **苍梧** | 新兴王国 | 均衡，崛起中，对各阵营都开放 |

**外交关系（未来）**

| 关系 | 效果 |
|---|---|
| 同盟 | 互相通行，共享声望 |
| 中立 | 正常贸易，不主动攻击 |
| 敌对 | 商船可合法劫掠（需该国私掠证） |
