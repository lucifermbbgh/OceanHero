## 1. 背景

试玩发现点击敌船会立刻开火并引发交战，玩家被迫接受不想打的战斗。原作是「点击锁定、点自己的火炮才开火」。

## 2. 需求与实现

- 锁定与开火分离：点击敌船仅锁定，不自动射击
- 每次齐射由玩家点「开火」触发一轮
- 换目标重新装填，避免刚锁定就开火
- 开火按钮显示 装填 X.Xs / 超出射程 / 开火！
- 脱战机制：与目标拉开 1600px 并保持 5 秒，NPC 放弃追击
- 锁定不再强制敌方开战，改为被打才还手

## 3. 验收结果

- 曾实现「自动开火开关」，经确认否决并移除，最终定为手动逐轮点射
- 锁定后静置 10 秒：己方零输出、敌船毫发无损（实测验证）
