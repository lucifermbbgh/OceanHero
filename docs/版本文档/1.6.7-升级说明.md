# 1.6.7 升级说明（海面/陆地纹理接入）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.6.6 |
| 目标版本 | **1.6.7** |
| 状态 | 已发布（2026-11-26） |
| 单一功能 | 程序海面纹理 + 羊皮纸陆地叠加层 |

## 1. 变更

| 项 | 之前 | 现在 |
|---|---|---|
| 海面 | 单色 + 简单波纹 | 分形噪声 + 波浪线 + 纸感底纹 |
| 陆地 | 纯色多边形 | **羊皮纸贴图 + 双线墨边** |
| 陆地绘制 | 代码画多边形 | 预渲染 `land_overlay.png`，随缩放/拖拽同步 |
| 资源 | 无 | bg_sea.png / land_overlay.png |

## 2. 新增文件

| 文件 | 说明 |
|---|---|
| `tools/map_pipeline/make_map_assets.py` | 程序生成海面与陆地叠加层 |
| `art/world_map/bg_sea.png` | 分形噪声海面 |
| `art/world_map/land_overlay.png` | 透明底陆地贴图 |
| `art/world_map/tex_sea_v2.png` | AI 海面纹理参考（未直接使用） |
