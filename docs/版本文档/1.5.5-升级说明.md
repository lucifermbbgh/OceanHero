# 1.5.5 升级说明（世界地图交互增强）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.5.4 |
| 目标版本 | **1.5.5** |
| 状态 | 已发布（2026-11-23） |
| 单一功能 | 世界地图悬停/选中/详情/缩放/拖拽/路线预览 |

## 1. 交互

| 操作 | 行为 |
|---|---|
| 鼠标悬停 | 节点白环高亮 |
| 左键点击 | 选中节点，右侧显示详情 |
| 滚轮 | 缩放 0.7x ~ 1.8x |
| 拖拽 | 平移画布（限制在 35% 范围） |
| 点击空白 | 取消选中 |
| M / Esc | 开关面板（不变） |

## 2. 状态与视觉

| 状态 | 表现 |
|---|---|
| 当前海域 | 金色圆环 |
| 可直接前往 | 绿色外环 |
| 选中 | 青色圆环 |
| 悬停 | 白色圆环 |
| 未探索 | 灰点「?」 |
| 路线 | 金色折线 + 右侧「航线：N 步」 |

## 3. 详情面板

已探索：名称、势力、劫掠/海兽数量、级别、航线步数。
未探索：仅「未知海域 / 尚未探索，无法查看信息」。

路线只经过**已探索且已解锁**的海域；不可达显示「无已知航路」。
