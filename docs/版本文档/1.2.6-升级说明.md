# 1.2.6 升级说明（岛屿初始货架）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.2.5 |
| 目标版本 | **1.2.6** |
| 状态 | 已发布（2026-11-18） |
| 单一功能点 | 各港初始库存按特产与等级差异化 |

## 1. 规则

| 商品类型 | 初始库存比例 |
|---|---|
| 本港特产 | 80% |
| 食物 / 原材料 | 40% |
| 消费品 | 港城 30%，其他 0 |
| 军用品 | 有铸造厂 30%，否则 0 |
| 贵金属 | 港城 10%，其他 0 |

母亲港特产固定为谷物。

## 2. 验收

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 港村特产 80%（40 满值 → 32） | ✅ |
| 2 | 基础品类 40%（40 → 16） | ✅ |
| 3 | 港村无消费品 | ✅ |
| 4 | 无铸造厂不出军用品 | ✅ |
| 5 | 港城消费品 30%（160 → 48） | ✅ |
| 6 | 港城贵金属 10%（160 → 16） | ✅ |

**测试**：66 单元 + 713 集成
