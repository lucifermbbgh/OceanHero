# 1.2.7 升级说明（商品随机供应）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.2.6 |
| 目标版本 | **1.2.7** |
| 状态 | 已发布（2026-11-18） |
| 单一功能点 | 缺货商品每周有概率补货出现 |

## 1. 规则

| 项 | 规则 |
|---|---|
| 触发 | 每周结算，对库存为 0 的商品掷骰 |
| 概率 | 20% |
| 数量 | 满值的 20% ~ 40% |
| 军用品 | 仅铸造厂港口参与 |
| 贵金属 | 不参与随机补货（保持稀缺） |

配合 1.2.6，形成「固定特产 + 基础供应 + 随机到货」的货架结构，
跑商才有路线选择的意义。

## 2. 验收

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 缺货商品可能补货 | ✅ |
| 2 | 有货商品不被改写 | ✅ |
| 3 | 贵金属不随机出现 | ✅ |
| 4 | 周结算播报补货条数 | ✅ |

**测试**：66 单元 + 713 集成
