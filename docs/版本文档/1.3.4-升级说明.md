# 1.3.4 升级说明（私掠许可证绑定国家）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.3.3 |
| 目标版本 | **1.3.4** |
| 状态 | 已发布（2026-11-18） |
| 功能组 | 私掠证绑定具体国家，合法劫掠按其敌国判定 |

## 1. 改动

| 项 | 之前 | 现在 |
|---|---|---|
| 私掠证 | 布尔值（有/无） | 绑定一个国家 |
| 合法劫掠 | 有证即合法 | 仅对持证国的**敌对国**合法 |
| 购证接口 | `buy_license_black()` | `buy_license_black(nation)` |

## 2. 判定规则

| 目标 | 持澜国证 | 结果 |
|---|---|---|
| 玄礁（澜国敌国） | 是 | **合法**，不扣声望 |
| 霜屿（澜国盟友） | 是 | 非法，照常扣声望 |
| 澜国（本国） | 是 | 非法 |
| 无国籍目标 | 是 | 非法 |

## 3. 存档

| 字段 | 说明 |
|---|---|
| license.has | 是否持有 |
| license.legal | 正规/黑市途径 |
| license.nation | 绑定国家（新增） |

## 4. 验收

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 未指定国家不能购证 | ✅ |
| 2 | 购买后绑定澜国 | ✅ |
| 3 | 劫掠玄礁合法、霜屿非法 | ✅ |
| 4 | 劫掠本国非法 | ✅ |
| 5 | 已有证不可重复购买 | ✅ |

**测试**：66 单元 + 803 集成
