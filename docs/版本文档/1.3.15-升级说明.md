# 1.3.15 升级说明（势力事件）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.3.14 |
| 目标版本 | **1.3.15** |
| 状态 | 已发布（2026-11-20） |
| 功能组 | 宣战 / 停战 / 结盟 / 禁运 四类势力事件 |

## 1. 规则

| 事件 | 效果 |
|---|---|
| 宣战 | 两国关系转为**敌对**，巡逻队相遇交战 |
| 停战 | 两国关系转为**中立** |
| 结盟 | 两国关系转为**同盟** |
| 禁运 | 该国单独事件，贸易受限 |

| 项 | 规则 |
|---|---|
| 触发 | 每周 8% 概率随机生成 |
| 持续 | 4 ~ 8 周 |
| 判定 | `event_relation()` 先于静态关系表 |
| 播报 | 周结算时底部滚动条提示 |

## 2. 与玩家的关系

> 事件只改变**势力之间的关系**，不改变**玩家与势力的关系**。
> 玩家想站队，只能靠自己去打——符合「攻击就是普通扣声望」的约定。

## 3. 界面

势力声望面板「总览」页顶部新增「进行中的势力事件」区块：

    云澜 ⇄ 赤鳞 宣战（剩 6 周）
    霜屿 ⇄ 白鲸 结盟（剩 3 周）

## 4. 验收

| # | 验收点 | 结果 |
|---|---|---|
| 1 | 宣战使两国敌对且对称 | ✅ |
| 2 | 结盟使两国同盟 | ✅ |
| 3 | 停战使两国中立 | ✅ |
| 4 | 禁运事件可生成 | ✅ |
| 5 | 到期自动移除并播报 | ✅ |
