# 1.6.18 升级说明（装备图标 36 枚 + 船厂接入）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.6.17 |
| 目标版本 | **1.6.18** |
| 状态 | 已发布（2026-11-28） |
| 单一功能 | 36 枚装备图标生产与船厂装备库接入 |

## 1. 生产

| 项 | 说明 |
|---|---|
| 模型 | DreamShaper，逐张 512²/20 步，串行 3 批 |
| 后处理 | 白底抠除 → bbox → 128 RGBA |
| 命名 | 与 data id 对齐（fx_gear_* 全称） |
| 校验 | 6×6 接触表核对 |

## 2. 接入

| 页面 | 表现 |
|---|---|
| 船厂 · 装备库 | 每行名称前 28px 图标 |
| 图标缓存 | 与商品图标共用 static 缓存 |

## 3. 风格说明

部分图标为圆形徽章底（势力装备/独特装备），部分为透明底；
UI 层后续可统一加徽章底板对齐观感。
