# 0.6.0-alpha 升级说明

| 项 | 内容 |
|---|---|
| 基线版本 | 0.5.0-alpha |
| 目标版本 | 0.6.0-alpha |
| 状态 | ✅ 已发布（2026-11-16，commit 42496a1） |
| 主题 | 任务板改造与海域边界 |
| 测试 | 65 单元 + 365 集成 |

## 1. 背景

任务接了做不完就卡死；船能开到地图外面；找不到切换海域的入口。

## 2. 需求与实现

- 任务可放弃：回到看板、进度清零、可重新接取
- 取消接取上限（原 3 个）与看板容量上限
- 看板刷新规则：每周结算仅当看板为空时补 9 个
- 海域硬边界：玩家与 NPC 位置钳制在 [0,8000]²
- 顶部罗盘显示前方航门方向、距离、解锁状态

## 3. 验收结果

- 曾实现「岛屿采集」（靠岸按 E 采资源），0.7 被特产市场取代后废弃
- 航门罗盘解决了「找不到切图入口」，但 0.7 又改成边缘换图

## 4. 影响范围

`scripts/core/game_state.gd、scripts/base/base_scene.gd、scripts/sea/sea_scene.gd`

## 5. 遗留问题

岛屿只是装饰；切换地图方式不符合原作
