# 1.3.18 升级说明（试玩验收修复：哨站越界）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.3.17 |
| 目标版本 | **1.3.18** |
| 状态 | 已发布（2026-11-20） |
| 功能组 | 试玩发现的哨站显示问题 |

## 1. 问题

试玩进入 6 号交界图时，画面上仍出现「白帆港 / 浅湾哨站」，
但该哨站只应存在于 1 号母港海域。

## 2. 修复

| 项 | 做法 |
|---|---|
| 哨站位置 | 仅 `map_index == 1` 时锚定，其余海图移到屏幕外 |
| 影响 | 其他海图不再显示哨站圈、标签与交互提示 |
