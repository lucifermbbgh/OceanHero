# 0.5.0-alpha 升级说明

| 项 | 内容 |
|---|---|
| 基线版本 | 0.4.0-alpha |
| 目标版本 | 0.5.0-alpha |
| 状态 | ✅ 已发布（2026-11-16，commit 833339c） |
| 主题 | 仓储体系与首次打包 |
| 测试 | 65 单元 + 344 集成 |

## 1. 背景

买到的货不知道放在哪、市场「库存」其实是港口库存；同时需要把游戏交给他人试玩。

## 2. 需求与实现

- 港口仓库：容量 800 + 400×仓库等级，随存档保存
- 市场「装船 / 存仓」页签，买入去向与卖出来源跟随目标
- 每行显示 港 X｜船 Y｜仓 Z，另有 →仓 / →船 搬运按钮
- 海上命令栏「货舱」按钮，随时查看容量与货物
- 换船载重校验：小船→大船平迁放行，超载禁止换乘并提示卸货量
- 导出配置：macOS universal + Windows x86_64

## 3. 验收结果

- macOS 首次导出失败（universal 要求 ETC2/ASTC），开启后通过
- 导出包数据全为 0 → 改为读 data/manifest.txt 清单加载，导出后数据完整
- 发行版禁用调试端口 McpInteractionServer
- 产出 碧海英豪.app（164MB）/ SeaHeroes-Windows.exe（106MB）

## 4. 影响范围

`scripts/core/game_state.gd、scripts/base/base_scene.gd、export_presets.cfg、data/manifest.txt`

## 5. 遗留问题

任务不可取消；船能开出地图边界
