# 0.9.0-alpha 升级说明

| 项 | 内容 |
|---|---|
| 基线版本 | 0.8.0-alpha |
| 目标版本 | 0.9.0-alpha |
| 状态 | ⬜ 待确认 |
| 主题 | 市场合并（本地/世界）+ 动态市场 + 远洋距离溢价 + 岛屿投资深化 |

## 1. 背景

0.8 让三级港口有了服务差异，但经济系统仍是「各港独立、玩家独舞」：

- 港口之间没有联动，A 港买、B 港卖时 B 港的价格不反映 A 港的行为
- 远洋订单目标永远只有母港和浅湾哨站，从未真正跨岛
- 「港口市场」与「交易所」其实是同一个系统的两个视角，却拆成了两个入口
- 玩家在一座岛反复做生意，没有任何积累感

## 2. 需求

### 2.1 市场合并：本地市场 / 世界市场

> 原来的「港口市场」与「交易所」合并为一个 **市场** 页面，内部用页签切换。
> 后续还会有「拍卖行」页签（仅大型岛屿港口城市，见 §3）。

| 页签 | 内容 | 作用 |
|---|---|---|
| **本地市场** | 只显示当前港口的现货：商品、可买/可卖数量、本港价格 | 日常补给与倒卖 |
| **世界市场** | 跨港口视窗：其他港口的**位置、商品、数量、价格** | 判断值不值得特意跑一趟远洋 |
| ~~拍卖行~~ | 未来版本，见 §3 | — |

世界市场字段：

| 字段 | 说明 |
|---|---|
| 港口名 | 目标港口 |
| 所在海域 | 图号 + 方位，帮助玩家估算航程 |
| 距离 | 从当前位置过去的估算航程（格数） |
| 商品 | 该港有货 / 收购的商品 |
| 数量 | 可成交量（受当地库存限制） |
| 价格 | 该港当前买价 / 卖价 |
| 预计利润 | 差价 × 可成交量（扣成本后） |

### 2.2 动态市场：NPC 参与经济

> 目标：市场不再只由玩家驱动，NPC 商船与港口自身也在买卖，价格会自己波动。

**实现方案（按周聚合，不做逐船模拟）**

```
每座港口 × 每种商品的状态：
    stock        当前库存
    production   周产出（该港特产 + 谷物木材基础产出）
    consumption  周消耗（该港人口 / 产业）
    trend        价格趋势（-1 ~ +1，用于世界市场展示涨跌）

每周结算：
    1. 港口自产：stock += production
    2. 港口自耗：stock -= consumption
    3. NPC 商队流量：按「产出地 → 需求地」生成若干批货运，直接增减两端 stock
    4. 玩家上周交易：把成交额折算成一次库存冲击（买走 = 减库存）
    5. 向满值回归 + 重新计算 trend
```

### 2.3 远洋贸易：距离溢价

- 特产在**原产地**便宜，在**非原产地**贵，价差随距离放大
- 距离系数：`1.0 + min(0.8, 距离 / 8000 × 0.8)`（最多 +80%）
- 世界市场页签直接给出「预计利润」，玩家不用自己算

### 2.4 岛屿投资深化

> 投资不再只给折扣，而是能**把岛养大**。

| 岛屿初始等级 | 投资满额后 |
|---|---|
| 渔港村落 | → 乡镇 |
| 乡镇 | → 港口城市 |
| 港口城市 | 不再升级，只有分红 |

- 投资额满额后**不会立刻升级**，而是在**下一个游戏年**开始时结算升级
- 升级完成后**投资进度清零**，重新从 0 开始累计
- 升级后货架、服务、库存上限全部按新等级生效
- 城市满额后不再升级，改为每周发放「投资红利」（金币 = 投资额 × 0.5%）

**岛屿默认等级调整**：低阶图默认只有村落，中阶图默认只有乡镇（原来每图固定 1 城 1 镇）。

| 海域 | 默认岛屿构成 |
|---|---|
| 1~3 图 | 全部村落 |
| 4~6 图 | 村落 + 1 座乡镇 |
| 7~9 图 | 村落 + 1 座乡镇 + 1 座港口城市 |

### 2.5 投资等级与回报（沿用 0.8 设计，数值微调）

| 等级 | 累计投资 | 折扣 | 货架 |
|---|---|---|---|
| Lv1 路人 | 0 | — | 谷物、木材 |
| Lv2 常客 | 5,000 | 10% | + 本岛特产 |
| Lv3 熟客 | 20,000 | 20% | + 1 种外来商品 |
| Lv4 贵宾 | 60,000 | 35% | + 2 种外来商品，单次上限 ×2 |
| Lv5 股东 | 150,000 | 50% | + 全部商品，单次上限 ×3 |

## 4. 验收标准

| # | 验收点 |
|---|---|
| 1 | 市场页面有两个页签：本地市场 / 世界市场 |
| 2 | 本地市场只显示当前港口的商品与数量 |
| 3 | 世界市场显示其他港口的名称、海域、距离、商品、数量、价格 |
| 4 | 世界市场的「预计利润」与实际跑一趟后的净收益误差 < 25% |
| 5 | 同一商品在两个不同岛屿价格不同（差异 ≥ 10%） |
| 6 | 在 A 港买入 100 单位后，A 港该商品价格上涨 |
| 7 | 跨周后 NPC 交易使部分港口库存发生变化（无需玩家参与） |
| 8 | 距离越远的港口，同一商品售价越高（系数上限 +80%） |
| 9 | 注资 5,000 金后该岛升到 Lv2，买价降低 10% |
| 10 | 投资满额后在下一个游戏年升级为乡镇，投资额清零 |
| 11 | 城市满额后不再升级，改为每周发放投资红利 |
| 12 | 1~3 图默认没有乡镇与城市 |
| 13 | 旧存档正常读取（投资额缺省 0，等级按现有岛屿） |

## 5. 不做

- 不做逐船 NPC 贸易模拟（按周聚合）
- 不做拍卖行与黑市（仅记录设计）

- 不做玩家间交易（单机）

## 6. 性能评估

| 方案 | 计算量 | 结论 |
|---|---|---|
| 逐船 NPC 交易模拟 | O(船数 × 帧) | 不采用 |
| **按周聚合的港口-商品流量** | O(港口 × 商品) = 30×4 = 120 次/周 | ✅ 采用 |
| 世界市场列表 | O(港口 × 商品) 每次打开 | ✅ 可接受 |
| 逐帧价格重算 | 无（仅在交易/跨周时重算） | ✅ |

> 结论：**算力不是瓶颈**。真正的风险是**数值稳定性**——
> 供需曲线若调得太陡，价格会剧烈震荡；需要给库存变化和价格加阻尼上限。
