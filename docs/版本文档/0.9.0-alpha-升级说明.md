# 0.9.0-alpha 升级说明

| 项 | 内容 |
|---|---|
| 基线版本 | 0.8.0-alpha |
| 目标版本 | 0.9.0-alpha |
| 状态 | ⬜ 待确认 |
| 主题 | 港口联网 + 岛屿投资 + 交易所瘦身 |

## 1. 背景

0.8 让三级港口有了服务差异，但交易仍然局限在「一个母港 + 若干只卖三样东西的岛」：

- 港口之间**没有联动**：在 A 港买、去 B 港卖，B 港的价格并不反映 A 港的行为
- 远洋订单的目标永远是母港或浅湾哨站，**从未真正跨岛**
- 交易所里的「期货」概念过重，与单机航海调性不符
- 玩家在一座岛反复做生意，**没有任何积累感**

## 2. 需求

### 2.1 港口联网

| 项 | 内容 |
|---|---|
| 独立库存 | 每座岛港口有自己的商品库存（现为 per-port id，需保证 9 图全岛持久化） |
| 独立行情 | 价格由本港库存决定，同一商品在不同岛价不同（已有基础，需扩展到全岛） |
| 联动 | 在 A 港大量买入会推高 A 港价格；把货运到 B 港大量卖出会压低 B 港价格 |
| 周恢复 | 每周各港库存向满值回归（已有，扩展到全岛） |

### 2.2 远洋订单跨岛

- 订单目标港口从「母港 / 浅湾哨站」扩展为**任意已解锁岛屿港口**
- 目的地越远，锁定价越高（距离系数 1.0 ~ 1.8）
- 订单会指定商品牌子，可能出现「只在本岛有货」的特产订单

### 2.3 岛屿投资（新系统）

见详细设计 §8.9。要点：

| 等级 | 累计投资 | 折扣 | 货架 |
|---|---|---|---|
| Lv1 路人 | 0 | — | 谷物、木材 |
| Lv2 常客 | 5,000 | 10% | + 本岛特产 |
| Lv3 熟客 | 20,000 | 20% | + 1 种外来商品 |
| Lv4 贵宾 | 60,000 | 35% | + 2 种外来商品，单次上限 ×2 |
| Lv5 股东 | 150,000 | 50% | + 全部商品，单次上限 ×3 |

- 投资额来源：直接注资（1:1）+ 该港市场成交额 ×10%
- 折扣只作用于买入价

### 2.4 交易所瘦身

| 标签 | 处理 |
|---|---|
| 行情 | 保留，扩展为多港对比 |
| 远洋订单 | 保留，扩展为跨岛 |
| 大宗交易 | **并入港口市场**（数量 ≥100 自动 95 折） |
| 期货 | **移除** |

## 3. 验收标准

| # | 验收点 |
|---|---|
| 1 | 同一商品在两个不同岛屿的价格不同（差异 ≥ 10%） |
| 2 | 在 A 港买入 100 单位后，A 港该商品价格上涨 |
| 3 | 远洋订单目标可以是任意已解锁岛屿 |
| 4 | 远距离订单的锁定价高于近距离订单 |
| 5 | 注资 5,000 金后该岛升到 Lv2，买价降低 10% |
| 6 | 该岛市场累计成交 50,000 金后，投资额额外 +5,000 |
| 7 | Lv2 之前买不到本岛特产，Lv2 之后可以 |
| 8 | Lv4 单次购买上限变为 20 件 |
| 9 | 交易所只剩 行情 / 远洋订单 两个标签 |
| 10 | 旧存档正常读取（投资额缺省为 0） |

## 4. 不做

- 不做股票/期货等金融衍生品
- 不做玩家间交易（单机）
- 不做跨阵营的经济战争
