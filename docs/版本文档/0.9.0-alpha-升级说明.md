# 0.9.0-alpha 升级说明

| 项 | 内容 |
|---|---|
| 基线版本 | 0.8.0-alpha |
| 目标版本 | 0.9.0-alpha |
| 状态 | 已发布（2026-11-17） |
| 主题 | 市场合并（本地/世界）+ 动态市场 + 阶梯溢价 + 岛屿投资升格 |

## 1. 背景

0.8 让三级港口有了服务差异，但经济系统仍是各港独立、玩家独舞：

- 港口之间没有联动，A 港买、B 港卖时 B 港的价格不反映 A 港的行为
- 港口市场与交易所其实是同一系统的两个视角，却拆成了两个入口
- 玩家在一座岛反复做生意，没有任何积累感
- 岛屿规格完全由地图编号决定，1 图永远没有城市

## 2. 需求

### 2.1 市场合并：本地市场 / 世界市场

| 页签 | 内容 | 作用 |
|---|---|---|
| 本地市场 | 只显示当前港口的现货：商品、可买卖数量、本港价格 | 日常补给与倒卖 |
| 世界市场 | 跨港口视窗：其他港口的位置、商品、数量、价格、趋势、预计利润 | 判断值不值得跑一趟 |

世界市场字段：港口名 / 所在海域 / 距离 / 商品 / 数量 / 价格 / 涨跌趋势 / 预计利润。

### 2.2 动态市场：NPC 参与经济

按周聚合，不做逐船模拟。

    每座港口 × 每种商品：stock / production / consumption / trend

    每周结算：
        1. 港口自产：stock += production
        2. 港口自耗：stock -= consumption
        3. NPC 商队货流：按产出地 → 需求地生成货运，增减两端 stock
        4. 玩家上周交易：成交额折算成库存冲击
        5. 向满值回归 + 重算 trend（价格变动每周限制在 ±15% 以内）

**算力**：30 港 × 4 商品 = 120 次/周，可忽略。

### 2.3 NPC 载货航行（战斗内容，不影响市场）

- NPC 商船与海盗船可携带货物，击沉后掉落
- **战斗胜利可获得其载货的 30%** 作为战利品
- 载货内容**不参与动态市场结算**，单纯是战斗玩法收益

> 这是战斗侧的加法，与经济模型解耦。

### 2.4 阶梯溢价：按地图等级跨度

不用距离系数，地图等级跨度才是真实的价值来源。

**规则**：每种特产有一个产地地图等级（该商品最早出现的地图编号）。

| 情况 | 售价 |
|---|---|
| 目标地图**不产出**该商品 | 按等级跨度溢价，最多 **+300%** |
| 目标地图**也产出**该商品 | 只按普通距离差价，无跨度溢价 |

**举例**：

- 1 图特产朗姆酒，9 图不产出 → 运到 9 图可卖**最高 +300%**
- 1 图特产谷物，9 图也产出 → 只按距离差价，无溢价

**关键约束**：

- 商品本身**不带产地标签**，溢价在**售出时**按商品 id + 目标港口所在地图实时计算
- 因此仓库里同种货物始终可以合并堆叠，不会因为产地不同而分裂

### 2.5 岛屿构成调整

每张图都应该有城市，否则拍卖行要到中后期才体验得到。

| 项 | 规则 |
|---|---|
| 每图构成 | **1 座城市 + 1 座乡镇 + 若干村落**（所有图一致） |
| 岛屿数量上限 | **每图 ≤ 8 座**（运行压力约束） |
| 与地图难度的关系 | 地图只影响敌人强度，不影响岛屿等级构成 |

### 2.6 岛屿投资深化：投资养的是村镇，不是岛

| 概念 | 说明 |
|---|---|
| 投资对象 | 岛上的聚落（村 / 镇 / 城），不是岛屿本身 |
| 岛的面积 | **不变**；升级只换聚落的贴图与功能，不放大岛屿像素 |
| 升级条件 | 投资满额 + **满一整年游戏时间** |

**升级倒计时规则**

投资满额的那一刻开始计时，必须在游戏内走满 52 周才升级：

    第 1 年 6 月 2 周  投资满额
    → 第 2 年 6 月 2 周  升级完成（正好 52 周后）

进度条显示：升格进度 还差 N 周 / 共 52 周。
升级完成后**投资额清零**，重新累计。

### 2.7 投资等级与回报

| 等级 | 累计投资 | 折扣 | 货架 |
|---|---|---|---|
| Lv1 路人 | 0 | — | 谷物、木材 |
| Lv2 常客 | 5,000 | 10% | + 本岛特产 |
| Lv3 熟客 | 20,000 | 20% | + 1 种外来商品 |
| Lv4 贵宾 | 60,000 | 35% | + 2 种外来商品，单次上限 ×2 |
| Lv5 股东 | 150,000 | 50% | + 全部商品，单次上限 ×3 |

城市满额后不再升级，改为每周发红利（投资额 × 0.5%）。

### 3.3 银行

| 项 | 内容 |
|---|---|
| 位置 | **仅港口城市** |
| 功能 | 存款 / 贷款 / 利息 |
| 利率 | **固定值**，不做浮动 |
| 计息 | 按周计息，**按月收取**利息 |
| 期限 | 最长 1 年，到期一次性还清本息 |
| 贷款前提 | 1) 在银行有存款；2) 贷款总额不超过申请时的存款额 |
| 破产 | 付息或还款时资金不足 → 清空存款与现金、海军声望归零、被海军通缉 |

### 实现说明

- **阶梯溢价**在 `MarketModel.sale_multiplier()` 里，商品产地表在 `GameState.COMMODITY_ORIGIN`
- **动态市场**按周聚合：每次周结算随机 8 笔港口间货流，O(港口数)，不做逐船模拟
- **投资折扣**只作用于买入价，卖出价另乘跨度溢价，两者互不干扰
- **升格计时**用新增的 `TimeService.total_weeks()`，界面显示「还差 N 周 / 共 52 周」
- **NPC 载货**在 `sea_ship.cargo_hold`，`LootSystem` 按 30% 结算，与市场结算完全解耦
