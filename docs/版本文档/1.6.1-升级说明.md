# 1.6.1 升级说明（矢量世界地图）

| 项 | 内容 |
|---|---|
| 基线版本 | 1.6.0 |
| 目标版本 | **1.6.1** |
| 状态 | 已发布（2026-11-23） |
| 单一功能 | 世界地图改为矢量多边形海域 |

## 1. 变更

| 项 | 之前 | 现在 |
|---|---|---|
| 海域节点 | 圆点 + 编号 | **切角矩形多边形**，势力色填充 |
| 背景 | 纯色 | 深蓝底 + 波浪纹理线 |
| 区域命中 | 距离检测 | 多边形点内判定 |
| 标签 | 节点旁编号 | 多边形中心编号，未探索显示「?」 |
| 航线 | 实线 | **虚线** |
| 小地图 | 世界地图打开时仍显示 | 打开世界地图时自动隐藏 |
